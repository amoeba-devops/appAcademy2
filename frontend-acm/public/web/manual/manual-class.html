1 수업일정 등록 관리자

운영 콘솔에서 화상 수업일정을 등록합니다.

  1. /admin/cal (캘린더) 접속 → 일정 등록 클릭.
  2. 제목, 날짜/시간(종일·시작·종료), 분류를 데모수업 또는 정규수업으로 선택합니다.
  3. 담당 강사를 지정하고, 참석 학생(참석자)을 추가합니다. 중요 학생이 입장하려면 그 학생이 참석자에 포함되거나 해당 수업반에 수강 등록돼 있어야 합니다.
  4. 필요 시 메모(설명)를 입력합니다 — 강사·학생의 수업일정 상세와 강의실 화면에 함께 표시됩니다.
  5. 저장하면 보다스쿨 화상수업으로 자동 설정되고 강의 입장 링크가 생성됩니다.
데모수업·정규수업은 저장 시 보다스쿨(BODASCHOOL) 화상수업으로 자동 연결됩니다. 입장 링크는 /portal/classroom/{수업ID} 형태입니다.

2 포털 로그인 강사 학생·학부모

강사와 학생(학부모)은 동일한 학원 포털에 로그인합니다.

  1. https://acm.amoeba.site/portal/login 접속.
  2. 학원 코드, 로그인 ID, 비밀번호를 입력합니다.
  3. 로그인 ID는 관리자가 발급합니다. 이메일을 로그인 ID로 쓰거나, 발급된 ID를 사용합니다.
  4. 비밀번호는 관리자가 발급한 비밀번호로 그대로 로그인합니다. (별도의 강제 변경 절차 없음)
계정·비밀번호 발급/변경은 관리자가 학생·강사 상세 화면의 포털 계정 패널에서 처리합니다. 관리자는 비밀번호를 직접 지정하거나 [로그인ID를 이메일로] 버튼으로 로그인 ID를 이메일로 바꿀 수 있습니다.
강사는 기존 운영 콘솔(/admin) 로그인도 사용할 수 있으나, 포털에서 강의실을 열려면 포털 로그인을 사용하세요.

3 수업일정·수업링크 확인 강사 학생·학부모

  1. 포털 상단 메뉴에서 수업일정(/portal/calendar) 을 엽니다. 월/주/일 보기로 내 수업을 확인합니다.
  2. 수업을 클릭하면 요약(일시·담당강사·장소·메모)이 뜹니다.
  3. [전체내용보기] 를 누르면 상세 화면으로 이동합니다 — 메모와 강의실 입장 카드, 보다스쿨 강의실 링크가 표시됩니다.
상세 화면의 보다스쿨 강의실 링크는 /portal/classroom/{수업ID} 형태로, 누구에게 전달해도 각자 역할(강사/학생)로 입장되는 링크입니다.

4 보다스쿨 앱 설치

화상강의는 보다스쿨(BODA) 앱으로 진행됩니다. 강사·학생 모두 PC에 앱이 설치돼 있어야 입장됩니다.

  1. 강의실 입장 카드의 [보다스쿨 설치 안내] 링크(또는 https://bodaedu.kr)에서 앱을 내려받아 설치합니다.
  2. 설치 후 입장 버튼을 다시 누르면 앱이 실행되며 강의실로 연결됩니다.
앱이 설치되지 않은 경우 입장 시 “보다스쿨 앱이 설치되어 있지 않습니다” 안내가 표시됩니다. 설치 후 다시 시도하세요.

5 수업 입장

순서가 중요합니다. 강사가 먼저 강의실을 열고(개설), 그 다음 학생이 입장합니다.

강사 강사 입장 (강의실 개설)

  1. 포털 로그인 → 수업일정 → 수업 클릭 → [전체내용보기].
  2. 입장 카드에서 [강사 입장] 을 누르면 보다스쿨 앱이 실행되며 강의실이 개설(열림)됩니다.
  3. 강의 링크(?autoStart=1)를 열면 강사는 자동으로 강의실이 열리고 입장됩니다.
강사가 강의실을 열어야 학생이 입장할 수 있습니다. 수업 시작 시각 전후로 미리 열어 두세요.

학생·학부모 학생 입장

  1. 포털 로그인 → 수업일정 → 수업 클릭 → [전체내용보기].
  2. 입장 카드에서 [앱으로 입장] 을 누르면 보다스쿨 앱으로 강의실에 입장합니다.
  3. 강사가 아직 강의실을 열지 않았다면 “강사가 강의실을 열면 입장할 수 있어요” 안내가 표시됩니다. 강사가 열면 잠시 후 입장할 수 있습니다.
학생 입장은 브라우저(webrtc) 링크가 아니라 보다스쿨 앱으로 진행됩니다. 반드시 앱 설치 후 [앱으로 입장] 을 사용하세요.

6 수업링크 공유

학생에게 링크를 전달할 때는 상세 화면의 보다스쿨 강의실 링크(/portal/classroom/{수업ID})를 복사해 전달합니다.

주의 — bodaedu.kr/webrtc?...&UTy=11&UId=... 형태의 링크는 특정 사용자(강사) 전용이라 학생에게 공유해도 입장되지 않습니다. 반드시 강의실 링크(/portal/classroom/…) 를 공유하세요.

7 자주 묻는 문제

증상원인 / 해결
학생이 “강사가 강의실을 열면 입장” 안내만 보임강사가 아직 강의실을 열지 않음 → 강사가 [강사 입장]으로 개설 후 학생이 다시 시도.
입장 시 “앱이 설치되어 있지 않습니다”보다스쿨 앱 미설치 → bodaedu.kr에서 설치 후 재시도.
공유한 링크로 학생이 못 들어감webrtc 링크를 공유함 → 강의실 링크(/portal/classroom/…) 를 공유.
로그인이 안 됨학원 코드·로그인 ID·비밀번호 확인. 비밀번호는 관리자에게 재발급 요청(관리자가 직접 지정 가능).
수업일정에 수업이 안 보임해당 수업의 참석자/수강반에 포함돼 있는지 관리자에게 확인.
입장 가능 시간이 아님수업 시작 시각 전후의 허용 시간대(개설 전/종료 후)를 벗어남 → 시간대 확인.
그 밖에 강의실 상태가 계속 “대기”로만 보이면 운영자에게 문의하세요(화상 플랫폼 연동 설정 확인 필요).
