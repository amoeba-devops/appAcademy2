1 포털 로그인

로그인 정보(학원코드·아이디·비밀번호)는 학원 관리자가 발급합니다. 비밀번호를 잊었다면 관리자에게 재설정을 요청하세요.

  1. https://acm.amoeba.site/portal/login 접속
  2. 학원코드와 아이디(강사 이메일 또는 발급 ID) 입력
  3. 비밀번호 입력 — 👁 눈 아이콘을 누르면 입력한 비밀번호를 확인할 수 있습니다
  4. [학원코드/아이디 저장]을 체크하면 다음 로그인 때 자동으로 채워집니다 (비밀번호는 저장되지 않음)
  5. [로그인] → 포털 홈으로 이동
브라우저 즐겨찾기에 /portal 을 등록해 두면 편리합니다. 화면은 좌측 정렬 레이아웃으로, 모바일에서도 동일하게 동작합니다.

2 수업일정 확인

좌측 메뉴 수업일정에서 내가 담당하거나 참석자로 지정된 일정만 표시됩니다. 보기 방식은 월 · 주 · 일 · 리스트 4가지입니다.

  1. 수업일정 메뉴 진입 → 기본 월 보기
  2. 상단 토글로 주/일/리스트 전환 — 리스트는 날짜별로 일정을 목록으로 보여줍니다
  3. 일정을 클릭하면 요약 팝업, [전체내용보기]를 누르면 상세 페이지로 이동

일정 상세 — 모든 정보 표시

항목내용
구분정규수업 / 데모수업 / 레벨테스트 / 기타 (제목 옆 배지)

첨부자료관리자가 일정에 첨부한 파일 — [다운로드] 클릭

3 화상수업 입장 (보다스쿨)

화상수업은 강사가 먼저 입장(=강의실 개설)해야 학생이 들어올 수 있습니다.

  1. 수업일정에서 해당 수업 → [전체내용보기]
  2. 처음이라면 보다스쿨 앱 다운로드 후 설치
  3. [강사 입장] 클릭 → 강의실이 개설되고 앱이 실행됩니다
  4. 필요 시 보다스쿨 강의실 링크를 복사해 학생에게 공유
상세 절차·문제 해결은 수업 개설·입장 매뉴얼을 참고하세요.

4 수강생관리 강사 전용

수업일정 아래 수강생관리 메뉴에서 나에게 배정된 학생을 폴더 형태로 봅니다. 대상은 ① 학생정보의 담당강사가 나로 지정된 학생 ② 내가 담당하는 수업(반)에 소속된 학생입니다.

  1. 수강생관리 진입 → 학생 📁 폴더 그리드 (이름·학교·학년·과목)
  2. 폴더 클릭 → 학생 상세

학생 상세에서 볼 수 있는 정보

구역내용
기본 정보학교/학년 · 과목 · 이메일 · 연락처 · 수강 시작일 · 특이사항 · 학습 목표
연결 상담신규상담에서 등록된 학생이면 상담 번호와 현재 단계
상담 기록상담 과정에서 남긴 최근 기록 5건
수업 기록최근 수업 일정 10건 — 클릭하면 일정 상세로 이동
목록이 비어 있으면 관리자에게 ① 학생정보(/admin/std)의 담당강사 지정 또는 ② 수업(반) 배정을 요청하세요.

5 문서/자료실

탭 2개로 구성됩니다 — 공유받은 게시물(다른 사람이 나에게 공유/제출한 자료)과 내 게시물(내가 올린 자료·문서). 내 게시물 탭에서 [새 문서] 와 [파일 업로드]로 새 글을 만듭니다.

파일 업로드 — 학생에게 자료 배포

  1. 내 게시물 탭 → [파일 업로드]
  2. 파일 선택(20MB 이하) + 제목 입력(생략 시 파일명)
  3. 공유할 학생 선택(복수 가능, 내 반 학생 목록) → [학생에게 공유]
  4. 학생은 자신의 "공유받은 게시물"에서 다운로드합니다
학생이 강사에게 제출한 파일(과제)은 내 공유받은 게시물 탭에 제출 배지로 표시됩니다.

문서 작성 — 게시판(리치에디터)

  1. 내 게시물 탭 → [새 문서]
  2. 제목 입력 후 본문 작성 — 굵게/기울임/취소선/제목(H1·H2)/목록/인용 툴바 지원
  3. 공유 대상 지정(아래 참조) → [저장]

공유대상·권한 — 뷰어/편집자

문서는 구글독스처럼 포털 사용자(강사·학생) 누구에게나 공유할 수 있고, 대상마다 권한을 정합니다.

권한할 수 있는 것
뷰어문서 열람 + 댓글 작성
편집자열람 + 댓글 + 제목/본문 수정
작성자(나)위 전부 + 공유대상/권한 변경 + 삭제
  1. 문서 편집 화면의 공유 대상 패널에서 이름 검색(강사/학생 전체)
  2. 대상 클릭으로 추가 → 각 대상 옆 드롭다운에서 뷰어/편집자 선택
  3. 공유대상 변경은 작성자만 가능합니다

수정 히스토리 · 버전보기 · 복원

문서는 저장할 때마다 버전이 기록됩니다(작성=v1). 문서 하단 🕘 수정 히스토리에서:

  1. 버전 목록 확인 — 버전 번호 · 수정자 · 시각
  2. 과거 버전 [보기] → 해당 시점의 본문을 읽기 전용으로 표시
  3. 편집 권한이 있으면 [이 버전으로 복원] — 복원도 새 버전으로 기록되어 이력이 사라지지 않습니다

댓글

게시물을 볼 수 있는 사람(작성자·공유대상)은 누구나 댓글을 남길 수 있습니다. 목록 카드의 댓글 버튼 또는 문서 하단 댓글 입력창을 이용하세요.
