0 한눈에 보기

상담이 수업 시작 단계에 도달하면 학생·학부모가 자동 등록되고 포털 계정이 자동 생성됩니다. 운영자가 임시 비밀번호를 발급해 전달하면, 사용자는 포털에서 로그인해 본인과 관련된 공지·수업일정·자료를 확인합니다.

접속 주소: https://acm.amoeba.site/portal/login (학생·학부모·강사 공용). 강사는 기존 운영 콘솔(/admin) 로그인도 그대로 사용할 수 있습니다.

1 포털 계정 발급 (운영자)

계정은 대상별 관리 화면의 "포털 계정" 패널에서 발급/재발급합니다. 발급 시 임시 비밀번호가 화면에 1회 표시되며, 이후에는 다시 볼 수 없으므로 [재발급]으로 새 비밀번호를 뽑아 전달합니다.

대상발급 위치
학생학생 관리 → 학생 상세 → 포털 계정 패널
학부모학생 관리 → 학부모 목록 → 해당 학부모 편집(연필) → 포털 계정
강사교사 관리 → 강사 편집 → 포털 계정 패널
  1. 패널에서 계정이 없으면 [계정 발급], 있으면 [비밀번호 재발급]을 클릭합니다.
  2. 표시되는 로그인 ID와 임시 비밀번호를 [복사]합니다. (창을 닫으면 비밀번호는 다시 볼 수 없습니다.)
  3. 해당 학생·학부모·강사에게 아이디와 임시 비밀번호를 전달합니다.
보안: 임시 비밀번호는 발급 시점에만 표시됩니다. 채팅·문자로 전달할 때 노출에 유의하고, 최초 로그인 시 반드시 변경하도록 안내하세요.

2 로그인 & 첫 비밀번호 변경

  1. https://acm.amoeba.site/portal/login 접속.
  2. 전달받은 아이디 + 임시 비밀번호 입력 → 로그인.
  3. 최초 로그인 시 비밀번호 변경 화면으로 이동합니다. 현재(임시) 비밀번호 + 새 비밀번호(8자 이상, 영문+숫자 포함)를 입력합니다.
  4. 변경 완료 후 포털 메인(공지사항)으로 진입합니다.
학부모는 기존 휴대폰 인증(OTP) 로그인(/parent/login)도 계속 사용할 수 있습니다. 아이디/비밀번호 방식과 병행됩니다.

3 포털 메뉴

좌측 메뉴는 공지사항 · 수업일정 · 자료실 3가지이며, 모든 역할(학생·학부모·강사)이 동일하게 사용합니다. 학부모 화면에는 상단에 자녀 선택이 표시될 수 있습니다.

공지사항

학원이 발행한 공지를 최신순으로 읽습니다. 제목을 클릭하면 본문 상세로 이동합니다.

수업일정 (캘린더)

본인과 관련된 일정만 표시됩니다. 상단에서 월 / 주 / 일 보기를 전환하고, ◀ ▶로 기간 이동, [오늘]로 복귀합니다. 읽기 전용이며, 화상수업 링크가 있으면 아이콘으로 바로 입장할 수 있습니다.

역할보이는 일정
강사본인이 담당(assignee)이거나 초대된 일정
학생본인이 참석자로 초대된 일정
학부모자녀가 참석자로 초대된 일정

자료실 (수업자료)

본인이 속한 반(수업) 단위로 자료가 묶여 표시됩니다. [다운로드]로 파일을 받습니다.

역할다운로드 범위
강사본인이 담당하는 반의 자료
학생본인이 수강 중인 반의 자료
학부모자녀가 수강 중인 반의 자료
자료가 안 보이면 아직 반(수업)에 배정되지 않았거나 해당 반에 업로드된 자료가 없는 경우입니다.

4 수업자료 업로드 (강사·운영자)

자료는 반(수업) 단위로 업로드합니다.

  1. 운영 콘솔 → 수업 관리 → 해당 반 상세 → 정보 탭의 수업자료 패널로 이동.
  2. (선택) 자료 제목 입력 → [업로드] → 파일 선택. 최대 20MB.
  3. 목록에서 다운로드 / 삭제가 가능합니다. 업로드 즉시 해당 반의 학생·학부모·강사 포털에 노출됩니다.
업로드 권한은 ADMIN · APP_ADMIN · TEACHER · STAFF입니다. 학생·학부모는 다운로드만 가능합니다.

6 자주 묻는 문제

증상원인 / 해결
로그인이 안 됨아이디·비밀번호 확인. 임시 비밀번호를 잊었으면 운영자에게 재발급 요청.
"비밀번호를 변경하세요" 화면에서 막힘최초 로그인 절차입니다. 새 비밀번호(8자+, 영문+숫자)를 설정하면 진입됩니다.
수업일정이 비어 있음본인이 초대된 일정이 없거나, 조회 기간에 일정이 없는 경우. 월/주/일·기간을 바꿔 확인.
자료실이 비어 있음반 배정 전이거나 해당 반에 업로드된 자료가 없음. 운영자/강사에게 문의.
자료 업로드 실패20MB 초과 또는 권한 부족(강사/운영자만 가능).
