1 포털 로그인

아이디는 학원에 등록한 내 이메일이며, 비밀번호는 학원에서 발급해 줍니다. 비밀번호를 잊었다면 학원(관리자)에 재설정을 요청하세요.

  1. https://acm.amoeba.site/portal/login 접속
  2. 학원코드(학원에서 안내) + 아이디(이메일) 입력
  3. 비밀번호 입력 — 👁 눈 아이콘으로 입력 내용을 확인할 수 있습니다
  4. [학원코드/아이디 저장] 체크 시 다음부터 자동 입력(비밀번호는 저장 안 됨)
  5. [로그인]

2 수업일정 확인

내가 참석하는 수업/일정만 표시됩니다. 상단 토글로 월 · 주 · 일 · 리스트 보기를 전환하세요.

  1. 수업일정 메뉴 → 원하는 보기 선택 (리스트 보기는 날짜별 목록)
  2. 일정 클릭 → [전체내용보기]로 상세 페이지 이동
  3. 상세에서 모든 정보 확인 — 구분 배지 · 시작~종료 일시 · 작성자 · 담당 강사 · 장소 · 관련자(참석자 전원) · 메모 전문
  4. 첨부자료가 있으면 [다운로드]로 수업 자료를 받습니다

3 화상수업 입장 (보다스쿨)

화상수업은 보다스쿨 앱으로 진행됩니다. 강사가 강의실을 연 뒤 입장할 수 있습니다.

  1. 수업일정에서 해당 수업 → [전체내용보기]
  2. 처음이라면 보다스쿨 앱 다운로드 후 설치
  3. 수업 시간에 [앱으로 입장] 클릭 — 앱이 자동 실행되며 강의실로 연결됩니다
  4. "강사가 강의실을 열면 입장할 수 있어요" 안내가 보이면 강사 개설 전이니 잠시 후 다시 시도(화면이 자동 갱신됩니다)
앱 설치·입장이 잘 안 되면 수업 개설·입장 매뉴얼의 문제 해결 섹션을 참고하세요.

4 문서/자료실

탭 2개 — 공유받은 게시물(강사가 공유한 자료·문서)과 내 게시물(내가 올린 과제·문서).

공유받은 자료 받기

  1. 공유받은 게시물 탭 → 강사가 공유한 파일/문서 목록
  2. 📎 파일: [다운로드] 클릭
  3. 📄 문서(문서 배지): 제목 클릭 → 본문 열람

과제 제출 — 강사에게 파일 보내기

  1. 내 게시물 탭 → [파일 업로드]
  2. 파일 선택(20MB 이하) + 제목 입력 → [업로드] — 대상 없이 먼저 업로드됩니다
  3. 업로드된 게시물 카드의 [공유] 버튼 → 담당 강사 검색·선택 → [공유 저장] (= 제출)
  4. 강사에게 공유한 게시물에는 제출 배지가 표시되고, 강사의 "공유받은 게시물"에 나타납니다

문서 열람·작성·댓글

하고 싶은 것방법
문서 읽기공유받은 문서 제목 클릭 — 뷰어 권한이면 열람+댓글 가능
문서 수정작성자가 나에게 편집자 권한을 준 경우 [편집] 버튼이 보입니다
내 문서 만들기내 게시물 탭 → [새 문서] → 제목·본문 작성 → 공유 대상(강사/학생) 추가 + 뷰어/편집자 지정 → 저장
댓글 남기기게시물 카드의 댓글 버튼 또는 문서 하단 입력창 — 볼 수 있는 사람은 누구나 작성 가능
수정 이력 보기문서 하단 🕘 수정 히스토리 — 저장 시점별 버전·수정자 확인, [보기]로 과거 버전 열람

5 자주 묻는 문제

증상확인·해결
로그인이 안 됨아이디는 학원에 등록한 이메일입니다 · 학원코드 확인 · 비밀번호는 학원에 재설정 요청
수업일정이 안 보임내가 참석자이거나 내 반 수업만 표시됩니다 — 학원에 수업 배정 확인 요청
강의실 입장이 안 됨강사가 아직 강의실을 열지 않은 상태일 수 있습니다 — 수업 시간에 다시 시도 · 보다스쿨 앱 설치 여부 확인
자료가 안 보임강사가 나에게 공유한 자료만 보입니다 — 담당 강사에게 공유 요청
문서 [편집]이 안 보임편집은 편집자 권한을 받은 경우만 가능 — 작성자(강사)에게 권한 요청
