# Dashboard Improvement Plan (대시보드 개선 실행계획)

## 1. Scope (범위)

[엑셀 분석 및 개선안](../analysis/REQ-260917-dsh-excel-improvement.md)을 실행하기 위한 제안이다. 현재 사이트 탭과 기간 필터를 재사용하고, 집계 신뢰성 정비 후 성과 분석·후속 조치 기능을 순차 도입한다. 이 문서는 구현 완료 보고서가 아니다.

- 넓은 화면은 핵심 카드 3열×2행, 태블릿 2열, 모바일 1열. 카드 안에 가로 스크롤 표를 넣지 않는다.
- 카드 선택 시 상세 표·원장 필터로 연결한다. 사이트·기간·상태 필터를 유지한다.
- 통합 차이 알림은 실제 불일치 때만 나타난다. 정상 0, 누락, 예정 상태는 색상과 텍스트를 함께 사용한다.
- 운영·수업은 초기 통합 탭 전용. 사이트 탭에서는 지원하지 않는 현황을 0으로 표시하지 않는다.
- ‘동기화’, ‘불만 등록’, 수동 수정은 관련 영역에 배치한다. 핵심 검토 흐름보다 강한 주 버튼으로 강조하지 않는다.
- 그래프의 기준일·단위·비교 범위와 키보드로 접근 가능한 상세 표를 함께 제공한다.

## 3. Delivery Sequence (작업 순서)

| 단계 | 작업 | 산출물 및 종료 기준 |
|---|---|---|
| A 정의 확정 | H/I/Q/P 및 학생·강사·수업 정의, 연도·브랜드 매핑, 원천 우선순위 확정 | 지표 사전·원장 매핑표. 의미가 다른 기존 코드의 교체·호환 정책 포함 |
| B 읽기 전용 대사 | 9/1~9/16 통합·사이트·원장·수동수정·이관 이력 대조 | 방문4,314/상담7/Apply4/불만6 차이의 날짜·출처별 근거. 미해결 항목 별도 유지 |
| C P0 구현 | null·상태·기준일 보존, 예정/실적 분리, 비교 구간, 메타데이터, 차이 표시 | 화면·CSV·API가 같은 정의와 기준일을 사용 |
| D 이관 검수 | 브랜드별 방문자 메모, 월 비용, 상태 현황, 일정·불만 메모를 검수용으로 변환 | 원본 위치와 대사 결과를 가진 이관 미리보기. 승인된 항목만 반영 |
| E P1 화면 | 카드·추이·사이트 비교·상세 표·후속 조치 목록 구현 | 목업 흐름과 필터 연결, 네 언어, 반응형 확인 |
| F 검증·출시 | 기존 기간 호환, 테넌트 격리, 이관 중복·재계산 검증 후 스테이징 확인 | 합의된 수용 기준 충족 및 변경 보고 |

공수는 A/B 이후 산정한다. 차이의 원인과 결제·상담 이벤트의 현재 가용성에 따라 범위가 달라져 지금 확정 일정으로 제시하지 않는다. 화면 개편만 먼저 진행해 정의 불일치를 고정하지 않는다.

## 4. Technical Changes (기술 변경 방향)

| 계층 | 제안 |
|---|---|
| 프론트엔드 | `frontend-acm/src/modules/dsh/`의 페이지·카드·사이트 표 재구성, 추이·상태·원장 상세 연결 추가 |
| API | 기존 range/summary 응답에 지표별 `asOf`, 유효일수, 원천, 완전성, 단위, 비교범위, 예정/실적을 제공. 필드명은 상세 설계에서 확정 |
| 집계 서비스 | `daily-kpi.service.ts`, `monthly-summary.service.ts`에 동일 집계 규칙 적용. null→0 변환, 미래일 포함, 마지막 행=스냅샷 가정 제거 |
| 상담·MAP | MAP 신청·상담 시작·일정 확정·테스트 완료·체험 완료를 해당 이벤트 날짜로 집계. updated_at을 사업 이벤트 시각으로 사용하지 않음 |
| 결제·학생 | 최초 납부 학생과 재학생을 분리. 학생·계약 강사 마스터와 수업 배정 인원을 별도 집계 |
| DB | 기존 `amb_acm_dsh_*` 활용 + 필요 시 기간 비용/이관 근거 저장 구조 추가. `ent_id`·감사 이력·멱등키 필수 |
| 이관 | 원본 시트·셀·메모 위치와 값 보존. 검수용 매핑과 반영용 데이터를 분리. 원본 월 합계와 일별 데이터를 중복 반영하지 않음 |

재계산은 확인된 원천·기간에 한해 적용한다. 기존 전체 수동 오버라이드가 사이트 재계산을 건너뛰게 하는 흐름도 함께 검토한다. 과거 값과 새 정의의 비교에는 지표 정의 버전·전환일을 표시한다.

## 5. Acceptance Criteria (수용 및 검증 기준)

1. **브랜드 대사:** 엑셀 C265:C279 메모를 읽으면 TPI2,069 / TA235 / SC3,533, 합5,837. 일별 값도 모두 일치한다. TA/SC 매핑 확정 전 서비스 코드로 자동 확정하지 않는다.
2. **정의:** MAP 신청은 등록 신청과, 상담 시작은 수업 시작과 분리된다. unrelated 수정으로 신청일별 실적이 이동하지 않는다. 최초 납부는 성공 수납 이력으로 추적된다.
3. **집계 차이:** 통합≠세부합이면 차이와 근거를 표시한다. 잔차를 공통에 숨기거나 이중 추가하지 않는다. 해결된 동일 모집단 가산 지표는 합계가 일치한다.
4. **누락/0/미래:** 9월 비용 공란은 미입력이다. 확정 무지출만 0원. 미래 실적은 —, 미래 예약은 예정에만 표시한다. 모든 지표0인 정상 수집일은 유효일에 포함한다.
5. **기간:** 방문9/15·상담9/16처럼 기준일이 다르면 명시한다. 비율은 겹치는 유효 구간 또는 미집계로 처리한다. 이전값0→양수는 +100%로 표시하지 않는다.
6. **원본 계산:** 1월 신청 이벤트는21+16=37로 산출하며 원본34와 차이3을 기록한다. 5월 일별 합27과 파생26의 차이도 유지한다. 원본 수식 오류40개를 조용히 0으로 바꾸지 않는다.
7. **비용:** 일별 비용이 없는 7월 월비용1,698,435원을 보존한다. 월 조회에서 한 번만 합산하고 부분 기간에는 임의 일할 비용을 실적으로 표시하지 않는다.
8. **예정:** 9/21 MAP1건과 9/22 첫 수업1건이 9/16까지의 완료 실적에 포함되지 않는다. 예약일만으로 완료 상태를 추정하지 않는다.
9. **현황:** 재학생은 기준일 값이다. 월별 일자 합762를 재학생 수로 표시하지 않는다. 마지막 미확정일의0이 이전 확정 현황을 대체하지 않는다.
10. **전환:** 고객 연결 없는 일별 합계로 고유 리드나 미확정 목록을 생성하지 않는다. 추천·신규·복귀 중복 및 선택 관찰기간을 검증한다.
11. **사용성:** 주요 카드 값·단위·비교가 가로 스크롤 없이 보인다. 차트 미수집 구간은 끊기고, 상세 이동 시 기간·사이트가 유지된다. 한국어·영어·베트남어·중국어 표시와 키보드 접근을 확인한다.
12. **안전한 반영:** 테넌트 격리, 동일 이관 재실행 중복0, 원본 보존, 검수 전후 합계 차이를 확인한다. 원장 개인 메모는 접근 권한이 있는 상세 화면에만 노출한다.

## 6. Review Items (검토 사항)

사용자의 ‘진행’ 요청으로 본 계획의 구현 진행 승인을 받았다. 분석서 §7의 구체적인 원천·귀속 정의 중 기존 데이터로 확정할 수 없는 항목은 별도 결정 사항으로 추적한다.

## 7. Implementation Progress (구현 진행, 2026-09-18)

사용자의 ‘진행’ 요청으로 구현에 착수했다. 이번 변경은 단계 C의 조회·표시 개선과 E의 카드 가독성 일부다. 전체 P0/P1 완료 또는 배포 완료를 뜻하지 않는다.

- 완료: 월/기간 공통 집계, 미래·실패·오래된 집계 제외, 지표별 null/0·관측일 평균·마지막 관측일·부분 집계, 달력 월 전월 비교, 기준0 증감 미산출, 사이트 차이·출처 안내, 카드 잘림 제거, 차트 누락 구간, CSV 상태 및 관측일 메타데이터.
- 검증: 대시보드 테스트18개, 프론트·백엔드 빌드 통과. 실제 컴포넌트를 예시 응답으로 렌더링한 로컬 브라우저 확인(기본 화면 및390px). 운영 원장과의 E2E 검증은 미실행.
- 남은 작업: 이벤트 정의·원장 연결(A), 운영 원장 대사(B), 검수 이관(D), 업무 목록 및 전체 화면 개편(E), 스테이징·출시(F), P2(G).
- 데이터 주의: 기존 CS/OPS 비-null 기본0에는 원천의 누락 여부가 보존되지 않는다. 이번 관측일은 저장값과 행 집계 상태 기준이며 실제 수집 완전성 인증이 아니다. 사이트 테이블에는 별도 freshness 상태가 없어 저장된 행 기준이다.
- 원본 엑셀, 운영 DB, 기존 지표 산출 이벤트는 변경하지 않았다. 상세 내용: [구현 보고서](../report/RPT-260918-dsh-actuals-foundation.md).
