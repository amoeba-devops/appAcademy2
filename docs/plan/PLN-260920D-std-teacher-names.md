# Teacher Names Display Plan (담당강사 전체 이름 표시 계획)

## 1. Screen Layout (화면구성도)

```text
학생관리 — 전체 통합 보기
┌───────────┬──────────┬─────────────────────────────┬──────┐
│ 이름      │ 학교     │ 담당강사                    │ 상태 │
├───────────┼──────────┼─────────────────────────────┼──────┤
│ 학생 A    │ …        │ 김효윤                      │ 재원 │
│ 학생 B    │ …        │ 김효윤, 정성경              │ 재원 │
│ 학생 C    │ …        │ 김효윤, 정성경, 김태윤,     │ 재원 │
│           │          │ 김혜린, 공한나              │      │
└───────────┴──────────┴─────────────────────────────┴──────┘
```

예시 이름은 표시 방식 설명용이다. 강사명은 현재 연결 순서대로 쉼표로 구분하고, 폭이 부족하면 줄바꿈한다. 모바일에서도 전체 이름을 유지하며 기존 테이블의 가로 스크롤을 사용한다.

## 2. Implementation (구현)

1. `frontend-acm/src/modules/std/components/std-table.tsx`의 `teacherMore` 분기를 전체 이름 표시로 교체한다.
2. 담당강사 셀의 줄바꿈을 허용하고 말줄임 없이 표시한다.
3. `teachers` 배열이 비었을 때 기존 `teacher` 텍스트 및 미등록 표시를 유지한다.
4. 프론트엔드 빌드와 0/1/2/5명 표시, 긴 이름·모바일·통합/사이트/퇴원 목록 회귀 확인.
5. CI·배포 후 실제 복수 강사 행에서 전체 이름이 보이는지 확인한다.

## 3. Scope and Approval (범위·확인)

DB 및 API 변경 없음. 문제 발생 시 이전 프론트엔드 이미지로 복구한다.
[요구사항](../analysis/REQ-260920D-std-teacher-names.md)과 본 계획을 사용자 확인 후 구현한다(AGENTS.md §9.2).
