# Student Date Save Fix Plan (학생 날짜 저장 수정 계획)

## 1. Implementation (구현안)
- 학생 날짜 수정 시 기존 날짜에 일치하는 재원기간 한 건을 우선 대상으로 한다.
- 일치하지 않지만 취소되지 않은 재원기간이 전체 한 건이면 그 기간을 수정 대상으로 삼아 기본 날짜와 함께 갱신한다.
- 여러 기간으로 대상이 불명확하면 임의 선택하지 않고 409 오류와 개별 재원기간 수정 안내를 제공한다.
- 날짜 역전·기간 겹침을 검사하여 이해 가능한 오류를 반환한다.
- 재원기간 편집 시 기본 날짜와의 동기화를 같은 대상 선정 규칙으로 적용하고 학생 조회 캐시도 갱신한다.
- 기존 migration을 고치지 않고 신규 SQL migration으로 트리거 개선. 강사 분기는 유지하고 취소기간 및 과거 여러 기간의 자동 덮어쓰기는 방지한다.

## 2. UI Layout (화면 구성안)
```text
학생 정보 수정
수업시작일 [YYYY-MM-DD]
수업종료일 [YYYY-MM-DD]
[취소] [저장]

대상이 여러 건인 경우:
수정할 재원기간을 확인할 수 없습니다.
학생 상세의 재원기간에서 해당 기간을 선택해 수정해 주세요.
```
정상적으로 대상이 결정되면 기존 저장 동작을 그대로 제공한다.

## 3. Verification (검증)
PostgreSQL 통합 테스트: 날짜 불일치 + 단일 기간, 일치 기간, 여러 기간 모호성, 취소 기간, 날짜 역전·겹침, 재원기간 역동기화, 강사 기존 동작.
API 오류 코드 및 4개 언어 사용자 안내 검증. 프론트엔드·백엔드 빌드.
운영 데이터 변경 없이 합성 데이터로 검증하고 결과를 보고한다.

## 4. Approval (승인)
