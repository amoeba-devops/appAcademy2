- 대시보드 대상 선택 제거로 '전체 청구' 기준 숫자를 대시보드에서 못 본다 → 월별 납부목록·청구 상세에서 확인 가능.
- 경과일은 납부기한이 없는 청구가 많으면 '—' 가 많다(데이터 문제, 표시만).
