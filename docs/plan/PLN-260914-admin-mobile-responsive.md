# PLN-260914 — 관리자 콘솔 모바일 최적화 / Implementation Plan

## 1. Goal (목표)

`/admin/*` 을 모바일(375px)부터 데스크톱까지 쓸 수 있게 만든다. 사이드바는 아이콘 모드·드로어를 지원하고, 컨텐츠는 미디어쿼리로 대응한다. **기존 데스크톱 레이아웃은 그대로 둔다.**

## 2. Architecture (구성)

```
                   < 768 (mobile)        768~1023 (tablet)      >= 1024 (desktop)
사이드바   오프캔버스 드로어         아이콘 고정 (64px)      펼침 240px ↔ 아이콘 64px
          (헤더 ☰ 로 열기)                                  (사용자 토글, 유지)
헤더      ☰ + ACM + 언어            ACM + 언어              ACM + ⇤ 토글 + 언어
본문      ml-0  p-3                 ml-16 p-4               ml-60/ml-16  p-6

상태: ui.store (zustand + persist)  { sidebarCollapsed: boolean }
      드로어 open 상태는 셸 로컬 state (URL 변경 시 자동 close)
```

- 브레이크포인트는 **Tailwind 기본값**(`md` 768 / `lg` 1024)을 쓰고 커스텀 추가는 하지 않는다.
- 사이드바 폭은 tailwind.config 의 기존 `sidebar: 240px` 옆에 `sidebar-icon: 64px` 를 추가한다.

## 3. Phases (작업 단계)

### P1. 셸 반응형 + 아이콘 모드 (R-1·R-2) — 약 3h

| # | 작업 | 파일 |
|---|---|---|
| P1-1 | `ui.store.ts` 신설 — `sidebarCollapsed` + `toggleSidebar()`, zustand `persist`(키 `acm-ui`) | `stores/ui.store.ts` (신규) |
| P1-2 | `useIsDesktop()` / `useIsMobile()` — `matchMedia` 기반 훅 (SSR 없음, 리스너 정리 포함) | `hooks/use-media-query.ts` (신규) |
| P1-3 | `AppShell` 3-모드 레이아웃 — 드로어(모바일) / 아이콘 고정(태블릿) / 토글(데스크톱) | `components/layout/app-shell.tsx` |
| P1-4 | 사이드바 아이콘 모드 — 라벨 숨김, `title`+`aria-label`, 미읽음 배지 dot 축소, 하단 영역 아이콘화 | 〃 |
| P1-5 | 모바일 드로어 — 헤더 ☰, 오버레이 클릭·ESC·라우트 변경 시 닫힘, `aria-modal`·포커스 트랩 | 〃 |
| P1-6 | 본문 여백·오프셋 반응형 (`ml-*`, `p-*`) | 〃 |

### P2. 공통 프리미티브 (R-3 기반) — 약 2h

| P2-2 | 가로 스크롤 누락 **11개 파일**에 적용 (REQ §2.2 목록) | `modules/{ref,sch,dsh,cls,my,qna,csl}/**` |

### P3. 주요 화면 5종 — 약 3h

| 화면 | 조치 |
|---|---|
| 대시보드 | 기간 프리셋/날짜 입력 `flex-wrap`, KPI 그리드 유지, 하단 표 스크롤 컨테이너, 차트 폭 100% |
| 신규상담 목록 | 필터바 접기(모바일), 테이블 스크롤, 열 우선순위 유지 |
| 신규상담 칸반 | 모바일에서 컬럼 가로 스크롤 + 카드 최소폭 `min-w-[240px]` |
| 수업일정 | 모바일 기본 뷰를 `일/리스트` 로, 월 그리드는 가로 스크롤 |
| 설정(`/admin/config`) | 폼 2열 → 1열, 탭 가로 스크롤 |

### P4. 잔여 화면 점검 — 약 2h

- 나머지 목록/상세 화면을 375·768·1280px 로 훑어 넘침(overflow) 제거
- 체크리스트는 `docs/test/TEST-260914-admin-responsive.md` 로 기록

## 4. UI 구성안 (화면 목업)

### 4.1 모바일 (< 768px) — 드로어 닫힘 / 열림

```
닫힘                                  열림
┌───────────────────────────┐        ┌───────────────────────────┐
│ ☰  ACM              [KO]  │        │ ☰  ACM              [KO]  │
├───────────────────────────┤        ├──────────────┬────────────┤
│ 대시보드                   │        │ ▣ 대시보드    │            │
│ ┌─────────┐ ┌─────────┐   │        │ ▣ 신규상담    │  (오버레이) │
│ │ 방문자   │ │ 신규상담 │   │        │ ▣ 학생       │            │
│ │  1,234  │ │    22   │   │        │ ▣ 학부모      │            │
│ └─────────┘ └─────────┘   │        │ ▣ 반         │            │
│ ┌─────────┐ ┌─────────┐   │        │ ▣ 강사       │            │
│ │ 상담전환 │ │  매출   │   │        │ ▣ 수업일정 ●  │            │
```

### 4.2 데스크톱 — 펼침 ↔ 아이콘 모드

```
펼침 (240px)                              아이콘 모드 (64px)
┌──────────┬──────────────────────┐      ┌────┬───────────────────────────┐
│ ACM   ⇤  │           [KO]       │      │ACM⇥│                    [KO]   │
├──────────┼──────────────────────┤      ├────┼───────────────────────────┤
│▣ 대시보드 │  대시보드              │      │ ▣  │  대시보드                  │
│▣ 신규상담 │  ┌────┐┌────┐┌────┐  │      │ ▣  │  ┌────┐┌────┐┌────┐┌────┐│
│▣ 학생    │  │KPI ││KPI ││KPI │  │      │ ▣  │  │KPI ││KPI ││KPI ││KPI ││
│▣ 학부모   │  └────┘└────┘└────┘  │      │ ▣  │  └────┘└────┘└────┘└────┘│
│▣ 수업일정 │                      │      │ ▣ ●│                           │
│   …      │                      │      │ …  │   (본문 폭 +176px 확보)     │
├──────────┤                      │      ├────┤                           │
│admin@... │                      │      │ ⏻  │                           │
│⏻ 로그아웃 │                      │      └────┴───────────────────────────┘
└──────────┴──────────────────────┘       hover → 툴팁 "수업일정"
```

- 아이콘 모드에서 채팅 미읽음은 숫자 배지 대신 **점(●)** 으로 표시한다.
- 토글 버튼은 헤더 좌측(브랜드 옆)에 둔다 — 사이드바 안에 두면 접었을 때 찾기 어렵다.

### 4.3 표의 모바일 처리 (가로 스크롤)

```
┌───────────────────────────┐
│ No. 학생   유입   단계  →  │   ← 컨테이너 안에서만 가로 스크롤
│ 22  김민   홈피   상담      │      (body 는 스크롤되지 않음)
│ 21  이준   외부   레벨      │
└───────────────────────────┘
```

## 5. Risks (리스크)

| # | 리스크 | 대응 |
|---|---|---|
| R-1 | 화면 수가 많아(142 tsx) 일괄 작업 시 회귀 위험 | P1·P2(공통) → P3(주요) → P4(잔여) 순으로 나누고, 데스크톱 레이아웃 무변경을 기준으로 검증 |
| R-2 | 프리티어 미적용 파일이 많아 diff 가 커질 수 있음 | 포맷 변경 금지, 실제 변경 줄만 수정 |
| R-3 | 자동화 테스트가 없어(frontend 테스트 러너 없음) 수동 확인 의존 | 375/768/1280 체크리스트를 테스트 문서로 남김 |
| R-4 | 칸반·캘린더는 정보 밀도가 높아 모바일 가독성 한계 | 이번엔 넘침 제거까지. IA 재설계는 범위 외 |
