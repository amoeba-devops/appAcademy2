# Admin Mobile Plan (관리자 모바일 개선 계획)

## 1. Priority (진행 순서)
1. 채팅 문제 재현: 방 미선택/선택, 알림 직접 진입, 대화 로딩/실패, 패널 숨김 상태, 모바일 키보드 표시.
2. 채팅: 모바일 방 목록과 대화창 중 하나만 표시. 목록 복귀·참여자 보기 제공, 메시지 영역 독립 스크롤, 입력창 가림 방지. 충돌하는 콘텐츠/viewport 규칙을 통일하고 dvh 및 safe-area 적용.
3. 공통 레이아웃: 메뉴 드로어, 헤더/알림/언어 선택, 페이지 여백, 우측 패널 접기 또는 모바일 시트, 모달 스크롤·하단 버튼·포커스 복귀.
4. 업무 화면: 상담, 학생/학부모/강사/직원, 일정/통계, 수납/대시보드 우선. 검색/필터 줄바꿈, 상세/폼 단일 열, 핵심 작업 버튼 접근성 개선.
5. 나머지 학교/자료/게시글/알림/수강/문항/Q&A/고객불만/설정 화면까지 목록·상세·생성·수정 동선 점검. 가로 폭이 필요한 표·달력은 해당 영역만 스크롤하고 핵심 식별정보를 유지한다.
6. 공유 채팅을 사용하는 강사 포털 및 데스크톱 회귀 확인.

## 2. UI Mockup (화면 구성안)
```text
[☰] ACM             [알림] [언어]
채팅                         [+]
[검색..........................]
[대화방 A          미읽음 3]
[대화방 B                  ]
```
```text
[← 목록] 대화방 A      [참여자] [⋯]
┌────────────────────────────┐
│ 메시지 목록 / 독립 스크롤     │
│                            │
└────────────────────────────┘
[첨부] [메시지 입력........] [전송]
```
```text
공통 업무 화면
[☰] ACM               [알림] [언어]
학생관리                 [등록]
[검색..........................]
[사이트 ▾] [상태 ▾] [필터]
[목록: 핵심 정보 우선 / 필요 시 영역 스크롤]
[이전]                 [다음]
[도움말/상세 패널 열기]
```
참여자는 모바일 시트로 열고, 닫으면 대화 입력 위치로 복귀. 초대/내보내기/제목변경 권한은 기존 정책 유지.

## 3. Acceptance (검증 기준)
- 320/360/390/430px 휴대폰, 768/1024px 태블릿, 1280px 이상 데스크톱.
- 페이지 전체 의도치 않은 가로 스크롤 없음. 표·달력만 의도적 영역 스크롤 허용.
- 방 선택 후 대화/입력창 표시, 목록 복귀, 읽지 않은 메시지/멘션 직접 진입, 참여자/DM/권한 버튼 확인.
- 키보드/세로·가로 회전 시 입력·전송 접근 가능. 터치 버튼 44px 수준 및 포커스·레이블 확인.
- 주요 경로별 목록·검색·상세·모달 접근 점검표와 스크린샷 작성. 합성 데이터로 테스트하며 운영 채팅 메시지는 전송하지 않는다.
- 빌드 및 관련 브라우저 테스트. 실제 iOS Safari/Android Chrome 확인 가능 여부를 보고서에 명시하고 에뮬레이션과 구분한다.

## 4. Delivery (진행)
AGENTS.md 9.2에 따라 분석서·화면 구성안 확인 후 구현. 사용자 승인 후 소스 수정 완료, 운영 미배포. 채팅과 공통 레이아웃을 먼저 검증한 뒤 전체 업무 화면에 적용하고 결과 보고 후 운영 배포한다.
