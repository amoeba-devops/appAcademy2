```
┌ 수업일정 등록 ───────────────────────────────┐

│ ┌──────────────────────────────────────────┐ │
│ │ □ 종일                                   │ │

│ │ → 종료일                                 │ │
│ │ 📅 [2026-11-03] 🕘 [15:30 ▼] [15:40]     │ │
│ │                          · 1시간 30분     │ │
│ └──────────────────────────────────────────┘ │
│ 장소 / 설명 / 화상수업 / 첨부 ...              │
└──────────────────────────────────────────────┘
```

- 직접 입력칸: `<input type="time">` (휴대폰은 기본 시간 선택기, PC는 숫자 입력).

## 3. Result (결과)
- 구현: `cal-event-modal.tsx` (참석자/학생 묶음 이동, `studentTitle()`·자동 제목, 시간 선택 옆 `type="time"` 직접 입력 — 아이콘·선택·입력칸을 한 묶음으로 줄바꿈), i18n 4개 언어(`form.sectionAttendees`, `field.timeManual`, `invitee.titleMore`).
- 로컬 확인(임시 DB):
  - 등록 화면: 학생 2명 → "김민, 김윤", 5명 → "김민, 김윤, 노은 외 2명".
  - 제목을 직접 고친 뒤 학생을 빼도 제목 유지.
  - 시작 시간 직접 입력 16:40 → 선택 목록·소요시간(50분) 반영, 저장 후 DB `16:40`.
  - 수정 화면: 기존 제목 유지(학생 삭제해도 변경 없음).
  - 좁은 화면(폭 513px — 브라우저 최소 폭): 시계·선택·입력칸이 한 묶음으로 다음 줄.
- 직접 입력칸 표시 형식(오전/오후 또는 24시간)은 브라우저·기기 언어 설정을 따른다.
- frontend-acm type-check·build 통과. 서버·DB 변경 없음.
