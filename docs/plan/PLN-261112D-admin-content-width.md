## 3. Risks (위험)
- 넓어지면서 짧은 목록·설정 화면은 카드 안 오른쪽 여백이 커 보일 수 있다 → 입력 영역 768 제한으로 완화.
- 다른 세션이 같은 공통 틀을 수정 중이면 충돌 가능 → 작업 직전 main 재확인.
