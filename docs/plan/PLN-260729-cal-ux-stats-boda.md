## Phase 1 — 캘린더 UX (관리자 1.1 + 강사포털 3)

### 관리자 /admin/cal
- **월간뷰**: 일자 옆 `+N 모두보기` 버튼 → **그날 전체 일정 모달**(목록 → 항목 클릭 시 일정 편집/상세). 날짜 클릭=일정등록(현행 유지). 일정등록화면 강제 노출 문제 해소.
- **리스트뷰**: 피드백/과제를 아이콘 대신 **텍스트 한 줄**(제목 옆) — 예: `16:00 중등수학 A반 · 피드백 · 과제제출 [수업완료]` / 미제출 시 표기 없음, `과제없음` 텍스트.
- **필터**: 수업종류(레벨테스트/데모수업/정규수업/기타) 셀렉트 추가 (백엔드 `category` 파라미터 기구현 — UI만).
- **일/주 보기**: 포털 리스트뷰 UI 참조 — **날짜 그룹 목록형**으로 재구현(카드 그리드 제거).
- **클릭 동작**: 일/주/리스트 = 항목 클릭 시 **바로 상세(편집 모달) 이동** · 월간뷰만 `모두보기` 모달 경유.

### 강사포털 /portal/calendar (3)
- 일/주/리스트 뷰에 **학생 필터**(내 일정의 참석 학생) + **수업종류 필터** 추가.
- 목록 행: 시간/제목 옆 **학생명 노출** + **피드백/과제 텍스트** (아이콘은 월간뷰 전용 유지).
- 일/주/리스트 항목 클릭 → **요약 모달 생략, 바로 상세 페이지**(/portal/calendar/:id). 월간뷰만 기존 유지.

```
[포털·관리자 리스트 행]
16:00  중등수학 A반 · 이서연 | 피드백 · 과제제출  [수업완료]
17:00  수학 클리닉 · 박지호 | 과제없음
```

## Phase 2 — BODA 보완 (1.2 + 1.3)

### 1.2 입·퇴실 기록 이름 매칭 + 강의실 페이지 정보 노출
- **이름 매칭 강화**: `미확인` 원인 = BODA wire userId ↔ ACM 참조 매칭 실패. 기록 조회 SQL에 (a) `bdp_ref_user_id` 매칭(현행) + (b) **undashed uuid 직접 매칭**(`REPLACE(id,'-','')=bdp_boda_user_id`) 추가, 이름이 매칭되면 종류(강사/학생)도 함께 보정.
- **강의실 페이지**(/portal/classroom/:evtId): 강사 등록 **피드백·과제 내용 노출** (열람 규칙은 §확인질문).

### 1.3 즉시강의 입장 불가 수정
- 원인: 즉시강의에 **담당강사 미지정** → 개설 좌석(11) 없는 방은 영구 PENDING → 학생 입장 불가, 운영자는 관전(13) 좌석이라 개설 불가.
- 수정: ① 즉시강의 모달에 **담당강사 선택**(전체 /admin/tch, 필수) 추가 — 지정 강사가 개설. ② **생성 운영자(콘솔 owner)도 개설 가능**하도록 owner 는 강사 좌석(11) 부여 (담당강사 미지정 legacy 이벤트 구제).

## Phase 3 — 수업통계 (2)
- /admin/cal 상단 `삭제한 수업일정 보기` 좌측 **[수업통계]** 버튼 → 통계 화면.
- **기간 선택**(주/월 + 기간 이동) 기준:
  - 전체 요약: 총 수업수 · 수업종류별 수 · 수업완료 수/율 · 총 수업시간

- 백엔드 `GET /acm/cal/stats?from&to` — 이벤트(assigneeTchId·category·시간) + review(classDone) 집계. DB 변경 없음.
