# School Management Plan (학교관리 개선 작업계획)

## 1. Objective (목표)

[요구사항 분석서](../analysis/REQ-260920F-sch-excel-redesign.md)에 따라 학교 기본정보와 대상별 입학전형 정보를 분리하고, 목록에서는 사용자 지정 9개 항목으로 함께 조회한다. 원본의 학교 18개/정보 33행 구조를 보존한다.

## 2. Screen Layouts (화면구성도)

### 2.1 List (학교 목록)

가로 스크롤 전체 열 순서:

```text
학교명 | 구분 | 지역 | 인가여부 | 시험대상 | 시험내용 | 지원자격 | 비고 | 지원일정 | ⋯
```

- 학교명은 sticky 열, 같은 학교의 공통 셀은 학교 단위로 묶고 대상별 행을 표시한다. 페이지 경계에서 같은 학교의 전형이 분리되지 않게 학교 단위 페이지 이동을 적용한다.
- 전형이 없는 학교도 1행 표시한다. 전형 수는 실제 등록 건수로 집계한다.
- 긴 내용은 2~3줄 요약과 `상세보기`로 제공한다. hover만으로 전체 내용을 확인하도록 만들지 않는다.
- 필터 결과 없음/로딩/오류도 흰색 목록 영역 안에 표시한다. 오류에는 재시도를 제공한다.
- 좁은 화면은 본문을 가용 폭으로 줄이고 표 내부 스크롤, 도움말 하단 배치를 사용한다.

- 상자 배경 흰색, 제목은 항목보다 1px 크게/Bold. 대상 미입력 전형은 조회값을 비워 두고 편집 동작의 접근 가능한 이름은 `전형 정보 1`처럼 제공한다.
- 지원일정은 원문이며 날짜 종류/최신성 미확인 안내를 제공한다. 과거 날짜를 현재 모집 상태로 바꾸지 않는다.
- 기존 학년대/정형 일정은 보존하되 새 전형 원문과 자동 동기화하지 않는다. 두 기능의 의미를 설명한다.

## 3. Data and API Design (데이터·API 설계안)

### 3.1 School Master (학교 공통)

`amb_acm_sch_school` 및 Domain/Repository/DTO에 다음을 반영한다.

| UI | 제안 필드 | 규칙 |
| --- | --- | --- |
| 학교명 | name | 기존 ID와 이름 보존, 이름 검증 유지 |
| 구분 | curriculumDescription | 신규 TEXT, DTO 최대 2,000자 |
| 지역 | region | 기존 재사용, 원본 미입력은 덮어쓰지 않음 |
| 인가여부 | isAuthorized | boolean nullable, null=미확인, 신규 기본값 null |
| 지원자격 | eligibility | 신규 TEXT, 최대 10,000자 |
| 비고 | notes | 기존 재사용, 긴 원문을 위해 DTO 최대 10,000자 검토 |

`level`, `isForeign`, `district`는 호환성 때문에 보존한다. 인가 nullable 전환은 SchSchoolPublicService와 참조 모듈의 타입·필터·출력도 함께 변경한다. 기존 boolean 데이터는 보존하고 신규 null을 false로 취급하지 않는다. 기본 폼의 true 자동 선택을 제거한다.

### 3.2 Admission Information (학교별 전형)

신규 `amb_acm_sch_admission_info` 제안:

- `sai_id UUID`, `ent_id UUID`, `sch_id UUID` 학교 FK.
- `target_label TEXT NULL`, `exam_content TEXT NULL`, `schedule_text TEXT NULL`, `sort_order INTEGER`.
- 원본 추적용 `source_file_hash`, `source_sheet`, `source_row`, `import_run_id` (nullable).
- `created_at`, `updated_at`, `deleted_at`; `set_acm_updated_at()` 재사용.
- 테넌트/학교/정렬 인덱스, 동일 import 원본 키에 대한 부분 unique 인덱스. 학교 소속 테넌트가 일치하는 FK 또는 동등한 DB 제약을 마련한다.
- DTO: 시험대상 최대 200자, 시험내용/일정 각각 최대 10,000자. 실제 엑셀 최대 길이를 테스트로 확인하여 잘림 방지.

기존 grade-band 테이블에 시험정보를 억지로 넣지 않는다. 기존 schedule의 날짜 열에 설명 문장을 파싱해 넣지 않는다.

### 3.3 Endpoints (API)

- 기존 학교 CRUD 확장. 기존 소비자가 사용하는 응답 구조를 유지한다.
- 목록 전용 집계 조회: 학교 단위 검색/페이지 이동 후 해당 학교의 전형들을 일괄 조회한다. DB 쿼리는 페이지 학교 수에 비례하여 늘어나지 않도록 한다.
- 학교 상세에서 공통 정보 및 전형 전체 반환.
- 학교 POST/PATCH의 `admissions` 배열로 전형 추가/수정/삭제를 함께 처리한다. 기존 ID는 수정, 신규 항목은 생성, 목록에서 제거된 기존 ID는 soft delete한다. 별도 전형 CRUD 대신 학교+전형을 원자적으로 저장해 부분 저장을 방지한다.
- 학교와 전형 동시 저장은 트랜잭션으로 처리한다. 빈 문자열을 지우는 PATCH와 필드 미전달을 구분한다.
- 기존 인증/역할 정책과 테넌트 격리를 적용한다. 다른 학교/테넌트의 전형 ID로 수정할 수 없어야 한다.

## 4. Initial Data Application (초기 반영 순서)

1. 원본 파일 해시와 셀 좌표를 기록하고 반복 헤더/빈 행을 제외해 18개 학교·33개 정보 행을 파싱한다.
2. 병합된 J열 일정은 정확한 병합 범위에만 확장한다. 학교 공통값은 다음 학교명/구역 경계까지만 적용한다.
3. 같은 테넌트의 학교 ID와 정규화한 이름을 1:1 대조한다. 불일치·다중 후보는 보류하며 기존 학교를 삭제하지 않는다.
4. dry-run 자료에 신규/보강/충돌/변경 없음, 인가 변경 11개, 원본 미기재 7개, 각 학교별 전형 건수를 표시한다.
5. 변경 전 학교/관련 정보 백업을 만든 뒤 검증된 매핑으로 트랜잭션 반영한다. UI 대조상 현재 18개 모두 기존 학교이므로 학교 중복 등록은 없어야 한다.
6. 재실행 시 동일 원본은 중복 생성하지 않는다. 반영 직전 대상 버전/updated_at이 dry-run 이후 바뀌었다면 충돌로 보류한다.
7. 18개 ID 유지, 33개 정보 행, 비인가 11개, 기존 참조 무결성을 사후 조회하여 보고한다. 원본 날짜는 최신 입학일정으로 인증하지 않는다.

## 5. Implementation Sequence (작업 순서)

1. 요구사항·화면구성도 사용자 확인.
2. PG migration, Domain/Repository/DTO/API 구현 및 기존 nullable 소비처 수정.
3. 9개 열 목록, 검색/필터/학교 단위 페이지 이동, 상세 및 등록·수정 화면 구현.
4. 원본 파서/dry-run/재실행 방지·백업·복구 절차 구현.
5. ko/en/vi/zh-CN 번역 및 공통 도움말 학교 전용 문구 추가.
6. 테스트·빌드·CI, 스테이징 migration/동작 확인, 운영 배포와 검증된 원본 데이터 반영.
7. 결과 보고서에 실행 건수·충돌·보존 항목·운영 확인 결과 기록.

## 6. Validation and Recovery (검증·복구)

- 파서: 18개/33행, 반복 헤더, 학교 공통값 경계, 6개 병합 범위, 날짜형 2셀, 빈 시험대상 12행, 빈 시험내용 1행, 줄바꿈·탭 보존 규칙.
- 데이터: 공백을 false/인가로 바꾸지 않음, 11개 비인가 정정, 빈 원본은 기존 값 보존, 같은 원본 2회 실행 후 건수 동일.
- API: 타 테넌트/학교 ID 접근 차단, 필드 삭제 PATCH, 긴 원문, 페이지별 학교 그룹 분리 방지, 트랜잭션 실패 시 부분 저장 없음.
- UI: 9개 열 순서, 전형별 일정 대응, 상세 전체 원문, 검색/필터/빈 결과, 896px 본문, 390px 내부 스크롤, 고정 학교명과 작업 메뉴, 키보드 조작.
- 회귀: 상담/Q&A 학교 검색·참조, 기존 학년대/정형 일정, 삭제 보호, 기존 학교 ID 유지.
- 복구: 배포 전 기존 UI 호환성 확인. 원본 반영 복구는 실행 ID와 변경 전 백업으로 해당 변경만 되돌리고 이후 사용자 수정은 보존한다. DB 열을 즉시 제거하는 down migration은 피한다.
