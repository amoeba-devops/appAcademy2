## 3. Result (결과)
- 등록 `/admin/std/new`·수정 `/admin/std/:id/edit` 전체 페이지(`StdForm`, 하단 고정 저장). 목록 [학생 등록]·상세 [수정]이 페이지로 이동, 저장 후 상세로.
- 수업정보 화면 항목 = 과목·교재·수업링크. 숨긴 값(추가교재·이동수단·GPA·SSAT/ISEE)은 서버가 보낸 항목만 병합해 보존.
- 포털 `GET /api/portal/std/class-info` + 수업일정 아래 **수업 정보** 카드. 포털 토큰 경로 목록(`api-client.ts`)에 `/portal/std` 추가(빠뜨리면 401 → 로그아웃, FIX-260719 와 같은 함정).
- 확인:
  - 통합 테스트 `it-std-class-info-portal` 5건(링크 저장·숨긴 값 보존, 학생 본인만, 학부모 자녀별·타 학생 제외, 강사·타 테넌트 빈 목록, https 검사), acm-std 단위 56건, backend tsc, frontend type-check·build.
  - 로컬 화면(임시 DB): 수정 페이지에서 교재·수업링크 저장 → DB 반영·숨긴 값 유지, https 없는 주소 경고, 상세에 링크 표시, 등록 페이지(사이트 미리 채움) 저장 → 새 학생 상세로 이동, 학생 포털 수업 정보 카드·[수업 입장].
  - 로컬에서 첫 저장 요청이 서버에 닿지 않고 브라우저에서 503(약 20초)으로 끝나는 경우가 있었음. 같은 요청을 curl 로 보내면 즉시 처리되고, 재시도는 성공. 로컬 개발 환경(HTTP/1.1 연결 수 제한 추정) 문제로 보이며 운영(HTTP/2)에서 다시 확인 필요.
  - 학부모 포털 화면·휴대폰 폭은 화면으로 보지 못함(학부모는 통합 테스트로 확인).
