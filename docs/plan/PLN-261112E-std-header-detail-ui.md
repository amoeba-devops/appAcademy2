# PLN-261112E Student list header & detail UI cleanup (학생 관리 헤더 통일·상세 정리)

Related: [REQ-261112E](../analysis/REQ-261112E-std-header-detail-ui.md)

## 1. Screen Layout (화면 구성안)

### 1.1 학생 목록 — 통합·TPI·TA·SC 모두 같은 헤더
```
지금 /admin/std/tpi                         바뀐 뒤 /admin/std/tpi
┌──────────────────────────────────┐        ┌──────────────────────────────────────────┐
│ ← 전체 통합 보기                  │        │ 👤 학생 관리         [엑셀 등록][학생 등록]│
│ 👤 학생 관리   [엑셀 등록][등록]  │        │ 학생 정보를 관리합니다.                   │
│ TPI · 학생 정보를 관리합니다.     │   →    │ 통합 120 │ TPI 52 │ TA 40 │ SC 25 │ 미분류 3│
│ (탭 없음)                         │        │          ▔▔▔▔▔▔ (선택된 탭 = 지금 사이트)  │
├──────────────────────────────────┤        ├──────────────────────────────────────────┤
│ [검색][상태][학교][학년]…         │        │ [검색][상태][학교][학년]…  (그대로)       │
```
- 탭 이동: 통합 → `/admin/std`, TPI → `/admin/std/tpi`, TA → `/admin/std/trinity`, SC → `/admin/std/santa-croce`, 미분류 → `/admin/std?site=UNASSIGNED`. 검색어·상태·학교·학년·강사·기간·표시 개수는 유지, 페이지는 1로.
- 왼쪽 메뉴(통합/TPI/TA/SC/퇴원생)는 지금처럼 유지.

### 1.2 퇴원생 목록 `/admin/std/withdrawn`

┌──────────────────────────────────────────┐

## 2. Style Standard (적용 기준 — 기존 UI-261019 표준 재사용)
| 요소 | 기준 |
|------|------|
| 내용 박스 | 공용 `Section`: 흰 배경, 모서리 8px, 테두리 gray-200, 제목 15px/600, 머리 구분선, 본문 여백 16~20px |
| 박스 안 소제목 | 13px/600 primary |
| 항목명 / 값 | 12px secondary / 14px primary (지금의 `이름 :` 콜론 형식 → 위아래 2줄 형식) |
| 입력·선택 목록 | 높이 36px, 14px, 모서리 6px, 테두리 gray-200, 흰 배경 (`Input` 과 동일). 공용 클래스 `.admin-field` 를 globals.css 에 추가해 select·date 입력에도 같이 씀 |
| 버튼 | 공용 `Button` — 저장=주 버튼, 취소·수정=outline, 작은 버튼 size sm |
| 표 | 공용 머리(회색 바탕 12px/600) |
