# Site Comparison Notice Plan (사이트비교 안내 제거 계획)

## 1. Scope (범위)

[요구사항](../analysis/REQ-260921-dsh-remove-reconcile-notice.md)에 따라 사이트비교 안의 합계 차이 안내 박스 전체를 제거한다.

## 2. Screen Layout (화면구성도)

```text
변경 전                              변경 후
┌ 사이트 비교 ───── 조회 기간 ┐      ┌ 사이트 비교 ───── 조회 기간 ┐
│ ┌ 합계 차이 안내 ────────┐ │      │ 사이트별 수치 및 합계 표    │
│ │ 제목 / 차이 수치 / 설명 │ │      │                            │
│ └───────────────────────┘ │      │ 공통(미지정) 설명           │
│ 사이트별 수치 및 합계 표   │      └────────────────────────────┘
│ 공통(미지정) 설명          │
└───────────────────────────┘
```

안내 박스가 차지하던 높이·여백도 함께 제거한다.

## 3. Implementation and Validation (구현·검증)

1. 계획 확인 후 `SiteComparisonTable`의 합계 차이 안내 JSX를 삭제한다.
2. 해당 안내 전용 `total`, `details`, `differences` 계산을 제거한다. 표의 합계 행 및 조회 API는 유지한다.
3. 관련 번역 키의 다른 참조가 없는지 확인하여 미사용 키를 정리한다.
4. 프론트엔드 타입 검사/빌드와 diff 검토를 수행한다. 단순 표시 제거이므로 신규 단위 테스트는 작성하지 않는다.
5. CI·스테이징·운영 배포 후 지정 URL에서 안내 박스 제거, 표/하단 설명 보존, 불필요한 빈 여백 제거를 확인한다.

## 4. Approval (확인)

2026-09-21 사용자 “진행” 확인으로 구현·검증·배포를 진행한다.
