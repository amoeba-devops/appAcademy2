# Implementation Plan (구현 계획)

## 1. Findings (현재 확인)

`frontend-acm/src/modules/csl/components/class-status-summary-panel.tsx`는 6단계 수강등록과 7단계 수강중에서 공유한다. 수강횟수, 시작일, 종료일을 항상 표시하고 비어 있으면 `—`를 출력한다. 4단계 `enrollment-panel.tsx`는 시작일만 입력하며 수강횟수와 종료일 입력은 이전 요청으로 제거돼 있다. 과거 저장된 종료일은 데이터에 남을 수 있다.

## 2. Scope (변경 범위)

6단계 수강등록에서 수강횟수는 값 존재 여부와 무관하게 행 전체를 숨긴다. 시작일·종료일은 각각 4단계 등록상담의 저장된 값이 있을 때만 행을 표시한다. 두 값 모두 없으면 두 행을 모두 숨기고 `—` 자리표시자를 만들지 않는다. 시작일만 있으면 시작일만 표시한다. 과거 유효한 종료일이 저장되어 있으면 표시한다.

조회용 UI 변경이며 기존 데이터 삭제나 4단계 입력/저장 변경은 하지 않는다. 공유 컴포넌트에서 6단계에 한정해 적용하여 별도 요청 없는 7단계 표시는 유지한다. 수업 스케줄에 따로 표시되는 실제 수업 날짜는 대상이 아니다.

```text
(수강횟수 행 없음 / 날짜 미지정 시 날짜 행 없음)
```

## 4. Implementation and Checks (구현 및 검증)

공유 요약의 stage 조건으로 수강횟수 행을 제거하고 날짜 행은 저장값을 기준으로 조건부 렌더링한다. 값 없음(null/undefined/빈 문자열), 시작일만 존재, 종료일만 존재, 두 날짜 존재, 기존 수강횟수 존재 케이스와 7단계 회귀를 브라우저 fixture로 확인한다. 프런트 빌드를 실행하고 화면 캡처를 보고서에 남긴다. 백엔드 및 DB 변경은 필요하지 않다.
