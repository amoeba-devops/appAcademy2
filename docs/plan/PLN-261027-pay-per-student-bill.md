### 1.2 학생별 청구 등록 대화상자 ([+ 청구] 로 열 때)
```
┌ 청구 등록 — 김하늘 · TPI ─────────────────────────────────────┐
│ 대상 학생: [김하늘 · TPI ×]          (학생 검색 영역 숨김)     │
│                                                                │
│ 청구월 [2026-10]   납기 [2026-10-10]                           │
│ 수업   [▼ 김하늘 수강 수업만: 중2 영어A / 중2 수학B / 없음]    │
│ 항목   [▼ 수업료 | 교재비 | 재료비 | 차량비 | 기타]            │
│ 제목   [11월 교재비            ]  메모 [          ]            │
│ 청구액 [ 35,000]   할인 [     0]                               │
│ ⚠ 할인이 청구액보다 큽니다.            (입력 오류 시 즉시 안내) │
│                                                                │
│ 미리보기: 김하늘 · 35,000 · 등록 가능                          │
│                             [미리보기] [등록 확정] [닫기]      │
```

- 상단 [청구 등록] 버튼은 기존과 동일(여러 학생 검색·추가). 단, 미리보기에서 문제 행은
  `김하늘 · 수강하지 않는 수업` 처럼 사유 표시 후 제외, 나머지만 등록.

양식(xlsx) — 시트 `청구` (회색 = 수정 금지), 샘플: `docs/design/samples/pay-bill-import-sample.xlsx`:
```
| 학생명(회색) | 지점(회색) | 청구월  | 납기       | 항목   | 수업      | 제목        | 청구액 | 할인 | 메모 | 수강 수업(참고·회색) | 학생ID(회색) |
| 김하늘       | TPI        | 2026-11 | 2026-11-10 | 수업료 | 중2 영어A | 11월 수업료 |        |    0 |      | 중2 영어A            | 3f2a…        |
```
- 항목 열은 드롭다운(현재 언어 라벨), 수업 열은 `안내` 시트 수업 목록 드롭다운. 청구월·납기 열은 텍스트 서식(엑셀 날짜 자동 변환 방지, 날짜로 입력돼도 해석).
- 청구월·납기·항목(CLASS)·제목(`{월}월 수업료`)·수업(수강 수업이 1개면 자동) 미리 채움, 청구액은 빈칸.
- 시트 `안내`: 항목 코드(CLASS 수업료 / BOOK 교재비 / MATERIAL 재료비 / TRANSPORT 차량비 / OTHER 기타), 수업 목록, 작성 규칙.
- 한 학생에 여러 청구(수업료+교재비)는 행을 복사해 추가.

## 3. Verification (검증)
- 로컬(빈 DB + sql/acm 전체): 미수강 수업 선택 → 400 없이 사유 표시, 학생별 [+ 청구] → 등록·목록 반영, 다중 학생 등록 회귀.
- 엑셀: 양식 다운로드 → 금액 입력 → 업로드 → 정상/제외/건너뜀 판정 → 등록 → 재업로드 시 전부 '이미 같은 청구 있음'.
- 마이그레이션 없음.

## 4. Result (결과) — 2026-10-27
- 통합 테스트 `it-pay-bill-per-student` 5건 통과(미수강·금액·없는 학생 사유, create 400 유지, 학생별 수업 필터, import-data 지점·테넌트 격리, 재업로드 중복).
