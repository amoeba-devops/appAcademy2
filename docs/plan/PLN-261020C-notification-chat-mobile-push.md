# Notification — Mobile Chat Push & Inbox Header Plan (작업 계획)

요구사항: [REQ-261020C](../analysis/REQ-261020C-notification-chat-mobile-push.md)

## 1. UI Mockup (화면 구성안)

현재:
```
┌───────────────────────────────┐
│ 알림                        ✕ │
│ [알림 설정]                    │  ← 한 줄 차지
│ [전체] [안 읽음]     [모두 읽음] │
│ ● 상담 상태가 변경되었습니다 …   │
```

변경 후 (이 기기 알림 꺼짐):
```
┌───────────────────────────────────────┐
│ 알림                                ✕ │
│ ┌───────────────────────────────────┐ │
│ │ 🔔 이 기기에서 알림 받기       [켜기] │ │  ← 꺼져 있을 때만
│ └───────────────────────────────────┘ │
│ [전체] [안 읽음]       [모두 읽음] [⚙] │  ← 한 줄 (⚙ = 알림 설정)
│ ● 채팅에서 나를 멘션했습니다  [멘션]    │
│   김선생 · 수학팀           09:12      │
│ ● 새 채팅                             │
│   운영팀                    09:10      │
│ ● 상담 상태가 변경되었습니다            │
│   #145 · 4. 등록 상담 → 5. 결제        │
│ ─────────────────────────────────────│
│            [전체 알림 보기]             │
└───────────────────────────────────────┘
```
- 켜기 안내는 켜져 있으면 숨김. 차단된 기기는 "브라우저 설정에서 알림을 허용하세요", iOS Safari 탭은 "홈 화면에 추가한 앱에서 켜세요".
- ⚙ 버튼은 아이콘 + 접근성 이름 "알림 설정", 누르면 지금의 알림 설정 창.
- 전체 알림 페이지(`/admin/notification-inbox`)도 같은 머리 줄(⚙ 포함).

휴대폰 푸시 (잠금 화면):
```
ACM
김선생님이 나를 멘션했습니다 · 수학팀
```

## 2. Work Packages (작업 단위)

| WP | 내용 | 파일 |

| WP1 | 알림 창 머리 한 줄 + ⚙ 아이콘, 전체 페이지에도 ⚙ | `frontend-acm/src/modules/notifications/components-inbox.tsx` |
| WP2 | 켜기 안내 배너(상태: 꺼짐/차단/미지원/iOS 브라우저) — 기존 `PushSettings` 구독 로직 재사용 | `push-settings.tsx`, `components-inbox.tsx` |

## 3. Notes (참고)

- 운영 DB·서버 설정 변경 없음(VAPID 키는 이미 설정됨). DB 마이그레이션 없음.
- 기존 구독은 0건이라 전환 영향 없음. 배포 후 사용자 안내: "알림 창에서 [켜기] 한 번".
