# PLN-261027 Login session length setting (로그인 유지 시간 설정)

## 1. Requirement (요구사항)
1. "로그인유지 기능 - 로그인시 로그인유지 기능 체크하면 48시간 유지"
2. "서비스설정에 로그인유지 시간 설정 기능 구현 - 관리자가 시간단위로 설정가능 최대 48시간. ama 연동은 사용하지 않을 계획이므로 고려하지 않는다. 모바일은 로그인 지속 유지"

## 2. As-Is (현황)
- 토큰 유지 시간은 발급 시 결정: PC·브라우저 **4시간**, 설치한 앱(PWA) **8시간** (REQ-261019B, `session-client.ts` `sessionSignOptions()`, env).
- 화면은 토큰 만료 시각(`exp`)에 맞춰 자동 로그아웃·안내(`session-expiry.tsx`).
- 학원(테넌트) 설정은 `amb_acm_tenant`(예: `tnt_timezone`). 콘솔 로그인은 계정으로, 포털 로그인은 학원코드로 학원을 알 수 있다.
- 서버 세션이 없어 발급한 토큰은 만료 전 강제 폐기 불가(감사 P3 예정). 관리자 잠금은 다음 요청부터 즉시 거부.

## 5. Design (설계)
- DB `sql/acm/1053`: `amb_acm_tenant.tnt_session_hours SMALLINT NULL CHECK (1..48)` (NULL = 기본 4).
- API `GET/PUT /api/acm/config/session` (ConfigAdminGuard). 로그인 화면은 로그인 전이라 학원을 몰라 시간 숫자 없이 "로그인 유지" 만 표시.
- 토큰 유지 시간 결정(`sessionSignOptions(ctx)`):
  - 모바일(설치한 앱 `X-ACM-Client: pwa` 또는 휴대폰 브라우저 User-Agent) → **30일**, 그리고 앱을 쓸 때마다 `POST /api/acm/auth/refresh`(·portal) 로 새 30일 토큰 → 사실상 계속 로그인
  - PC·브라우저 + 로그인 유지 체크 → 학원 설정 시간(1~48)
  - PC·브라우저 + 체크 안 함 → 4시간(기존)
- refresh: 유효한 토큰으로만, 계정 활성·잠금 아님 확인 후 같은 규칙으로 재발급(모바일만). 화면은 열 때·하루 1회 이상 호출.
- 로그아웃·관리자 잠금은 지금처럼 동작.
