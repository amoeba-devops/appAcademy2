- [학생 선택해 청구]: 기존 청구 등록 창(학생 검색·여러 명 추가)을 목록 도구줄에서 연다. 행별 [+ 청구]는 학생 고정 창.
- [변경 저장]: **행마다 한 건씩** 요청(행별 실패 사유를 받기 위해 — `PATCH batch` 는 한 건이라도 실패하면 전체 롤백). 신규는 `batch-create`(제목 `{월}월 수업료`·기본 납기·수강 수업 1개면 자동), 기존은 `PATCH batch`(사유 `목록 직접 입력`, 초안은 납기 없으면 기본 납기로 확정). 제목·사유는 화면 언어로 저장.
- 도구줄은 스크롤해도 보이도록 고정(sticky). 입력값은 검색·필터·페이지를 바꿔도 유지되고, 월·사이트·탭 이동 시에만 확인 후 버림.
