# 테넌트별 메뉴 노출 설정 매뉴얼 (교사 관리 숨기기)

> 특정 학원(테넌트)의 **관리자 사이드바**에서 `교사 관리`(`/admin/tch`) 같은 메뉴를 켜고 끄는 방법.
> **APP_ADMIN 전용** — 시스템 어드민에서 설정한다.

---

## 0. 접속 주소 (앱어드민)

| 용도 | URL |
|------|-----|
| 로그인 | `https://acm.amoeba.site/admin/login` (계정 `admin@amoeba.group`, 권한 `APP_ADMIN`) |
| 사용자 관리 | `https://acm.amoeba.site/system/admin` |
| **테넌트 관리 (메뉴 노출 설정)** | `https://acm.amoeba.site/system/tenants` |

- 로그인 후 좌측 사이드바 **하단 "시스템 관리"** 링크로도 진입(APP_ADMIN에게만 보임).
- ⚠️ 임시 비밀번호 계정이면 첫 로그인 시 `/admin/change-password` 강제 변경 화면이 먼저 나온다.
- ⚠️ **APP_ADMIN 전용**. 일반 학원 ADMIN은 자기 메뉴를 끌 수 없다.

---

## 1. 로그인 → 좌측 하단 "시스템 관리"

관리 콘솔 로그인 후 사이드바 **맨 아래**의 **시스템 관리** 클릭.

```
┌─ acm.amoeba.site/admin/dashboard ───────────────┐
│ ACM                                              │
│ ┌────────────┐                                  │
│ │▣ 대시보드   │   (관리 콘솔)                    │
│ │  신규 상담  │                                  │
│ │  학생 관리  │                                  │
│ │  교사 관리  │                                  │
│ │  수업일정   │                                  │
│ │  설정       │                                  │
│ ├────────────┤                                  │
│ │▶ 시스템 관리│ ← 클릭 (APP_ADMIN만 노출)        │
│ │ admin@amoeba.group                             │
│ │ ↪ 로그아웃  │                                  │
│ └────────────┘                                  │
└──────────────────────────────────────────────────┘
```

## 2. 테넌트 관리 → 대상 학원 선택

시스템 어드민(상단 짙은 헤더 + **시스템** 배지) → 좌측 **테넌트 관리** → 학원 행 클릭.

```
┌─ acm.amoeba.site/system/tenants ────────────────────────┐
│ ACM [시스템]                                             │
│ ┌────────────┐  테넌트 관리                              │
│ │ 사용자 관리 │  이름            ent_id    상태   사용자수 │
│ │▣ 테넌트 관리│  Trinity Academy →…0001   ACTIVE   12  ◀─ 클릭
│ │            │  System          …00ff   ACTIVE    1     │
│ │↩ 관리 콘솔로│                                          │
│ └────────────┘                                          │
└──────────────────────────────────────────────────────────┘
```

## 3. "메뉴 노출"에서 교사 관리 끄기 → 저장

테넌트 상세 하단 **메뉴 노출** 섹션에서 **교사 관리** 체크 해제 → **저장**.
(`대시보드`는 항상 노출 — 토글 불가)

```
┌─ /system/tenants/…0001 ── 메뉴 노출 ─────────────────────┐
│ 켜진 메뉴만 해당 테넌트 관리자 사이드바에 표시(데이터 권한 무관) │
│ ┌─────────┐┌─────────┐┌─────────┐                       │
│ │☑ 대시보드 ││☑ 신규상담 ││☑ 학생관리│  (항상)             │
│ │☑ 학부모  ││☑ 수업관리 ││☐ 교사관리│ ◀── 체크 해제(대상)  │
│ │☑ 직원관리 ││☑ 수업일정 ││☑ 학교    │                    │
│ │☑ 참조자료 ││☑ MAP기출 ││☑ 설정    │                    │
│ └─────────┘└─────────┘└─────────┘            [ 저장 ] ◀─ │
└──────────────────────────────────────────────────────────┘
```
- 다시 켜려면 체크 후 저장.

## 4. 결과 — 해당 학원 사이드바에서 교사 관리 사라짐

저장 후 그 테넌트 사용자가 관리 콘솔을 **새로고침/재로그인**하면 사이드바에서 `교사 관리`가 빠진다.

```
변경 전 사이드바          변경 후 사이드바
 대시보드                 대시보드
 신규 상담                신규 상담
 학생 관리                학생 관리
 교사 관리   ──────────▶  (없음)
 수업일정                 수업일정
 설정                     설정
```

## 5. 동작 원리 / 주의

- 사이드바는 로그인 사용자의 테넌트 노출 설정(`GET /acm/me/menus`)을 받아 필터링한다.
- **UI 숨김만** — 백엔드 데이터 권한·테넌트 격리는 그대로다. 메뉴를 꺼도 `/admin/tch` 로 직접 접근하면 화면은 열린다(메뉴에서만 숨김).
- 설정값은 **행이 없으면 기본=노출**(하위호환). 끈 메뉴만 override로 저장된다.
- 반영 시점: 새로고침/재로그인 시(메뉴 응답 캐시 약 5분). 로딩/오류 시에는 **전체 노출(fail-open)**.
- 토글 대상: `대시보드` 제외 전 메뉴(신규 상담·학생·학부모·수업·**교사**·직원·수업일정·학교·참조·게시글·알림·수강신청·MAP·Q&A·설정).

## 6. 자주 묻는 문제

| 증상 | 원인 / 해결 |
|------|-------------|
| "시스템 관리" 링크가 안 보임 | APP_ADMIN 권한 아님. `admin@amoeba.group`(APP_ADMIN)으로 로그인 |
| 끈 메뉴가 여전히 보임 | 새로고침/재로그인 필요(캐시 ~5분). 또는 다른 테넌트 사용자로 확인 중인지 점검 |
| 메뉴를 꺼도 URL로 들어가짐 | 정상 — UI 숨김 기능(권한 차단 아님). 하드 차단이 필요하면 별도 작업 |
| 대시보드가 토글 안 됨 | 코어 메뉴라 항상 노출(의도된 동작) |
