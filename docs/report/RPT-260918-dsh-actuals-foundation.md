# Dashboard Actuals Foundation (대시보드 조회 집계 개선)

## 1. Changes (변경 내용)

미래일과 누락을 실제0으로 해석하고 전체 날짜로 평균을 나누던 조회 로직을 공통 집계 함수로 교체했다. 월별 표·기간별 표·요약 카드가 같은 규칙을 사용한다.

- Asia/Seoul 기준 미래 날짜, PARTIAL_FUTURE, FRESH가 아닌 행은 실적 집계에서 제외한다. 과거 원본 행은 보존한다.
- 지표별 값이 null/공란이면 평균 분모에서 제외하고 실제0은 포함한다. 숫자가 하나도 없으면 합계·평균 모두 null이다.
- `coverage`에 지표별 관측일수, 대상일수, 마지막 관측일과 MISSING/PARTIAL/AVAILABLE을 반환한다. `AVAILABLE`은 저장된 값 존재 기준이지 외부 원천의 완전성 검증 결과가 아니다.
- 학생·강사 현황은 마지막 사용 가능한 관측값을 사용한다. 수집 모집단 자체의 불일치는 이번 수정으로 해결되지 않는다.
- 완료 달은 전월 전체, 진행 중인 달은 전월 같은 경과일까지 비교한다. 월말 일수는 전월 말일로 제한한다. 월 단위가 아닌 사용자 범위는 동일 길이 직전 구간을 사용한다. 비교 날짜를 화면에 표시한다.
- 누락 있는 구간의 증감률과 이전값0의 증감률은 계산하지 않는다.
- 사이트 표는 미입력 비용·없는 사이트 행을 null로 보존한다. TOTAL과 알려진 사이트 값의 차이를 표시하고 미분류·공통에 자동 가산하지 않는다.
- GA4 배지는 전체 지표 출처가 아니라 GA4 수집 내역임을 명시한다.
- 카드 표의420px 최소폭을 제거하고 1열/2열로 배치한다. 누락 구간은 차트 선을 끊는다.
- CSV는 미래·사용 불가 행의 실적 값을 비우고 집계 상태, 관측일수, 마지막 관측일 메타데이터를 제공한다. 값과 API상의 null을 함께 보존한다.
- 한국어·영어·베트남어·중국어 문구를 추가했다.

## 3. Remaining Work (남은 작업)

본 변경은 개선계획 전체의 첫 구현 단위다. 아래 항목은 구현·배포 완료로 보고하지 않는다.

1. MAP 신청 원장은 `amb_acm_csl_map_apply.mpa_submitted_at`에 접수시각이 존재한다. 기존 등록 기반 `cs_apply`를 변경하려면 과거 이관값과 새 정의의 적용 구간 및 원천 변경 이력을 함께 정해야 한다.
2. 상담 시작·최초 납부·재학생·계약 강사 정의는 현재 집계와 다르다. 신규0을 실제 성과로 확정하지 않도록 정의 안내를 표시했으나 해당 원장 매핑은 미구현이다.
3. 운영의 방문자4,314 등 차이의 실제 DB 행·수동 수정 이력 대사는 미실행이다. 화면에서 잔차를 설명할 수 있도록 표시만 추가했다.
4. 기간 비용 원장, 브랜드 메모 이관, 후속 업무 목록, 고유 리드·코호트 및6개 핵심 카드 개편은 남아 있다.
5. `FRESH`는 재계산 상태다. 원천별 수집 성공·지연을 증명하는 상태 모델은 추가 설계가 필요하다. 사이트 테이블에는 대응 상태가 없다.
6. 기존 CS/OPS의 non-null 기본0은 누락과0을 소급 구별하지 못한다. 과거 완료/예정이 혼합된 MAP 수치도 이번 조회 수정만으로 복원되지 않는다.
