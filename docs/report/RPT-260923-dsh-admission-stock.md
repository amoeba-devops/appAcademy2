# Admission-based Student Count Report (학생수 입학일 기준 변경 결과)

## 1. Result (결과)

[승인 요구사항·화면 구성](../plan/PLN-260923-dsh-admission-stock.md)에 따라 운영 학생수와 기초잔액의 최초 반영일을 수업시작일에서 입학일로 변경했다. 산식 버전은 `operating-admission-stock-v3`. UI 학생수 제목도 한국어·영어·베트남어·중국어로 변경했다.

운영 원본의 날짜/수기값 변경은 없다. 다음은 **운영 데이터 스냅샷을 변경된 코드로 계산한 검증값**이며, 아직 운영 앱 배포 결과는 아니다.

| 날짜 | 기존 통합 | 변경 통합 | TPI | TA | SC | 신규학생 |
|---|---:|---:|---:|---:|---:|---:|
| 2026-09-21 | 48 | 48 | 31 | 3 | 14 | 0 |
| 2026-09-22 | 50 | 51 | 34 | 3 | 14 | 3 |
| 2026-09-23 | 51 | 51 | 34 | 3 | 14 | 0 |

22일 입학·23일 수업시작인 학생을 22일부터 반영한다. 재입학 공백은 유지하고 동일 학생의 겹친 기간은 중복 집계하지 않는다. 확인된 기존 기간 중 중복 이력이 있어 최초 입학 누적에서 모든 퇴원 이벤트를 단순 차감하지 않는다. 해당 원본 이력 수정은 수행하지 않았다.
