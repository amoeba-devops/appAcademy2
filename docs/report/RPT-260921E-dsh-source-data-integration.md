## 2. Released Slice (이번 구현 범위)

- `GET /api/acm/dsh/source-current`: JWT tenant 기준, 동일 SQL 스냅샷에서 현재 STD/TCH/N:M 배정 조회. 개인정보·계정 정보 없음.
- 통합 대시보드에 **원장 현재 현황** 별도 패널: 재원 학생/재직 강사/배정 학생/배정 강사, 조회 시각, 기간 실적과 다르다는 설명.
- 날짜 누락 건수와 과거 이력 제한을 접이식 영역에 표시.
- 백그라운드 탭 polling은 중지, 활성 화면 5초/재진입·포커스·수동 새로고침 갱신. 캐시 키에 tenant/user 포함. 이관·직접 SQL 후에도 다음 조회에 반영.
- 조회 실패 시 과거값을 최신값/0처럼 표시하지 않음. 기존 통계 API/표/CSV/수동 입력/사이트 탭은 변경하지 않음.
- 전체 P1~P4 완료가 아니다. 기존 기간 지표를 새 정의로 전환하거나 이력·새 사건일 필드를 추가하지 않았다.

### 2.1 Adjustment after Audit (대사 후 적용 범위 조정)

승인 계획의 G0/G2에 따라 기간 지표 전환은 보류한다. 현재값은 역사적 집계로 전환하지 않는 독립 읽기 전용 추가이므로 기존값 복원·outbox·이력 백필이 필요 없다. 모든 입력 경로는 다음 DB 조회로 포괄한다. 이 조치는 이력/갱신 게이트를 통과한 것으로 간주하지 않으며 이후 **기간 지표 전환**에는 원래 계획의 게이트를 그대로 적용한다.

## 3. Validation (검증)

- 프론트 및 백엔드 빌드 통과.
- 대시보드 단위 테스트 6 suites / 20 tests 통과.
- 실제 PostgreSQL 격리 테스트 5개 통과: 다중 배정 중복 제거, 휴원/삭제/비강사 제외, 테넌트 격리/고아 관계, 직접 수정·복구, 빈 테넌트 0.
- 구현 SQL을 운영에서 읽기 전용 실행: 58 / 14 / 47 / 12 일치. EXPLAIN ANALYZE 1회 실행시간 2.799ms. 이는 부하테스트/p95 결과는 아니다.
- API는 기존 대시보드 인증·테넌트 guard를 재사용. 기존 원장 편집 경로 및 DB 스키마 변경 없음.
- 배포 및 운영 UI 확인: 진행 중.

## 4. Remaining Gates (남은 작업)

- CS 신청·완료체험·시작과 실제 수업 원장에 과거 실적이 없어 기존 이관값을 원장 실적으로 전환할 수 없다. 현재 원장 0행을 과거 실적 0으로 간주하지 않는다.
- 신규/퇴직·과거 인원은 날짜 및 상태·배정 이력 기반이 필요하다. 날짜 입력 UI·상태 이력·갱신 기반·신구 버전 집계는 후속 구현 대상이다.
- 기간 산식 전환·Class 단위/코드 변경·드릴다운·v2 CSV·사이트 CS와 효과 동시 전환은 미완료다.
- 기존 수동값/원장은 보존했으며 신규 추정 날짜를 채우지 않았다. 필요한 날짜·과거 원천을 확보한 지표만 후속 게이트를 통과시킨다.
