# 강사용 가이드 — BODA 화상 수업 진행

> 이 문서는 **강사 본인** 이 사용할 실전 가이드입니다. 운영자 설정·기술 세부 사항은 [전체 매뉴얼](./MANUAL-260610-boda-classroom-user-flow.md) 을 참고해 주세요.

---

## 1. 두 가지 흐름

| 상황 | 흐름 | 적합한 경우 |
|---|---|---|
| **A. 즉시 강의 개설** | 캘린더 없이 지금 바로 시작 | 갑작스러운 1:1 / 보충 / 질문 응대 / 짧은 시연 |
| **B. 일정 등록 후 시작** | 캘린더에 미리 등록한 수업을 시간 맞춰 시작 | 정규 수업 / 다수 학생 / 시간표 공유 필요 |

> 어느 흐름이든 학생에게 알림이 자동 전송되고, BODA 강의실은 데스크톱 앱이 자동 실행됩니다.

---

## 2. 사전 준비 (1회만 확인)

- ✅ 학원 운영자가 BODA 연동을 등록한 상태인지 확인 (`/admin/config` BODA 섹션이 `설정 완료 ✅` 로 표시)
- ✅ **BODA 데스크톱 앱** 이 본인 컴퓨터에 설치되어 있는지 확인 (운영자 안내 메일 / 학원 홈페이지에서 다운로드)
- ✅ **로그인 정보** 확인:
  - 운영 환경: `https://acm.amoeba.site/admin/login`
  - 학원 운영자가 발급한 강사 계정 이메일·비밀번호

> 첫 수업 5분 전, BODA 앱이 미리 실행 중인지 확인하면 시작 지연이 없습니다.

---

## 3. 흐름 A — 즉시 강의 개설 ⚡

### 3-A-1. 진입
1. 강사 계정으로 `https://acm.amoeba.site/admin/login` 로그인.
2. 좌측 메뉴 또는 직접 URL `/admin/cal` 으로 캘린더 진입.
3. 우측 상단의 **`⚡ 즉시 강의 개설`** 버튼 클릭 (강사·운영자에게만 보임).

### 3-A-2. 모달 입력 (3 가지만)

```
┌──────────────────────────────────────────────────────────┐
│ ⚡ 즉시 강의 개설                                  [X]  │
├──────────────────────────────────────────────────────────┤
│ 제목 (선택)                                              │
│ ┌────────────────────────────────────────────────────┐   │
│ │ 즉시 강의 - 김교사 14:30        (자동 채워짐)      │   │
│ └────────────────────────────────────────────────────┘   │
│                                                          │
│ 예상 시간    ( ) 30분  ( ) 60분  (●) 90분  ( ) 120분    │
│                                                          │
│ 학생 초대             🔍 [검색...........]              │
│ ┌────────────────────────────────────────────────────┐   │
│ │ ☑ 박학생 (중3-A)   ☑ 이학생 (중3-A)               │   │
│ │ ☐ 김학생 (중3-B)   ☐ 최학생 (중2-A)               │   │
│ │ ...                                                │   │
│ │ 선택됨: 2명                                        │   │
│ └────────────────────────────────────────────────────┘   │
│                                                          │
│ ℹ️ 강의 시작 시 학생에게 즉시 알림이 전송됩니다           │
│                                                          │
│                            [취소]   [강의 시작 ⚡]      │
└──────────────────────────────────────────────────────────┘
```

| 필드 | 입력 가이드 |
|---|---|
| **제목** | 비워두면 `"즉시 강의 - {본인 이름} HH:mm"` 자동 생성. 보충 주제·차수 등 명시 권장. |
| **예상 시간** | 기본 90분. 짧은 1:1 보충은 30~60분, 그룹 시연은 120분 권장. 종료 시각은 자동 계산. |
| **학생 초대** | 본인이 담당하는 클래스 학생이 추천됩니다 (CLASS 라벨). 최근 7일 내 함께 수업한 학생은 "최근" 라벨로 표시. 체크박스 다중 선택. 0명도 가능 (시연·테스트). |

### 3-A-3. 강의 시작
1. **`강의 시작 ⚡`** 버튼 클릭.
2. **새 탭** 이 열리고 약 2~3 초 후 본인 컴퓨터의 **BODA 데스크톱 앱이 자동 실행** 됩니다.
3. 동시에 초대한 학생들에게 알림(메일·AmoebaTalk)이 발송됩니다 — 학생이 알림 링크를 누르면 곧바로 강의실로 입장 가능.

> 새 탭에 "강의를 자동으로 시작합니다…" 메시지가 잠깐 보인 후 BODA 앱이 뜹니다. 5초가 지나도 앱이 안 뜨면 [§5 자주 발생하는 문제](#5-자주-발생하는-문제) 참고.

### 3-A-4. 수업 진행 (BODA 앱 내부)
- BODA 앱에서 평소처럼 강의 (화면 공유 / 칠판 / 채팅 등) 진행.
- 학생이 입장하면 자동으로 명단에 추가됩니다 (출결 기록도 자동).
- 종료 시 **BODA 앱의 `수업 종료`** 버튼 클릭.
- 화상 강의실은 자동으로 정리됩니다 — 강사가 종료를 못 하고 떠나도 종료 예정 시각 + 10~15분 후 시스템이 자동 마무리.

### 3-A-5. 종료 후 확인
- 캘린더 (`/admin/cal`) 에서 방금 만든 일정을 클릭 → **BODA 화상 강의실** 패널의 상태가 `폐쇄됨` 으로 표시되면 정상 마무리.
- **출결 재동기화** 버튼을 누르면 BODA 측 출결 데이터를 다시 가져와 보정합니다.

## 4. 흐름 B — 일정 등록 후 수업 시작

### 4-B-1. 일정 등록 (수업 며칠 전)
1. `/admin/cal` 진입 → 원하는 날짜 셀 클릭 (또는 우측 상단 **`+ 일정 등록`** 클릭).
2. 일정 등록 다이얼로그에서 다음 입력:

| 항목 | 입력 |
|---|---|
| 제목 | 예: `중3 영어 - 비교급/최상급` (필수) |
| 분류 | **수업** 선택 |
| 시작 / 종료 | 예: `2026-06-15 19:00 ~ 20:30` (필수) |
| 종일 토글 | (체크 안함 — 화상 수업은 시간 지정 필수) |
| 장소 | (선택, 오프라인 병행 시만) |
| 설명 | 예: "비교급 보충 강의 — 학습지 §3 참고" (학생에게 노출됨) |
| **화상 미팅** | **`보다스쿨` 선택** |
| 미팅 URL | **비워두기** — 저장 시 시스템이 자동으로 채웁니다 |
| 참석자 | 학생 검색 → 다중 선택 |

3. **저장** 클릭.
4. 학생들에게 알림 메일이 즉시 발송됩니다.

> 💡 다른 화상 도구 (Google Meet 등) 선택 시에만 미팅 URL 직접 입력 필요. BODA 선택 시 자동 발급.

### 4-B-2. 수업 시간이 되면 — 강의 시작
1. 시작 시각 **10분 전** 부터 입장 가능 (운영자 정책에 따라 조정 가능).
2. 캘린더에서 해당 일정 클릭 → **`BODA 화상 강의실`** 패널의 **`수업 시작 →`** 링크 클릭 (또는 알림 메일의 입장 링크).
3. 새 탭의 런처 페이지에서 **`강의실 입장 (강사)`** 버튼 클릭.
4. 본인 컴퓨터의 BODA 데스크톱 앱이 실행됩니다.

> 흐름 A 와 달리 자동 실행은 되지 않습니다 — 버튼을 한 번 누르면 BODA 앱이 뜹니다 (학생들은 강사 입장 전까지 대기 화면 표시).

### 4-B-3. 학생 입장 흐름 (참고)
- 학생/학부모는 알림 메일의 링크, 또는 본인 시간표 (`/my/timetable`) 에서 수업 클릭.
- 강사가 아직 입장 전이면 **"강사 입장 대기 중"** 화면 (10초마다 자동 새로고침).
- 강사 입장 후 학생 화면이 자동 갱신되어 **`수업 입장`** 버튼 활성화 → 학생이 클릭 시 BODA 앱에서 입장.

### 4-B-4. 수업 중 / 종료
- 흐름 A 의 [§3-A-4](#3-a-4-수업-진행-boda-앱-내부) 와 동일.
- 종료 후 캘린더 일정에서 상태 확인 가능.

## 5. 자주 발생하는 문제

| 증상 | 원인 / 대응 |
|---|---|
| `강의 시작` 클릭했는데 새 탭이 안 열림 | 브라우저 팝업 차단 — 주소창 우측의 차단 아이콘 클릭 → "이 사이트에서 팝업 허용". |
| 새 탭은 떴는데 BODA 앱이 안 뜸 | BODA 데스크톱 앱 미설치 / 미실행. 에러 카드의 "설치 안내" 링크 클릭. 앱 실행 후 페이지 새로고침. |
| `보다스쿨 스크립트 응답이 늦습니다` | 네트워크 일시 장애. 1~2분 후 재시도. 지속 시 학원 운영자에게 알림. |
| `입장 가능 시간이 아닙니다` | 시작 10분 전 / 종료 15분 후 범위 밖. 일정 시간 확인. |
| 학생이 알림을 못 받았다고 함 | 일정 다이얼로그 하단의 **알림 결과** 확인 — `SKIPPED (이메일 없음)` 면 학생 프로필에 이메일 등록 필요. |
| 출결이 비어 보임 | 캘린더 일정 → **BODA 화상 강의실** 패널의 **`출결 재동기화`** 버튼 클릭. 자동 보정도 종료 후 10~15분 내 동작. |
| 룸이 안 닫히고 멈춰 있음 | 운영자에게 요청 — 캘린더 일정의 **`강제 폐쇄`** 버튼으로 해결 가능. |

## 6. 즉시 vs 일정 등록 빠른 비교

| 항목 | 즉시 강의 (A) | 일정 등록 (B) |
|---|---|---|
| 클릭 수 | 약 3-step | 약 8-step |
| 시간 입력 | 자동 (지금 ~ 지금+90분 등) | 수동 (시작·종료 입력) |
| 학생 검색 | 추천 12명 + 검색 (예정) | 전체 검색 |
| 강의실 자동 실행 | ✅ 새 탭이 BODA 앱 자동 호출 | 버튼 1회 클릭 필요 |
| 캘린더 아이콘 | ⚡ | (없음) |
| 학생 알림 | 시작 클릭 즉시 | 일정 저장 즉시 |
| 시간표 공유 | 수업 후에만 표시 | 등록 즉시 학생 시간표에 노출 |

## 7. 체크리스트 (수업 직전 1분 점검)

- [ ] BODA 데스크톱 앱 실행 중인가?
- [ ] 마이크 / 카메라 / 화면 공유 권한 허용되어 있는가?
- [ ] 학생 명단이 맞는가 (캘린더 일정의 참석자 목록 확인)?
- [ ] (오프라인 병행 시) 장소 / 자료 준비 완료?
- [ ] 알림이 학생에게 정상 발송되었는가 (일정 모달 알림 결과)?

---

## 8. 빠른 참조 카드 (인쇄용 한 줄 요약)

> **즉시 수업**: `/admin/cal` → `⚡ 즉시 강의 개설` → 학생 체크 → `강의 시작` → BODA 앱 자동 실행
>
> **정규 수업**: `/admin/cal` → 날짜 클릭 → 시간·제목·학생 입력 → 화상 미팅=보다스쿨 → 저장 → 시간 되면 일정 클릭 → `수업 시작`

---

## 9. 도움 요청

- 학원 운영자: 학원 내부 헬프데스크 / 운영팀 연락처
- BODA 앱 설치·기술 문제: 학원이 안내한 설치 가이드 / 보다에듀 고객지원
- 시스템 장애 (다른 강사도 동일 증상): 학원 운영자 → `dev@amoeba.group`
