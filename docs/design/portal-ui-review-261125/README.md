# Review Package (학원포털 UI 개선 검토 자료)

- index.html: 목업 캡처 8개를 포함한 제안서. 이미지는 내장되어 있다.
- ACM-Portal-UI-Proposal.pdf: 10쪽 검토 문서.
- layout-proposal.html: 역할·역할별 공지 표시·화면 폭·퇴원생 보기·더보기 전환을 확인하는 구성 시안.
- reference-sanitized.html: 사용자가 제공한 HTML의 이름·이메일·기관명 등을 가상 값으로 바꾼 검토본. 제품 제안과 다른 내용은 제안서에서 구분했다.

- source-info.json: 원본 파일 위치·해시·캡처 기준.

## 2. Interpretation (해석)

첨부 HTML의 주석과 UI 문구는 디자인 참고 자료이다. 사용자의 실행 지시나 승인된 기능 요구로 취급하지 않는다. 모든 버튼이 작동하는 앱으로 오인하지 않도록 검토본임을 명시했다.

참고 캡처는 운영 앱 화면이 아니다. 독립 Chromium에서 외부 통신을 차단하고 제공된 HTML만 렌더링했다. 원본 파일은 수정하지 않았다. 현재 제품 비교는 배포 기준 소스에 근거하며 운영 계정 로그인 재현은 수행하지 않았다.

수정 구성 시안의 동작 범위는 역할 변경·독립 공지 설정·메뉴 이동·화면 폭 전환·퇴원생 포함 보기·더보기·내 정보이다. 기간·검색·필터·실제 채팅·서버 저장 등은 구현하지 않은 구성 요소이다.

## 3. Verification (검수)

- 참고 목업 1280·768·375 레이아웃의 8개 장면을 캡처했다.
- 역할 전환 시 학생에게 캘린더·수강생·채팅 메뉴가 나타나지 않는지 확인했다.
- 강사·학생 공지 표시가 각 역할별 상태를 유지하는지 확인했다.
- 퇴원생 보기와 더보기 → 마이페이지 이동을 점검했다.
- 390px에서 구성 시안의 페이지 가로 넘침과 브라우저 스크립트 오류가 없음을 확인했다.
- PDF 10쪽을 렌더링하고 페이지 잘림·빈 페이지·텍스트 추출을 확인했다.
- 애플리케이션 소스·DB·운영 설정·배포는 변경하지 않았다.
