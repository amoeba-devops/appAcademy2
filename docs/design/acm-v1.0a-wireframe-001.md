## 20. UI Conventions (전체 공통)

- **Empty state**: 화면 중앙 일러스트 + "지금 등록하세요" CTA
- **Loading**: skeleton (TanStack Query `isLoading`)
- **Error**: toast (sonner) + inline form (RHF `errors`)
- **Confirmation**: 파괴적 액션은 modal 2-step (예: "삭제 확정")
- **Empty Korean tag display**: `[빈 태그]` placeholder
- **Date display**: KST `YYYY-MM-DD HH:mm`, relative `3일 전` (date-fns ko-KR)
- **Number formatting**: `.toLocaleString('ko-KR')`
- **Bilingual labels**: 라벨은 한국어 우선, 툴팁에 영문(`@/i18n/en`)
