# Teacher Class Information Requirements (강사별 수업정보 요구사항)

## 1. Request (요청)

대상: `/admin/std/:id` 학생 상세. 사용자 지정 화면을 실제 조회하여 확인했다.

1. 한 학생의 담당강사 1명마다 수업정보 1개를 연결한다.
2. 페이지 배경과 정보 박스를 구분하고 박스 내부를 흰색으로 표시한다.
3. 기존 제목 13px/Bold와 `항목 : 값` 형식을 유지한다. 미입력 실제 값은 비워두고, 조회 화면은 `입력필요`, 입력창은 `입력하세요`를 회색 이탤릭 플레이스홀더로 표시한다. 안내 문구를 데이터 값으로 저장하지 않는다.

## 2. Findings (현황)

- `amb_acm_std_student_teacher`는 학생↔강사 복수 연결 및 순서만 저장한다. 동일 학생·강사 중복 연결은 유니크 제약으로 방지한다.
- 수업정보는 학생에 단일 값으로 저장된다. 상세에서는 강사 이름을 쉼표로 합치고 과목·교재 등을 한 번만 표시하여 강사별 수업을 구분할 수 없다.
- 지정 화면에는 강사 1명, 교재와 추가교재가 입력되어 있다. 박스의 계산된 배경색은 투명이다.
- 상세의 수업정보: 담당강사, 과목, 교재(`curriculum`), 추가교재(`materials`), 이동수단, GPA, SSAT/ISEE.
- 현재 수정 폼은 추가교재·SSAT/ISEE 입력이 빠져 있어 새 강사별 폼에 함께 제공해야 한다.
- 기존 강사 동기화는 연결 행 전체를 삭제 후 생성한다. 그 행에 직접 수업정보를 붙이거나 삭제 전파를 적용하면 정보가 소실될 위험이 있다.

## 3. Functional Requirements (기능 요구사항)

| ID | 요구사항 |
| --- | --- |
| F01 | 학생 A–강사 X 조합마다 현재 수업정보 1개. 강사 X가 다른 학생을 맡는 것은 별도 정보이며 허용한다. |
| F02 | 강사 N명을 선택하면 N개의 독립 수업 카드/편집 그룹을 제공한다. 같은 강사를 중복 선택할 수 없다. 기존 최대 5명 규칙을 유지한다. |
| F03 | 과목·교재·추가교재·이동수단·GPA·SSAT/ISEE를 각 강사 카드에서 저장·조회한다. 학생 기본 인적사항·MAP 점수·학생 공통 메모는 기존 위치를 유지한다. |
| F04 | 강사 추가 시 빈 수업정보를 생성한다. 순서 변경은 내용에 영향을 주지 않는다. 담당강사 해제 시 수업정보를 보존하고 재연결 시 복원한다. |
| F05 | 담당강사가 없으면 강사 연결 안내를 표시하며, 가짜 강사 카드를 만들지 않는다. 기존 공통 수업정보는 별도 연결 대기 영역에 보존한다. |
| F06 | 기존 실제 강사 연결이 정확히 1명일 때만 기존 단일 정보를 그 강사와 연결한다. 복수/미연결/텍스트 이름만 있는 경우 자동 복제·이름 추정 연결 없이 연결 대기로 보존한다. |
| F07 | 등록/수정 저장 시 강사 연결과 수업정보를 함께 검증하고 트랜잭션으로 처리한다. 다른 강사 카드의 값이 덮어써지지 않는다. |
| F08 | 상세의 기본 인적사항·원본 행정정보(노출 시)·MAP·강사별 수업·메모·포털 계정·학부모 정보 박스 내부를 흰색으로 통일한다. 페이지는 옅은 회색으로 구분한다. |

| F09 | 학생 상세와 등록/수정의 미입력 항목은 실제 값을 비워둔다. 조회는 `입력필요` 안내, 텍스트 입력창은 `입력하세요` placeholder를 회색 이탤릭으로 표시하고 값 입력 시 사라진다. 실제 입력값은 기존 일반 글꼴·본문 색상을 사용한다. 날짜·선택형은 기본 형식/미선택 안내를 유지하며 유효한 값을 넣어 빈칸을 대신하지 않는다. |

## 4. Compatibility and Data (호환·데이터)

- 조회 범위와 수정 권한, 테넌트 격리, 강사 포털의 담당학생 접근 기준을 유지한다.
- 기존 공통 정보와 엑셀 원본 기록을 삭제하거나 임의 수정하지 않는다. 다중 강사 학생의 원본 값은 운영자가 카드별로 배정할 때만 새 정보로 반영한다.
- 기존 수업일정·출결·결제의 수업 단위를 변경하는 요구가 아니다. 이 기능은 학생 상세의 강사별 수업 프로필이다.
- 기존 학생 상태·소속 사이트·학부모 관계는 변경하지 않는다.

## 5. Acceptance (완료 기준)

강사 2명에게 서로 다른 교재를 저장하고 새로고침해도 각각 유지된다. 순서 변경/담당 해제/재연결 시 정보가 올바르게 보존된다. 단일 강사의 기존 값은 손실 없이 표시되고, 다중 강사의 공통 값은 잘못 복제되지 않는다. 모든 정보 박스는 흰색으로 페이지와 구별되며 모바일에서도 카드별 연결을 이해할 수 있다.
