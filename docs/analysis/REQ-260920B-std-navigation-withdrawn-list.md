# Student Navigation and Withdrawn List (학생관리 메뉴·퇴원 목록 분리)

## 1. Request (요청)

학생관리 아래 TPI, Trinity Academy, Santa Croce, 퇴원 네 하위 메뉴를 구성한다. 퇴원생은 별도 목록에서 관리하고, 학생관리의 ‘퇴원생 엑셀 업로드’ 버튼을 제거한다. 요청의 ‘Triity Academy’는 기존 사이트 정식 표기인 ‘Trinity Academy’로 통일한다.

추가 요청: TPI·Trinity Academy·Santa Croce 하위 메뉴와 함께 **3개 사이트 전체 통합 보기**를 유지한다. 상위 학생관리를 누르면 통합 목록을 열고, 사이트 하위 메뉴에서는 해당 사이트만 조회한다. 기존 퇴원 전용 목록 분리 요구는 유지한다.

## 2. Current Behavior (현재 동작)

- `app-shell.tsx`에는 학생관리 단일 메뉴만 있으며 학부모 관리는 별도 메뉴이다.
- `/admin/std`의 사이트 탭과 상태 필터가 한 화면에서 재원·휴원·퇴원을 모두 조회한다.
- 퇴원 상태 선택 시 퇴원일·사유 열을 표시하지만 독립 메뉴/경로는 없다.
- 현재 화면에는 ‘퇴원생 엑셀 업로드’, 일반 ‘엑셀 업로드’, ‘학생 등록’ 버튼이 있다.
- `/admin/std/:id` 상세 화면을 공통으로 사용한다. 상세의 목록 복귀 경로 검증은 기존 `/admin/std?…` 형태를 기준으로 하므로 신규 하위 경로 지원이 필요하다.

## 4. List Rules (목록 구분)

- 상위 통합 화면은 요약 카드만 제공하는 화면이 아니라 기존 학생 목록 기능을 유지하는 전체 통합 목록이다. 사이트별 화면에는 ‘전체 통합 보기’ 링크를 제공한다. 통합 범위에는 기존 미분류 학생도 포함한다.
- 사이트별 목록과 상위 현재 학생 목록은 ACTIVE/INACTIVE만 조회한다. ‘전체’는 현재 학생 전체를 의미하며 퇴원생을 포함하지 않는다.
- 퇴원 목록은 WITHDRAWN만 조회한다. URL의 상태 값을 바꿔도 현재 학생을 이 목록에 섞지 않는다.
- 메뉴 이동은 학생 상태나 소속 사이트를 변경하지 않는다. 기존 학생 편집/상태 변경이 있을 때만 해당 목록의 소속 결과가 달라진다.
- 퇴원 목록에서는 사이트 필터로 미분류까지 조회한다. 사이트별 현재 학생 화면은 사이트 탭을 반복 노출하지 않는다.
- 일반 학생 엑셀 업로드는 기존 사이트/현재 학생 화면에서 유지한다. 퇴원 목록에는 엑셀 업로드 버튼을 노출하지 않는다.
- 기존 원본 정보·퇴원 이력·암호화 감사와 학생 상세 편집은 유지한다. 버튼 제거는 데이터 삭제나 과거 이력 삭제를 의미하지 않는다.
- 이전 명부의 보류 36명 연결 승인과 기존 재원/휴원 상태 변경은 별도 미결 사항이다. 이번 화면 변경 승인으로 데이터 연결/상태 변경 승인을 추정하지 않는다.

## 5. Scope and Approval (범위·확인)

새 메뉴·목록 구성과 버튼 제거가 이번 추가 구현 범위다. 화면구성도와 상세 작업 순서는 [작업계획서](../plan/PLN-260920B-std-navigation-withdrawn-list.md)를 따른다. AGENTS.md 9.2에 따라 요구사항·계획 확인 후 구현한다.

2026-09-20 사용자 “진행”으로 v1.1.0 구성의 구현·배포 승인. 기존 명부 보류 36명의 연결 및 상태 변경은 이번 승인 범위에 포함하지 않는다.
