# Admin UI Consistency Requirements (관리자 UI 통일 요구사항)

## 1. Request (요청)

1. 대시보드를 제외한 관리자 화면의 콘텐츠/목록 가로 폭을 수업통계 화면 기준으로 통일한다.
2. 콘텐츠 오른쪽에 팁 또는 배너용 패널을 추가한다.
3. 목록 주변 배경은 회색, 목록 표면은 흰색으로 통일한다.

## 2. Findings (확인 사항)

- 운영 `/admin/cal-stats` 실측 콘텐츠 폭 및 computed max-width: **896px**. 소스의 `max-w-4xl`과 일치한다.
- `AppShell`은 좌측 내비게이션과 본문 여백만 관리하고 `Outlet`을 직접 출력한다. 공통 콘텐츠 폭/우측 패널이 없다.
- 학생 상세는 `max-w-3xl`, 일부 설정은 `max-w-2xl`, 통계는 `max-w-4xl`, 여러 목록은 가용 폭 전체를 사용하여 폭이 다르다.
- 일부 목록 컨테이너는 흰색 배경이 지정되지 않아 회색 페이지 배경이 비친다.
- 표준 토큰은 `bg-canvas`(현재 #fafafa), `bg-surface`(#ffffff), 공통 테두리 `--border-subtle`을 이미 제공한다.

## 3. Scope (적용 범위)

`AppShell` 아래 인증된 `/admin/*` 업무 화면의 목록·상세·등록/편집·설정에 적용한다. 수업통계 자신도 같은 본문 폭에 우측 패널을 추가한다.

- 상담/접수, 학생(통합·사이트·퇴원·상세), 학부모, 교사, 직원, 수업/일정, 수업통계, MAP, 학교/기준정보, 게시글, 알림, 수강등록, Q&A, 채팅, 설정.
- **대시보드 `/admin/dashboard`는 본문 폭·패널·표면 변경 모두 제외한다.** `/admin` 및 `/admin/`의 대시보드 이동 동작도 유지한다.
- 별도 레이아웃의 로그인/비밀번호 변경, `/system`, `/my`, `/portal`, 공개 홈페이지는 제외한다.
- 모달·팝오버의 폭은 본문 폭 통일 대상이 아니다. 기존 입력과 선택 기능을 유지한다.

## 4. Requirements (요구사항)

| ID | 요구사항 |
| --- | --- |
| F01 | 공통 본문은 가용 폭 100%, 최대 896px로 통일한다. 제목·검색·목록·상세 박스의 좌우 기준선을 맞춘다. |
| F02 | 본문 옆에 256px 팁/배너 패널, 간격 24px를 둔다. 896px는 패널 포함 전체가 아닌 본문 자체의 기준이다. |
| F03 | 실제 콘텐츠 가용 폭이 1176px 이상일 때 두 열을 사용한다. 그보다 좁으면 본문 아래에 보조 패널을 배치하고 본문은 min(가용 폭, 896px)을 사용한다. |
| F04 | 관리자 공통 배경은 회색, 목록 본문·정보 카드·보조 패널은 흰색으로 통일한다. 기존 선택/hover/상태색은 유지한다. |
| F05 | 목록 헤더는 연한 회색, 데이터 행은 흰색을 기본으로 한다. 로딩·빈 결과·오류도 동일한 흰색 목록 영역 안에 표시한다. |
| F06 | 팁은 현재 페이지와 관련된 짧은 사용 안내를 제공한다. 제공된 배너가 없으면 팁을 표시하며 빈 광고 박스나 임의 광고를 노출하지 않는다. |
| F07 | 넓은 표는 표 컨테이너 안에서 가로 스크롤한다. 페이지 전체 가로 넘침, 우측 패널 겹침, 강사명/필수 열 숨김을 방지한다. |
| F08 | 달력·채팅·편집기의 높이/내부 스크롤과 입력 상태를 보존하면서 외부 폭 기준을 맞춘다. 우측 패널 때문에 기능이 가려지지 않아야 한다. |
| F09 | 사이드바 펼침/접힘·모바일 드로어 변화에도 실제 콘텐츠 폭에 따라 재배치한다. 읽기 순서는 본문 → 보조 패널이다. |

## 5. Assumptions and Acceptance (설계 가정·완료 기준)

- 우측 패널 256px와 간격 24px는 승인 대상 제안값이다. 이번 범위는 영역과 기본 팁 제공이며 배너 업로드 CMS·광고 추적·외부 광고 연동은 포함하지 않는다.
- 기능·데이터·권한·라우팅은 유지하며 공통 외형을 정리한다.
- 충분한 화면 폭에서 모든 대상 화면의 본문이 896px로 일치하고 우측 패널이 표시된다. 작은 화면에서는 표 내부 스크롤과 패널의 하단 배치가 정상이어야 한다.
- 대시보드 기존 4개 패널 배치와 그래프가 유지되어야 한다.
