# REQ-261112E Student list header & detail UI cleanup (학생 관리 상단 헤더 통일·상세 화면 정리)

## 1. Request (요청)
1. `/admin/std` 와 `/admin/std/tpi` 등 사이트별 페이지의 우측 콘텐츠 상단 헤더를 동일하게 사용한다.
2. 사이트별 페이지 상단의 `← 전체 통합 보기` 를 삭제하고, 전체 목록의 `통합 / TPI / TA / SC / 미분류` 탭을 모든 페이지에 배치한다.
3. 학생 상세(`/admin/std/{id}`) 콘텐츠 영역 UI 최적화·정리
   - 내용 박스 배경을 흰색으로 통일
   - 박스 안 중간 제목·소제목·항목 크기 등 스타일 통일
   - 선택 목록(select) 글자 크기 등 다른 페이지 기준과 통일
