## 3. Requirements (요구사항)
| ID | 내용 |
|----|------|
| FR-1 | 필터 바를 스크롤 시 상단 고정. 기준 토글 `청구월 기준`(기본)·`실제 수납일 기준`, 오른쪽에 `KRW · 갱신 YYYY-MM-DD HH:mm`, [새로고침]은 통계·월별 두 조회를 함께 다시 불러온다. 기준 선택은 URL `basis=bill|paid` 로 유지. |
| FR-2 | 데이터 품질 배너 `DataQualityBanner`: 기간 확인 필요 인원(`reviewCount`) 또는 이력 불완전이 있을 때만 표시. 한 줄 요약 + 펼침 상세(월별 확인 필요·확인된 휴원·퇴원) + [학생 정보에서 확인 →]. 원생현황 카드 안의 경고 박스는 제거. |
| FR-3 | 상단 통계 3종은 그대로, 섹션 머리에 [통계 접기 ▴ / 펼치기 ▾]. |
| FR-4 | KPI 5개 (같은 폭, 좁은 화면 2~3열). <br>청구월 기준: 순청구액 · 누적 순수납액 · 현재 미납액(미납 N명, 0 초과 시 빨강) · 수납률(진행바) · 전월 순청구. <br>실제 수납일 기준: 당월 납부 · 당월 환불·취소 · 당월 순수납 · 전월 순수납 · 전전월 순수납. <br>클릭 시: 미납 → 월별 납부목록(미납), 나머지 → 월별 납부목록. |
| FR-5 | 청구 진행 퍼널 6칸(월 재원생·청구 미등록·금액수정·확정 청구·미납·기간 확인 필요), 처리할 일(미등록 > 0)은 빨강, 기간 확인은 주황. 칸 클릭 → 해당 상태 목록. 옆에 [+ 학생 선택해 청구 (미등록 N명)]. 대시보드의 대상 선택은 없애고 '해당 월 재원생' 고정. |
| FR-6 | 12개월 추이: 월별 순청구(보라)·순수납(초록) 묶음 막대 SVG, 선택 월 강조, 막대에 금액 툴팁. 데이터 없는 달은 빈 칸. |
| FR-7 | 사이트별 비교 표: 재원생·순청구액·미납액·순수납·수납률(순청구>0일 때) + 합계 행, 숫자 오른쪽 정렬·천 단위, 사이트명 클릭 → 그 사이트로 필터. |
| FR-8 | 미납 상위 10명: 학생(학생 상세 링크)·사이트·미납금·경과일·[보기]. 경과일 = 오늘(학원 타임존) − 가장 오래된 미납 청구의 납부기한, 기한 없으면 '—'. 없으면 "✓ 미납 학생이 없습니다 · {월} · {사이트}". 서버 `MonthlyRow.oldestUnpaidDue` 추가. |
| FR-9 | i18n 4개 언어, 차트·표 다크/모바일(390px) 깨짐 없음. |

## 4. Non-goals (범위 밖)
- 목업 하단 API 제안(`GET /pay/summary` 통합)은 하지 않는다 — 기존 `statistics`·`monthly` 두 조회로 충분.
- 월별 납부목록·청구 상세 탭은 변경 없음.
