# REQ-260921B — 상담 등록 개선: 학년 자유입력 · 생년월일 · 튜터링/맵테스트 구분 / Intake form: free-text grade, birthdate, consultation kind

## 1. Requirement (요구사항 — 사용자 원문)

> `/admin/csl` 신규상담등록시
> - 학년입력 — 셀렉트리스트에서 input box 로 변경
> - 생년월일 입력란 추가
> - Map Test 통합되어 생년월일 항목 필요
> - 튜터링상담 / 맵테스트 구분자도 필요
> 개선해야할 부분 검토하고 요구사항 정리

## 2. As-Is (현행 — 2026-09-21 코드·프로덕션 실측)

### 2.1 학년 — 콘솔은 코드 셀렉트, 웹 접수는 자유 텍스트 → 한 컬럼에 두 체계가 섞여 있다

| 경로 | 입력 방식 | 저장값 예 |
|---|---|---|
| 콘솔 신규 상담 ([csl-create-dialog.tsx](../../frontend-acm/src/modules/csl/components/csl-create-dialog.tsx)) | `<select>` 13종 코드 `E1~E6 / M1~M3 / H1~H3 / OTHER` | `M2` |
| 아임웹 `/contact2` 상담 접수 · `/test2` 맵테스트 접수 | 자유 텍스트 (REQ-260916 Q4 "해외 학년 표기 대응") | `G10`, `6학년`, `예비고1`, `kinder` |

- 컬럼 `amb_acm_csl_inquiry.grade` **VARCHAR(10)**, DTO `@MaxLength(10)`. 프로덕션 71건 중 코드값은 **0건**, 전부 자유 텍스트다. `G2 (현재 유치원` 처럼 **10자에서 잘린 값**이 실제로 존재한다.
- 목록·상세는 `t('grade.'+값, 값)` 으로 코드면 라벨, 아니면 원문을 보여 이미 자유 텍스트를 수용한다.
- 자동 학생 등록(수강 등록 시)은 `grade` 를 학생 `std_grade`(VARCHAR 20) 로 복사한다 ([csl-enrollment-registration.service.ts:157](../../backend/src/modules/acm-csl/application/csl-enrollment-registration.service.ts#L157)).

### 2.2 생년월일 — 맵테스트 부속 테이블에만 있다

| 위치 | 컬럼 | 비고 |
|---|---|---|
| `amb_acm_csl_map_apply` (맵테스트 신청 1:1 부속) | `mpa_birthdate DATE` + `mpa_birthdate_raw` | `/test2` 접수·`/admin/test` 상세에서만 입력·표시 |
| `amb_acm_csl_inquiry` (상담 본체) | **없음** | 콘솔 신규 상담·`/contact2` 상담에는 생년월일 자체가 없음 |
| `amb_acm_std_student` | `std_birth_date DATE` | 자동 학생 등록 시 **복사되지 않음** (상담에 값이 없으므로) |

### 2.3 구분 — "튜터링 상담 vs 맵테스트" 를 나타내는 명시 필드가 없다

현재는 세 가지 간접 신호뿐이다.

| 신호 | 값 | 한계 |
|---|---|---|
| `inq_apply_type` | `COUNSELING_ONLY / EXAM_ONLY / BOTH` (상담만/시험만/상담+시험) | "시험" = 맵테스트라는 보장이 없고, 콘솔에서 자유롭게 고른다 |
| `amb_acm_csl_map_apply` 행 존재 | `/test2` 접수건만 | 콘솔에서 맵테스트 상담을 등록하면 부속 행이 없어 `/admin/test` 목록에 안 나온다 |
| `inq_apply_purpose` 에 `MAP_TEST_TUTORING` 포함 | 다중 선택 | 목적이지 구분자가 아님 |

프로덕션 71건: 맵테스트 접수(`EXAM_ONLY`+부속행) **67**, 웹 상담 **3**, 콘솔 상담 **1**. `/admin/csl` 목록에는 71건이 구분 없이 섞여 보인다.

### 2.4 그 밖에 검토에서 드러난 개선점

| # | 항목 | 내용 |
|---|---|---|
| I-1 | 학년 컬럼 길이 | VARCHAR(10) → 실데이터 잘림 발생. **40자**로 확장 + DTO 상한 동일 조정 (외부 접수 DTO 포함) |
| I-2 | 학년 코드 잔존 호환 | 과거 코드값(`E1`…)이 들어올 수 있으므로 표시 폴백(라벨) 유지. 편집 시 input 에 라벨을 채워 준다 |
| I-3 | 생년월일 이원화 | 상담 본체에 `inq_birthdate` 를 두고 맵테스트 부속 `mpa_birthdate` 와 **동일 값 유지**(부속은 원문 `raw` 보존용). 기존 67건은 부속 → 본체로 백필 |
| I-4 | 학생 자동 등록 | 상담 생년월일을 `std_birth_date` 로 복사 (지금은 빈 채로 생성됨) |
| I-5 | 콘솔 맵테스트 등록의 `/admin/test` 노출 | 구분=맵테스트로 콘솔 등록 시 부속 행도 생성해 `/admin/test` 목록·상세와 일관되게 |
| I-6 | 상세 페이지 | 인테이크 패널 표시 항목에 생년월일·구분 추가. 인라인 편집 대상은 현재 메모류뿐이므로 학년·생년월일 편집은 상세의 기본정보 수정 경로(§4 Q-3) |
| I-7 | 목록·필터 | 목록에 구분 배지 열, 필터에 구분 셀렉트 추가. CSV 내보내기에 생년월일·구분 포함 |

## 5. Acceptance Criteria (인수 조건)

- **AC-1** 신규 상담 폼에서 학년을 자유 텍스트로 입력·저장하며 40자까지 잘리지 않는다. 기존 코드값 상담은 라벨로 계속 표시된다.
- **AC-2** 신규 상담 폼에 생년월일이 있고 저장·목록·상세·CSV 에 표시된다.
- **AC-3** 신규 상담 폼 최상단에서 튜터링 상담 / 맵테스트를 고를 수 있고, 목록 배지·필터·상세 헤더에 구분이 보인다.
- **AC-4** 웹 접수건은 구분이 자동 부여되고, 기존 71건은 백필 규칙대로 구분·생년월일이 채워진다.
- **AC-5** 맵테스트 구분으로 콘솔 등록한 건이 `/admin/test` 목록에 나타난다.
- **AC-6** 수강 등록으로 자동 생성되는 학생에 생년월일이 복사된다.
- **AC-7** 신규 문자열 4 locale.
