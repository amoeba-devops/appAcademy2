# REQ-261102 Monthly list quick amount & paid-in-full (월별 납부목록 청구액 입력·완납)

## 1. Request (요청)
`/admin/pay?month=2026-09&site=ALL&view=monthly`
1. 사이트 — 미지정 제외.
2. 월별 납부목록에서 바로 청구 작성/수정 — 청구액만 간단히 입력.
3. 상태가 미청구/미납일 때 [완납] 버튼 — 누르면 바로 처리.

## 2. Decisions (결정, 2026-11-02 — 사용자 답변)
| # | 질문 | 결정 |
|---|------|------|
| Q1 | 미지정 제외 범위 | '전체 사이트' 목록·합계·대시보드에서 사이트 없는 학생·청구 제외(전체 = TPI·Trinity·Santa Croce 합) |
| Q2 | 미청구 [완납] | 미청구는 **청구액 입력**(청구 생성), 청구된 미납·부분납의 [완납]은 남은 미납액을 수납 완료로 기록 |
| Q3 | 완납 수납 기본값 | 납부일=오늘, 결제수단=계좌이체 미리 채움, 바꿀 수 있음 |
| Q4 | 대상 월 | 모든 달(월별 목록은 더 이상 조회 전용 아님) |

## 3. Requirements (요구사항)
| ID | 내용 |
|----|------|
| FR-1 | `siteMatches('ALL')` = 사이트 있는 기록만. 사이트별 표에서 '미지정' 행 제거. |
| FR-2 | 월별 납부목록 청구액 칸 클릭 → 그 자리 입력칸(청구액만), Enter·칸 이동 시 저장, Esc 취소. 청구 없음 → 수업료 청구 생성(납기 해당 월 10일, 수업 1개면 자동), 1건 → 금액 변경, 2건 이상 → 청구 창. |
| FR-3 | 상태 칸: 미청구·금액수정 → [청구액 입력], 미납·부분납 → [완납] → 미납액·납부일·결제수단 한 줄 → [완납 처리]로 해당 월 청구별 미납액 수납 기록. |
| FR-4 | 월별 목록 마지막 열 [청구] → 청구 창(수정·삭제·추가·수납). |
