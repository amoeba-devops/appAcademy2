## 2. Findings (현황과 문제)

현재 상세는 `교사 정보 수정` 모달이며 기본 정보, 담당 과목, 메모, 이력서·첨부파일, 포털 계정을 제공한다. 학력·성별·거주지역·경력·상세 프로필 전용 필드는 없다. 이메일은 DB/DTO/생성 서비스에서 필수이나 원본에는 이메일 열이 없다. 제공 표의 연락 수단은 전화번호 18명, 카카오톡 ID만 있는 강사 1명, 미입력 2명이다.

현재 과목 코드는 MAP, MATH, WRITING, LANGUAGE_ARTS, SSAT, ISEE, INTL_PREP, OTHER로 제한된다. 원본의 SAT, TOEFL, 과학, AP/IB, 컨설팅 등을 기존 과목만으로 표현하면 정보가 손실된다. 경력은 `5년 7개월`, `교육경력 없음` 등 문장이므로 정수 연차로 강제 변환하지 않는다.

명단의 No. 값은 중복되므로 식별자로 사용할 수 없다. 병합 셀과 서식 때문에 시트 최대 행수도 인원수가 아니다. 프로필에 없는 강사 9명도 `강사 정보`에 있는 등록 대상이다. 프로필 미존재를 퇴직으로 해석하지 않는다.

## 3. Field Mapping (필드 매핑)

아래 신규 필드는 선택 입력이며 원본 문장과 줄바꿈을 보존한다. 빈 문자열은 NULL로 정규화하고 기존 필드와 신규 필드를 구분한다.

| 화면 필드 | API 제안 / 저장 형식 | 원본 및 처리 |
| --- | --- | --- |
| 이름 | 기존 `tchName` | B열; 앞뒤 공백만 정리 |
| 학력 | `tchEducation`, TEXT | C열; 학교·전공·학위·재학/중퇴 상태 원문 보존 |
| 담당 과목 상세 | `tchTeachingSubjectsText`, TEXT | D열; 기존 과목 선택과 병행 |
| 성별 | `tchGender`, nullable enum | E열의 명시 값만 MALE/FEMALE; 미입력 NULL |
| 거주지역 | `tchResidence`, VARCHAR(200) | F열 지역명, 상세 주소를 요구하지 않음 |
| 경력 | `tchExperience`, TEXT | G열 원문; 기준일 없는 연차를 자동 증가시키지 않음 |
| 전화번호 | 기존 `tchPhone` | H열의 전화번호만 저장; 국제번호·앞자리 0 보존, 길이 검증 |
| 카카오톡 ID | `tchKakaoId`, VARCHAR(100), nullable | H열의 명시된 카톡ID 값; 접두어를 제외하고 보존, 전화번호로 저장하지 않음 |
| 상세 프로필 | `tchProfileText`, TEXT | 사용자 제공 프로필 본문 전체; 엑셀 대조 시 병합 셀 좌상단을 1회 읽음 |
| 이메일 | 기존 `tchEmail` nullable 개선 | 원본에 없으면 NULL, 임의 주소 생성 금지 |
| 영문명·생년월일·입사일·출결번호 | 기존 필드 | 원본에 없으면 기존 값 유지/신규 NULL |

전문 수업·입시 지도·지도 학교 설명은 상세 프로필에서 줄바꿈으로 읽을 수 있게 한다. 사용자 표의 `<br>`와 유니코드 줄 구분자는 실제 줄바꿈으로 변환하고 HTML로 실행하지 않는다. 별도 열의 전공(공한나 Biology, 이지혁 생명과학, 윤여송 기계공학)은 학력에 이미 포함되어 있으면 중복 추가하지 않고, 누락된 경우 학력의 전공 설명으로 보완한다. 프로필이 없는 나머지 9명에게 임의의 소개문을 생성하지 않는다. 프로필의 학교 설명으로 학생 관계나 학교 마스터를 자동 생성하지 않는다. 명확한 기존 코드만 과목 태그에 매핑하고, 나머지는 상세 과목/프로필 원문에 남긴다. 새로운 과목 마스터 구축은 이번 범위에 포함하지 않는다.

## 4. Registration and Merge Rules (등록 및 병합 규칙)

1. 원본 21명을 명단 기준으로 처리한다. 운영 화면 기준 예상은 **신규 20명 + 정성경 1명 보완**이며 실행 직전 동일 테넌트의 전체 상태·삭제 기록까지 재대조해 확정한다. 다른 기존 교사는 그대로 유지한다.
2. 같은 테넌트의 이름으로 후보를 찾고, 이메일/연락처 등 이용 가능한 원본 속성으로 충돌을 검사한다. 동명이인·다중 후보·삭제된 후보는 자동 생성/복구하지 않고 검토 대상으로 분리한다. 엑셀 No.와 행 순서를 교사 ID로 사용하지 않는다.
3. 정성경은 기존 `tch_id`를 사용한다. 빈 필드만 채우며, 기존 과목은 집합 합집합으로 추가한다. 기존 학력·연락처 등 비어 있지 않은 값과 원본이 다르면 덮어쓰지 않는다. 기존 프로필이 있으면 원문 블록 중복을 검사해 새 내용만 보완 대상으로 제시한다. 기존 메모는 유지한다.
4. 사용자 계정·AMA 연결·학생 담당 관계·수업·첨부파일·기존 고용 및 재직 정보는 변경하지 않는다. ACM 교사 등록과 로그인 계정 발급은 별개이며 이번 데이터 반영은 `tchCreateAccount=false`이다.
5. 신규 교사는 사용자 요청에 따라 강사로 등록하되, 원본에 없는 고용형태는 정규직으로 추정하지 않고 `미입력(NULL)`을 지원한다. 재직상태는 신규 기본 재직임을 반영 미리보기에 명시한다.
6. 이메일 없이 교사 레코드를 저장할 수 있도록 변경한다. 로그인 계정 발급을 별도로 선택할 때에만 유효한 이메일·계정 발급 요건을 검사한다. 기존 AMA 자동 등록의 동작 변경은 최소화하고 호환성을 검증한다.
7. 반영 내역은 신규/보완/보류/변경 없음으로 구분한다. 동일 파일 재실행 시 신규 중복과 프로필 중복 추가가 없어야 한다. 실행 전후 비교와 감사 기록은 서버 측 제한된 저장소에 보관하고 문서에는 집계만 기록한다.

| 위치 | 발견 사항 | 처리 |

| 강사 정보 C7 / 현 강사 프로필 B5 | 조혜수 학력이 University of Washington / Washington University in Saint Louis로 상이 | 학력 정규 필드 자동 확정 보류; 두 원본과 위치를 검토 기록에 보존. 나머지 정상 필드 등록 가능 |
| 강사 정보 D13 | 최한나 과목에 `펜실베니아` 기재 | 담당 과목으로 입력하지 않고 해당 필드만 보류; 거주지로 임의 이동 금지 |
| 강사 정보 G15 / 현 강사 프로필 B21 | 전우현 경력 `교육경력 없음`과 지도 이력 표현의 시점 차이 가능 | 경력 갱신/연차 추정 금지; 검토 기록에 남기고 원문 구분 |
| 강사 정보 H16 | 천세준 연락 수단은 카카오톡 ID | 카카오톡 ID 필드에 저장하고 전화번호는 NULL 유지 |
| 강사 정보 H23 | 윤여송 전화번호에 보이지 않는 방향 제어문자 및 줄바꿈 | 전화번호의 표시용 제어문자·바깥 공백 제거 후 숫자 보존 검증; 식별 값 추정 금지 |
| 강사 정보 H8, H13 | 연락처 누락 | NULL 허용; 가상 번호 생성 금지 |
| 전체 명단 | 이메일·입사일·고용형태 미제공 | 추정 입력 금지 |

오류 필드만 보류해 해당 강사 전체 등록을 불필요하게 막지 않는다. 보류 중인 필드는 운영자가 확인 후 수정할 수 있도록 보고서에 남긴다.

## 6. Acceptance Criteria (완료 조건)

- 확장 상세화면에서 신규 필드 조회·저장 및 줄바꿈 유지가 가능하다. 모바일은 한 열로 표시하며 계정 제어와 저장 버튼의 접근성을 유지한다.
- 전화번호와 카카오톡 ID는 분리되며 천세준의 전화번호를 임의 생성하지 않는다. 전화번호 정리 시 앞자리 0과 실제 숫자가 보존된다.
- 이메일 없는 교사 생성·수정은 성공하고, 이메일이 필요한 로그인 계정 발급은 입력 없으면 실패한다. 기존 이메일 있는 교사의 동작은 유지한다.
- 교사별 원본 대조 결과 21명이 각각 신규/보완/보류/변경 없음으로 추적된다. 프로필 12명은 중복 저장되지 않는다.
- 정성경은 동일 ID 1명으로 유지되고 원본과 충돌하는 기존 값, 연결 계정, 관계, 첨부파일이 보존된다.
- 동일 파일 재실행 결과 추가 신규 등록과 동일 프로필 재추가가 0건이다. 다른 테넌트와 기존 비대상 교사 변경은 0건이다.
- 계획 승인 후 구현·검증·배포·데이터 반영 결과를 별도 보고서로 남긴다. 운영 반영 결과는 [구현 보고서](../report/RPT-260919-tch-profile-import.md)를 참조한다.
