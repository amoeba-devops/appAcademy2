# REQ-261027C Collections list redesign & white content area (수납 목록 재구성·콘텐츠 흰 배경)

## 1. Request (요청 원문 정리)
1. 콘텐츠 영역에서 **전체 배경**과 **콘텐츠 노출 영역**을 구분하고, 콘텐츠 노출 영역은 **흰색 배경**.
2. 수납 관리 **월별 납부목록**: 목록 위 학생 통계 부분 불필요.
   - 남길 줄 2개: ① 월 선택 ② 학생 검색 · 엑셀(내보내기)
   - [학생 선택해 청구], 재원생 학생 통계, 선택 대상 합계 줄 → **대시보드·통계 탭에서만** 표시
3. **가로 폭 확장**, 작업 영역 줄바꿈 없음.
4. 목록 열(월별 납부목록·청구 상세 **동일**):
   `번호 | 학생이름 | 사이트 | 학교 | 학년 | 청구액 | 할인액 | 실납부액 | 미납금 | 환불금 | 상태 | 청구작성/수정`
5. 역할 분리: **월별 납부목록 = 과거 납부 상태 조회만**, **청구 상세 = 이번 달 청구 작성**.

## 3. Requirements (요구사항)
| ID | 내용 |
|----|------|
| FR-1 | 관리 화면 공통: 바깥은 회색 배경, **페이지 본문은 흰색 카드**(테두리·둥근 모서리·안쪽 여백). 이미 흰 카드를 쓰는 화면은 이중 테두리가 생기지 않게 정리. |
| FR-2 | 수납 관리 화면은 **본문 최대 폭 해제**(이용 팁 패널 기본 숨김), 표는 줄바꿈 없이(`whitespace-nowrap`) 넘치면 가로 스크롤. |
| FR-3 | 월별 납부목록 상단은 2줄만: ① ◀ 월 ▶ · 이번 달 · 사이트 ② 학생 검색 · 상태 · 엑셀 내보내기. |
| FR-4 | 학생 통계 카드·선택 대상 합계·[학생 선택해 청구]는 대시보드·통계 탭으로 이동. |
| FR-5 | 두 탭 공통 12열(학생 단위): 번호 · 학생이름 · 사이트 · 학교 · 학년 · 청구액 · 할인액 · 실납부액(수납−환불) · 미납금 · 환불금 · 상태 · 청구작성/수정. 한 달에 청구가 여러 건이면 합계. |
| FR-6 | **월별 납부목록**: 월 선택(과거 포함), **조회 전용** — 입력칸·저장 없음. |
| FR-7 | **청구 상세**: 이번 달 학생 목록에서 청구 작성 — 청구액·할인액 입력, [변경 저장], [엑셀 일괄등록], 마지막 열 [작성](청구 없음)·[수정](청구 있음). 수납 입력·환불은 [수정] 창에서. |
| NFR | 4개 언어, 모바일 규칙(입력 16px·터치 36px+), 기존 API 규칙 유지. |
