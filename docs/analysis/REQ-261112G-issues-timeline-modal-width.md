# REQ-261112G Issues page timeline & wider issue form (이슈 화면 타임라인·이슈 등록 창 폭 확대)

## 1. Request (요청)
대상: `/admin/issues`
1. 이슈 화면에도 우측 패널에 타임라인을 구현한다 (REQ-261112F 프로젝트 타임라인과 같은 형태).
2. 이슈 등록 모달 창의 가로 크기를 확대한다.

## 2. Current State (현황, 2026-11-12 main `4cd36d3` 기준)
| 항목 | 현황 |
|------|------|
| `/admin/issues` (`prj/issues/issues-page.tsx`) | 접근 가능한 **모든 프로젝트**의 이슈. 목록(표 최소 896px)·칸반, 필터(범위·검색·유형·상태·우선순위·프로젝트·담당자) |
| 화면 폭 | 기본 카드 최대 1,280px(REQ-261112D). 표가 896px 이상이라 1280 카드 안에 타임라인(340px)을 붙이면 표가 가로 스크롤됨 |
| 타임라인 API | `GET /acm/prj/projects/:id/timeline` — **프로젝트 1개** 기준만 있음 (REQ-261112F) |
| 이슈 등록 창 (`issue-form-dialog.tsx`) | 최대 폭 **672px**(`max-w-2xl`), 본문 높이 75vh. 프로젝트·유형 / 제목 / 설명(리치 에디터) / 우선순위·담당자 / 참여자 / 기간 / 처리 결과 — 2열 배치. 설명 입력칸이 좁아 긴 업무 요청 작성이 불편 |
| 같은 창 사용처 | 이슈 화면, 프로젝트 이슈 탭, 이슈 상세 수정, 내 업무 |

## 3. Requirements (요구사항)
| ID | 내용 |
|----|------|
| R1 | `/admin/issues` 오른쪽 패널 "이슈 타임라인": 접근 가능한 모든 프로젝트의 이슈 생성·상태 변경·담당자·프로젝트 이동·코멘트 (+ 문서·파일 등록) |
| R2 | 각 항목에 프로젝트 이름 표시, 클릭 시 이슈 상세 |

| R4 | 종류 필터·더 보기·1280px 미만 숨김은 프로젝트 타임라인과 동일 |
| R5 | 표가 좁아지지 않도록 `/admin/issues` 를 전체 폭 예외에 추가 |

| R7 | 권한: 기존 이슈 목록과 같은 접근 규칙(참여 프로젝트, 서비스 관리자는 전체), 삭제 프로젝트·이슈 제외 |
