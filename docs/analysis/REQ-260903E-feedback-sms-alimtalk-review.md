# REQ-260903E — 수업 피드백 카카오톡 전송 조사 보고 (ACM 직접 구현) / KakaoTalk Feedback Delivery Investigation

## 1. Decision & Scope (결정·범위)

- **결정(2026-09-03)**: 카카오톡 전송은 AMA(AmoebaTalk) 경유가 아닌 **ACM 직접 구현**.
- 과제: 카카오톡 비즈니스 채널에 가입(채널 추가)한 회원(학부모)에게 수업 피드백 내용을 전송하는 방안 조사.

## 2. 전송 수단 조사 결과 (2026-09 기준)

### 2.0 공통 전제
카카오는 개별 기업에 발송 API를 직접 열지 않는다 — **공식 대행사(딜러사) 경유가 필수**다 (Solapi, 알리고, NHN Cloud, BizGo/인포뱅크, 휴머스온 등). 대행사가 REST API·발송결과 웹훅·충전금 과금을 제공한다.

### 2.1 알림톡 (AlimTalk) — 정보성 메시지
| 항목 | 내용 |
|------|------|
| 발송 대상 | **채널 친구 여부 무관** — 전화번호만 있으면 발송 |
| 내용 형식 | **사전 검수 승인된 고정 템플릿 + #{변수}** (자유 본문 불가), 최대 1,000자 |
| 검수 | 카카오 심사 1~5영업일. 정보성 메시지만 허용(광고 불가) |
| 야간 제한 | 없음 |
| 단가 | 약 7~9원/건 (SMS 대비 ~80% 저렴) |

### 2.2 친구톡 → 브랜드 메시지 — 채널 친구 대상 자유 본문
| 항목 | 내용 |
|------|------|
| 주의 | **친구톡은 2025-12-31 서비스 종료** — 후속은 "브랜드 메시지" |
| 발송 대상 | **채널 친구(비즈채널 가입 회원)** + 마케팅 수신 동의 번호 |
| 내용 형식 | 자유 본문(텍스트/이미지/버튼 등), 템플릿 심사 불필요 |
| 야간 제한 | **20:50~익일 08:00 발송 불가** |
| 단가 | 알림톡보다 높음(텍스트 기준 ~14원/건 안팎) |
| 성격 | 광고성 채널로 분류 — 광고 표기·수신거부 표기 의무 등 광고 규제 적용 |

### 2.3 적합성 판단 — 수업 피드백은 "정보성"
피드백은 수신자(학부모)의 서비스 이용에 따른 **정보성 메시지**로, 카카오 정책상 **알림톡이 정합**하다.
- 알림톡이면 "채널 가입 회원" 조건조차 불필요 — 등록된 전화번호만으로 전 학부모 도달.
- 브랜드 메시지는 광고 채널로 분류돼 정보성 피드백 전송 용도로는 규제·야간 제한·마케팅 동의 요건이 불리.
- 단, 알림톡은 **자유 본문 불가** — 피드백 리치 HTML 전문은 담을 수 없고, **"피드백 도착 알림" 템플릿**(학원명·학생명·수업명·일시 + 변수로 요약/안내) 형태가 현실적. 전문 열람은 이메일(기구현) 유지.
  - 템플릿 예: `[#{학원명}] #{학생명} 학생의 #{수업명}(#{일시}) 수업 피드백이 도착했습니다. 자세한 내용은 이메일을 확인해 주세요.`

## 3. 권고 구현안 (ACM 직접)

1. **대행사**: Solapi(구 CoolSMS) 권장 — REST API·SDK 성숙, 알림톡 8원/친구톡 계열 14원, 알림톡 실패 시 **SMS 자동 대체발송** 지원. (알리고·NHN Cloud 도 동등 기능 — 가격/운영 편의로 최종 선택)
2. **설정 UI**: `/admin/config`에 "💬 카카오 알림톡" 카드 — 대행사 API Key/Secret(AES-GCM 암호화, Gmail SMTP 패턴 재사용), 발신프로필 키(pfId), 템플릿 코드, 대체발송(SMS) 사용 여부
3. **발송 흐름**: 피드백 발송 모달에 "알림톡 발송" 채널 추가 — 전화번호 보유 학부모 대상 수신자 표시, 발송 결과별 표시(기존 이메일 UX 동일). 이력은 `amb_acm_notification_log`(channel=ALIMTALK/SMS)
4. **개발 규모**: 백엔드 대행사 클라이언트+설정+발송 서비스 ~5파일, 프론트 설정 페이지+모달 확장 ~4파일 — **약 2~3일**
