# Mentions, Opt-in Invite Mail, Documents Create, Drive UI Requirements (멘션·참석자 메일·문서 작성·드라이브 UI 요구사항)

## 1. Request (요청)
1. 이슈와 댓글에 **멘션** 기능을 넣고, 멘션되면 **알림**(알림함)을 받는다.
2. 수업 일정에서 참석자를 지정하고 저장할 때 참석자 메일을 **자동 발송하지 않고, 선택했을 때만 발송**한다. 기본은 미발송.
3. `/admin/documents`로 바로 들어간 경우에도 **메모·시트·문서·파일을 작성**할 수 있게 한다.
4. `/admin/drive` 화면 UI를 AMA `/drive`와 **같게** 만든다.

## 3. Requirements (상세 요구사항)
### FR-1 Mentions in Issues & Comments (이슈·댓글 멘션)
- 이슈 설명과 댓글 에디터에서 `@`를 입력하면 **프로젝트 참여자** 목록이 뜨고(이름·이메일 검색, 방향키·Enter), 고르면 `@이름` 칩이 들어간다. 보기 화면에서도 칩(indigo)으로 보인다.
- 저장 시 서버가 본문에서 멘션된 사람을 뽑아 **새로 멘션된 사람에게만** 알림을 보낸다(수정 때 이미 멘션된 사람에게 다시 보내지 않음). 본인·비참여자는 제외.
- 알림 종류 `ISSUE_MENTION`: 알림함 문구 “{보낸 사람}님이 이슈 ‘{ISS-n 제목}’에서 회원님을 멘션했습니다”(댓글이면 “댓글에서”), 클릭 → 이슈 상세(댓글이면 해당 댓글로 이동). 웹 푸시는 기존 규칙대로 함께 간다.
- 받는 사람: 콘솔 계정(ADMIN·STAFF·TEACHER) 중 프로젝트 참여자.

### FR-2 Opt-in Invitee Mail (참석자 메일 선택 발송)
- 일정 등록/수정 창, 반복 일정, 즉시 수업 창의 참석자 아래에 **[ ] 저장 시 참석자에게 메일 보내기** 체크(기본 해제).
- 체크했을 때만 지금과 같은 규칙으로 발송(등록 = 전체 참석자, 수정 = 새로 추가된 참석자, 반복 = 1회).
- 체크하지 않으면 메일을 보내지 않고, 참석자 발송 상태는 ‘미발송’으로 표시한다. API 기본값도 미발송.

### FR-3 Create from Documents Page (문서 화면에서 바로 작성)
- `/admin/documents` 상단에 **[+ 새로 만들기]**. 누르면 창에서 ① 프로젝트(검색 선택, 보관 제외) ② 종류(메모·스프레드시트·문서·파일) ③ 방식을 고른다.
  - 메모: ACM 작성 / 시트·문서: ACM 작성 · 기존 Google 링크 등록 · Google에서 새로 만들기(회사 Drive 공용폴더 준비 시) / 파일: 업로드(회사 Drive 또는 ACM 저장소).
- 프로젝트 필터나 현재 탭이 정해져 있으면 그 값을 기본으로 채운다. 작성 후에는 해당 문서(또는 목록)로 돌아온다.

### FR-4 Drive UI = AMA (드라이브 화면 AMA 동일화)
- 한 화면 구성(팝업 탐색 → 화면 안 탐색): 헤더(드라이브 · 부제 · 읽기 전용 표시 · 전체 검색) → 폴더 카드(보라 아이콘, 공유 드라이브/개인 폴더 표시, 연결 해제는 hover) → 폴더를 열면 경로(전체 폴더 › …), 정렬(작성일·크기·종류·작성자 + 방향), 목록/카드 전환, 선택 모드, [새 폴더], [업로드](진행 표시), 더 보기.
- 행/카드: 종류별 아이콘·색(AMA 매핑), 이름·크기·수정일·작성자, 행 메뉴(이름 변경·이동·휴지통).
- 선택 모드: 하단 떠 있는 바(N개 선택 · 전체 선택 · 해제 · 이동 · 휴지통).
- 파일 클릭 → 상세 팝업(유형·크기·수정일·소유자, Drive에서 열기·다운로드).
- ACM 고유 기능은 유지: 연결 관리(회사 Google 계정), 폴더 연결, 폴더별 공유 대상(NONE·VIEW·EDIT) 권한. 권한이 VIEW면 쓰기 버튼을 숨기고 ‘읽기 전용’ 표시.
- 서버에 없는 기능 추가: 이름 변경, 이동(같은 연결 폴더 안), 휴지통(Drive 휴지통으로, 영구 삭제 아님), 일괄 이동·휴지통, 검색, 파일 상세. 모두 EDIT 권한 + 연결 폴더 하위만.
- 업로드 한도는 AMA와 같은 **50MB**(결정 Q3). 서버 업로드 한도와 nginx 요청 크기를 함께 올린다.

### NFR
