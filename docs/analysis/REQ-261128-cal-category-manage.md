# REQ-261128-CAL Calendar category management · color picker (일정 분류 관리 · 컬러피커)

Related plan: [PLN-261128-CAL](../plan/PLN-261128-cal-category-manage.md)

## 1. Request (요구사항 원문 요약)
- `/admin/cal` 일정 등록의 분류(카테고리)를 **추가·수정·삭제**할 수 있게 한다.
  - 현재 분류: 레벨테스트, 데모수업, 정규수업, 미팅, 기타.
- 다음 4개 분류를 추가한다: **수업 가능 시간, 수업 불가능 시간, 휴강, 결강**.
- 색상 선택을 8색 팔레트에서 **컬러피커**로 바꾼다.

### 2.1 Categories with system behavior (기능이 묶인 분류)
The five current categories drive logic elsewhere, so they cannot be deleted.
기존 5개 분류는 다른 기능과 묶여 있어 삭제할 수 없다.

| 분류 | 묶인 기능 |
|------|-----------|
| 정규수업 · 데모수업 | 화상수업(보다스쿨·Meet) 자동 개설, 수업 리뷰 알림, 외부 스케줄러 API |
| 레벨테스트 · 데모수업 | 상담(CSL) 일정 자동 생성·초기화 |
| 정규수업 | 학생 연결 도구(`/admin/cal/link-students`) 기본 대상 |
| 기타 | 삭제된 분류·알 수 없는 코드의 대체 표시 |

## 3. Requirements (요구사항 정의)
| ID | Requirement |
|----|-------------|
| FR-1 | 관리자는 분류를 추가할 수 있다: 이름, 색상, 통계 포함 여부, 순서 |
| FR-2 | 관리자는 분류를 수정할 수 있다. 기본 5개는 **색상·순서만** 수정하고, 이름은 4개 언어 번역을 유지한다 |
| FR-3 | 관리자는 추가한 분류를 삭제할 수 있다. 기본 5개는 삭제할 수 없다 |
| FR-4 | 삭제는 숨김 처리한다. 새 일정에서는 고를 수 없고, 이미 만든 일정은 이름과 색을 그대로 보여 준다 |
| FR-5 | 첫 배포 때 **수업 가능 시간 · 수업 불가능 시간 · 휴강 · 결강** 4개를 추가 분류로 넣는다. 일반 추가 분류와 같이 수정·삭제할 수 있다 |
| FR-6 | 4개 추가 분류는 기본값을 **통계 제외**로 둔다. 강사 수업시간 통계에 잡히지 않게 하기 위함이며, 관리자가 바꿀 수 있다 |
| FR-7 | 분류 목록이 쓰이는 모든 곳이 같은 목록을 쓴다: 일정 작성 모달, 달력 필터, 범례, 통계, 강사 포털 캘린더 |
| FR-8 | 분류·담당 강사 색상 설정을 **컬러피커**(색상 칸 + HEX 입력 + 추천 색)로 바꾼다 |
| FR-9 | 기존 팔레트 색상 설정은 같은 색의 HEX 값으로 옮긴다. 화면 색은 바뀌지 않는다 |
| FR-10 | 분류 관리·색상 설정 권한은 지금의 색상 설정과 같다 (ADMIN) |

## 4. Non-Functional (비기능)
- **i18n**: 화면 문구는 4개 언어(ko/en/vi/zh-CN)로 둔다. 관리자가 입력한 분류 이름은 입력한 그대로 모든 언어에 보인다. 기본 4개 추가 분류만 언어별 이름을 둔다.
- **Tenant isolation**: 분류는 `ent_id` 별로 따로 관리한다.
- **글자 대비**: 사용자가 고른 색으로 카드 배경(연한 색)과 글자(진한 색)를 자동으로 만든다. 글자는 읽을 수 있는 대비를 유지한다.
- **External API**: 외부 스케줄러 API(`/api/integration/scheduler`)의 분류 값은 그대로 둔다. 기존 연동이 깨지지 않게 하기 위함이다.

## 5. Out of Scope (범위 제외)
- 수업 가능/불가능 시간을 예약·배정 로직(충돌 검사, 외부 예약 차단)에 반영하는 일. 이번 범위에서는 달력 표시용 분류로만 쓴다.
- 휴강·결강 분류를 수업 회차(`acm-cls`) 취소 상태나 수납과 자동 연동하는 일.
