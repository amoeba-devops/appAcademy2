# REQ-261112F Project issue list — title link & project timeline (프로젝트 이슈 목록 제목 링크·프로젝트 타임라인)

## 1. Request (요청)
대상: `/admin/projects/{id}?tab=issues`
1. 이슈 목록에서 이슈 제목을 클릭해도 이슈 상세 화면(`/admin/issues/{id}`)으로 이동한다.
2. 이슈 목록 우측 패널에 프로젝트 타임라인을 구현한다 — 해당 프로젝트의 이슈 생성, 담당자 지정/변경, 이슈 상태 변경, 코멘트 작성 등의 내역을 확인할 수 있어야 한다.

## 2. Current State (현황, 2026-11-12 main `5022b20` 기준)

### 2.1 이슈 목록 (`frontend-acm/src/modules/prj/project-page.tsx`)
- 목록 보기: 카드의 제목이 일반 글자(`<h2>`)라 눌러도 이동하지 않는다. 오른쪽 `보기/수정` 버튼만 상세로 이동한다.
- 칸반 보기(`issue-kanban.tsx`): 제목이 이미 상세 링크다 → 변경 불필요.
- 프로젝트 상세는 전체 폭 화면(공통 오른쪽 패널 없음, REQ-261112D 예외)이라, 타임라인은 이슈 탭 안에 직접 배치해야 한다.

### 2.2 이력 데이터 (이미 저장 중 → DB 변경 불필요)
| 이벤트 | 출처 | 남는 값 |
|--------|------|---------|
| 이슈 생성 | `amb_acm_prj_item` (`pit_kind='ISSUE'`) `created_at`·`created_by` | 생성자, 제목, 번호 |
| 상태 변경 | `amb_acm_prj_issue_status_log` `psl_kind='STATUS'` | 이전→새 상태, 메모, 변경자 |
| 담당자 지정/변경 | 같은 표 `psl_kind='ASSIGNEE'` | 이전→새 담당자, 변경자 |
| 프로젝트 이동 | 같은 표 `psl_kind='PROJECT'` | "이전 → 새 프로젝트" 이름, 변경자 |
| 코멘트 작성 | `amb_acm_prj_issue_comment` (삭제 제외) | 작성자, 내용(HTML) |

제약
- 이슈 등록 시 처음 지정한 담당자는 별도 기록이 없다 → "생성" 이벤트에는 생성자만 표시(현재 담당자를 생성 시 담당자로 오해할 수 있어 표시하지 않음).
- 제목·설명·기간 수정, 코멘트 수정·삭제는 기록이 없어 타임라인에 나오지 않는다.
- 다른 프로젝트로 옮겨진 이슈의 과거 이력은 이슈를 따라간다(이슈의 현재 프로젝트 기준).
