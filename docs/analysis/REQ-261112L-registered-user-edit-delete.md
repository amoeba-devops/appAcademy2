# REQ-261112L Registered users — edit/delete (등록 사용자 수정·삭제)

## 1. Overview (개요)
`/admin/config/invites` 등록 사용자 탭 각 행에 [수정]·[삭제]를 추가한다. 이름 링크(학생·강사·직원 화면 이동)는 유지.

## 2. Current State (현재)
- 목록 = 콘솔 계정(관리자·직원·강사) + 포털 로그인 계정(학생·강사). 행 동작 없음
- 콘솔 관리자·직원: `/acm/config/admins` 에 상세 수정·소프트삭제·복구 있음(강사 콘솔 계정은 대상 아님)
- 포털 계정: 발급·비밀번호 재발급·로그인ID 이메일 전환만. 상태 수정·삭제 없음. 운영 학생 10·강사 5 (학부모 11 은 목록 대상 아님)

## 3. Requirements (요구사항)
| ID | Requirement |
|---|---|
| FR-1 | 콘솔 계정 [수정] → 관리자 관리와 같은 상세 창(이름·이메일·상태·잠금·비밀번호·로그인 방식). 강사는 등급 고정 |
| FR-2 | 콘솔 계정 [삭제] → 관리자 관리와 같은 소프트삭제(로그인·SSO 차단, 목록 제외, 관리자 관리 '삭제됨'에서 복구). 본인·테넌트 마스터 불가 |
| FR-3 | 포털 계정 [수정] → 상태(사용/중지) 변경, 비밀번호 재발급 |
| FR-4 | 포털 계정 [삭제] → 로그인 계정만 소프트삭제(학생·강사 정보 유지). 로그인 차단, 목록·학생 상세에서 '미발급'처럼 보이고, 다시 [발급]하면 같은 로그인ID로 되살림(새 비밀번호) |
| FR-5 | 수업 시작 자동 발급은 삭제된 포털 계정을 되살리지 않음 |
| FR-6 | 권한: 이 화면과 같은 서비스 운영자(CONFIG_ADMIN) |
