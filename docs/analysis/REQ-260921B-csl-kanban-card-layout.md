# Consultation Kanban Cards (상담 칸반 카드 개선)

## 1. Request and Findings (요청·확인)

대상: `/admin/csl` 칸반 보기. 사용자 제공 2026-09-21 스크린샷과 `csl-kanban-board.tsx`, `registered-at-cell.tsx`를 확인했다.

현재 단계 내부 카드 그리드와 버튼에 최소 너비 제한이 없어서 긴 날짜 문구가 열 너비를 넘어갈 수 있다. 카드에는 학교 필드에 저장된 “홈페이지 접수(이관)” 등의 문구, 유입 경로 배지, 등록일과 별도 접수 일시가 함께 출력된다.

## 2. Requirements (요구사항)

- 카드 및 내부 콘텐츠의 가로 폭을 각 단계 안으로 제한한다. 긴 이름·배지·날짜가 인접 단계와 겹치지 않도록 줄바꿈 또는 말줄임을 적용한다.
- 하단 등록/접수일 앞의 📥 이모티콘을 삭제한다.
- 이관 데이터에서 별도로 붙는 `(접수 MM/DD HH:mm)` 문구를 카드에서 숨긴다. 원래 등록일은 유지하며, 같은 날의 유효한 시간 표시는 유지한다. 목록·상세 및 저장 데이터는 유지한다.
- “홈페이지 접수”, “홈페이지 접수(이관)”, “TPI 웹 접수” 등 실제 학교명이 아닌 접수 문구 대신 소속 사이트를 TPI·TA·SC로 표시한다.
- 사이트 기준은 기존 집계와 동일하게 `siteOverride ?? sourceSite`로 한다. 미지정은 “미지정”으로 표시하고 홈페이지 접수만으로 특정 사이트를 추정하지 않는다.
- 카드의 사이트·학년 행에 사이트를 한 번 표시하고, 홈페이지/외부 웹 유입 배지는 중복 출력하지 않는다. 실제 학교명이 있는 경우 학교명은 별도 행으로 유지한다. 전화·카카오 유입 배지 및 신청유형은 유지한다.

## 3. Acceptance (완료 기준)

긴 이름, 이관 날짜, 여러 배지가 있는 카드에서도 단계 경계 넘침이 없어야 한다. TPI/TRINITY/SANTACROCE가 각각 TPI/TA/SC로 표시되어야 한다. 단계별 개수, 필터 및 카드 상세 열기는 정상 동작해야 한다.

## Amendment: Single Row (수정 요청: 한 줄 배열)

2026-09-21 사용자 수정 요청에 따라 6개 단계를 한 줄로 고정한다. 보드 최소 너비 1380px과 내부 가로 스크롤을 적용한다. 앞선 반응형 열 수 조정 계획은 이 수정으로 대체한다. 사이트·날짜 표시 개선은 유지한다.

```text
[접수] [레벨테스트] [데모수업] [등록상담] [결제] [수강등록]
<------ Horizontal scroll on narrow screens ------>
```

사용자의 직접 수정 요청에 따라 구현·검증·배포한다.
