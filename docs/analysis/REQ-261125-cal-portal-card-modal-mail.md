# REQ-261125-CAL2 Calendar title hint · portal card/modal · parent mail progress · materials tabs (일정 제목 안내·포털 카드/모달·학부모 메일 진행·자료실 탭)

## 1. Overview (개요)
REQ-261125-CAL 로 달력 문구가 `시간 | 학생 | 제목` 으로 통일되어 참석 학생이 자동 표시된다.
관리자가 제목에 학생 이름을 또 입력하지 않도록 안내하고, 강사 포털 카드·모달·메일 발송·탭을 관리자 화면 수준으로 맞춘다.

## 2. Requirements (요구사항)
| ID | Requirement |
|---|---|
| FR-1 | `/admin/cal` 일정 작성·수정: 제목 입력란 앞에 자동 표시 항목 `[참석자]`(참석 학생 이름, 없으면 "참석자") 를 고정 표시, 안내 "참석 학생은 달력에 자동 표시됩니다 — 제목엔 과목만" + 달력 미리보기 줄 |
| FR-2 | 제목이 참석 학생 이름과 같으면 경고 (저장은 가능, 달력에선 제목 생략됨) |
| FR-3 | `/portal/calendar` 카드: 관리자 카드처럼 1줄 `시간 \| 학생 \| 제목`, 2줄 과목(=일정 구분: 정규수업 등). 강사 줄 없음 |
| FR-4 | 포털 일정 모달: 과목(일정 구분)·강의링크(참석 학생의 학생관리 수업 링크, 이 강사 기준) 추가 |
| FR-5 | `/portal/calendar/:id` 학부모 메일 발송: 발송 중 진행 표시줄, 완료 시 "발송완료되었습니다" 안내 후 모달 닫기, 발송 시각 저장(기존 발송 이력), 발송 버튼 아래 발송 이력 표시 |
| FR-6 | 강사 포털 문서/자료실 탭(공유받은 게시물·내 게시물)을 수강생관리 탭과 같은 밑줄 형태로 |
| FR-7 | 새 문구 i18n ko/en/vi/zh-CN |
