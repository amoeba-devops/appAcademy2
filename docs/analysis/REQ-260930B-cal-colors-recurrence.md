# Calendar Colors and Recurrence (캘린더 색상·반복 일정)

## 1. Request (요청)

대상: `/admin/cal` 수업일정 캘린더.

- Category와 In Charge별 색상을 지정한다. 구글 캘린더의 색상 선택 방식을 참고한다.
- 일정 등록에 일·주·월·특정일자 반복 옵션을 추가한다.
- ‘일반복’은 ‘일 반복’으로 해석한다. 일 반복에서 토·일요일 포함·제외를 명시적으로 선택한다.

## 3. Proposed Behavior (제안 동작)

### 3.1 Colors (색상)

- 상단에 **색상 기준: 카테고리 / 담당자(In Charge)** 선택과 **색상 설정** 버튼을 둔다. 기본은 현재와 같은 카테고리 기준이다.
- 관리자는 카테고리·담당 강사별 색상을 팔레트에서 선택하고 기본값으로 되돌릴 수 있다. 색상표는 학원 공통이며 선택한 표시 기준은 사용자·학원별로 기억한다.
- 한 일정의 주 색상은 선택한 기준 하나로 결정한다. 다른 기준의 이름은 배지·텍스트로 함께 표시한다.
- 담당자는 **담당 강사**를 뜻한다. 담당자 미지정은 중립색이며 작성자의 색상으로 대체하지 않는다. 이름이 같아도 강사 UUID로 구분한다.
- 기존 `CLASS` 등 레거시 카테고리도 표시·설정을 지원한다. 기존 일정을 다른 카테고리로 일괄 변환하지 않는다.
- 과거 일정과 ICS 이관 일정에도 조회 시 색상을 적용한다. 일정 데이터 자체를 색상 변경 때문에 수정하지 않는다.
- 색상만으로 정보를 구분하지 않고 이름·범례를 유지하며 글자 대비를 확보한다.

### 3.2 Recurrence (반복)

| 반복 종류 | 입력 | 동작 |
|---|---|---|
| 없음 | 기존 시작·종료 | 현재 단일 일정 |
| 일 | N일 간격, 주말 포함/제외 | 시작일 기준 N일 간격 후보 중 토·일 제외 가능 |
| 주 | N주 간격, 요일 복수 선택 | 선택한 요일마다 동일한 현지 시각 |
| 월 | N개월 간격, 시작일의 날짜 | 해당 날짜가 없는 달은 건너뜀(예: 31일) |
| 특정일자 | 달력에서 날짜 복수 선택 | 중복 제거된 선택 날짜마다 동일한 시각·길이 |

- 일 반복의 주말 옵션은 기본 **포함**으로 표시하고 저장 전 반복 요약에도 명시한다. 제외는 공휴일 제외를 의미하지 않는다.
- 일·주·월 종료 조건은 **종료 없음 / 종료 날짜 / 반복 횟수**이다. 종료 날짜는 학원 시간대 기준 해당 날짜를 포함한다. 횟수는 제외한 날을 빼고 실제 생성하는 회차 수다.
- 특정일자는 선택한 날짜 목록 자체가 범위이며 별도 무기한 종료 옵션을 표시하지 않는다. 시작 날짜를 최초 선택값으로 넣고 최종 요약에 실제 선택 날짜를 표시한다.
- 최초 시작일이 제외 요일이면 다음 유효 회차부터 생성한다. 저장 전 다음 5회와 반복 요약을 미리 보여준다. 생성 회차가 없으면 저장할 수 없다.
- 학원 시간대의 현지 시각을 기준으로 반복한다. 날짜를 넘기는 일정과 종일 일정의 기간을 유지한다. DST 지역에서도 반복 시각이 임의로 한 시간씩 바뀌지 않도록 검증한다.
- 종료 없는 반복은 규칙을 계속 보관하고 필요한 조회 구간 및 선행 1년 구간을 점진 생성한다. 생성 범위를 반복 종료일로 취급하지 않는다.
- 신규 직접 등록 반복 일정의 수정·삭제는 **이번 일정 / 이번 일정부터 이후 / 전체 반복** 범위를 선택한다. 실제 수업·출결 등 이력이 연결된 회차는 일괄 덮어쓰기·삭제하지 않고 보호 대상 수와 이유를 알린다.
- 기존 ICS 반복의 원본 규칙·예외·중단 상태는 유지한다. 이번 단계에서는 ICS의 복잡한 원본 규칙을 신규 입력 폼으로 자동 변환하지 않는다. 기존 회차 수정·반복 종료 기능은 유지한다.

## 4. Acceptance Criteria (완료 기준)

1. 카테고리 또는 담당자 색상을 저장하면 재접속 후에도 유지되고 일·주·월·목록에 동일하게 반영된다.
2. 다른 학원의 색상·담당자·반복 정보에 접근할 수 없다. 색상 변경은 관리자만 가능하다.
3. 주말 포함 시 매일, 제외 시 평일에만 생성되며 간격·종료 날짜·횟수·미리보기가 일치한다.
4. 주 복수 요일, 월말·윤년, 특정일자 중복 제거, 종일·자정 넘김을 정확히 처리한다.
5. 재시도·동시 생성·자동 연장으로 같은 회차가 중복되지 않으며 수정·삭제 예외가 되살아나지 않는다.
6. Google/BODA 설정 및 기존 권한·초대자 테넌트 검증을 유지하고 자동 연장으로 초대 알림이 대량 발송되지 않는다.
7. ICS 원본·기존 일정·수업 이력 및 기존 필터 동작이 유지된다.
