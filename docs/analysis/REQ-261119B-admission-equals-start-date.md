# REQ-261119B Admission date equals class start date (입학일 = 수업 시작일)

## 1. Overview (개요)
학생 정보의 입학일(`std_admission_date`)과 수업 시작일(`std_start_date`)을 같은 날짜로 관리한다.
두 값이 다르면 빠른 날로 통일한다. (REQ-261116 "입학일은 관리자 입력" 결정을 대체)

## 2. Current State (현황, 2026-11-19 운영)
| 상태 | 학생 | 같음 | 입학일만 없음 | 입학일이 빠름 | 시작일이 빠름 | 둘 다 없음 |
|---|---|---|---|---|---|---|
| 재원 | 77 | 45 | 17 | 8 | 1 | 6 |
| 퇴원 | 135 | 102 | 1 | 2 | 2 | 28 |
| 비활성 | 118 | 0 | 1 | 0 | 0 | 117 |

- 통일 대상 32명 (재원 26·퇴원 5·비활성 1) 중 소프트 삭제·재등록 제외 **23명 (재원 18·퇴원 4·비활성 1)**, 이 중 수업 시작일이 앞당겨지는 학생 10명 (대시보드 운영 기간도 따라 바뀜).
- 운영 기간이 여러 개인 학생(트리거 예외 대상) 중 해당자 0명.
- 시작일만 있고 입학일이 없는 재원생은 월별 납부 목록에 '기간 확인'으로 표시되는 중 → 통일 후 해제.

## 3. Requirements (요구사항)
| ID | Requirement |
|---|---|
| FR-1 | 학생 등록·수정 화면은 날짜 하나("입학일 (수업 시작일)")만 입력받고 두 컬럼에 같은 값을 저장 |
| FR-2 | API 로 둘 중 하나만 오거나 다르게 오면 빠른 날로 두 값을 맞춘다 (엑셀 가져오기·퇴원생 가져오기 포함) |
| FR-3 | 상담 등록·상담 수업 시작일 변경 연동(#444)은 두 값을 함께 바꾼다 |
| FR-4 | 기존 학생 23명(재등록 제외) 일괄 통일 (빠른 날), 학생별 실패 시 건너뛰고 기록 |
| FR-6 | 대시보드 운영 기간 편집이 수업 시작일을 바꾸면 입학일도 같이 (트리거 `acm_std_period_to_master`) |
| FR-7 | **재등록 학생 제외** — 상태 이력에 퇴원 뒤 재원이 있거나 운영 기간이 2개 이상인 학생(이번 수정에서 퇴원→재원 전환 포함)은 입학일·수업 시작일을 따로 둔다. 화면도 두 칸 |
| FR-5 | 학생 상세·목록 표시는 한 값으로, 컬럼 둘은 DB 에 그대로 둔다 (집계 쿼리 호환) |

## 4. Out of Scope (범위 밖)
- 수업 종료일·퇴원일 관계 (기존 규칙 유지)
- 두 날짜가 모두 없는 학생 (151명, 그대로)
