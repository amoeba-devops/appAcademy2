# Chat Participants Requirements (채팅 참여자 관리 요구사항)

## 1. Scope (범위)

대화방 목록에 왕관 아이콘과 방장 이름을 표시하고, 선택한 방의 우측 패널에서 참여자 조회·DM·초대·내보내기를 제공한다. 일반 참여자는 참여자 조회와 DM 버튼만 표시하며 방장에게만 참여 관리 권한을 제공한다. 기존 메시지 전송, 보관, 나가기 기능은 유지한다.

## 2. Findings (코드 검토 결과)

운영 배포 커밋 7806e5a의 채팅 구현을 기준으로 확인했다. 인증된 운영 화면을 직접 점검한 결과가 아니며 웹 조회 도구로 해당 URL에 접근할 수 없었다.

- `TalkChannelView.members`에 이름, USER/TEACHER 구분, OWNER/MEMBER 역할이 있다. `mine`은 현재 로그인 사용자의 OWNER 여부다. 왕관 표시에 새 DB 필드는 필요하지 않다.
- `talk-chat.tsx`는 방 제목 및 마지막 메시지 목록, 대화 헤더의 참여자 요약만 표시한다. 방장용 멤버관리 모달은 존재한다.
- `AdminContentLayout`의 공통 우측 패널은 이용 팁과 가리기/다시 보기 기능을 제공한다. 선택 방 정보를 연결하는 패널 슬롯이 필요하다.
- 기존 `PUT channels/:id/members`는 방장을 제외한 멤버 전체를 교체한다. 개별 초대·내보내기를 이 API로 구현하면 오래된 화면 상태로 다른 참여자 변경을 덮어쓸 수 있다.
- 기존 `findOrCreateDm`은 USER 운영자 호출만 지원하며 채널의 `tlc_created_by`도 운영자 UUID를 필수 저장한다. 강사 DM 시작을 지원하려면 API와 개설자 저장 구조를 함께 확장해야 한다.
- 방장 위임/나가기, 참여 종료 이후 메시지·파일·알림 차단과 SSE 갱신 로직은 재사용할 수 있다.

## 3. Rules (동작 기준)

| 영역 | 기준 |
|---|---|
| 왕관 | 단체방 목록에 `왕관 + 현재 OWNER 이름`, 본인이면 `(나)`를 표시한다. 참여자 목록에서도 같은 방장을 표시한다 |
| 개설자와 방장 | 최초 개설 기록과 현재 방장은 구분한다. 기존 위임 기능과 일치하도록 왕관과 관리 권한은 **현재 OWNER**를 기준으로 한다 |
| 참여자 목록 | 선택한 방의 현재 활성 참여자만 표시한다. 방장 우선, 나머지는 이름순. 본인에게 `(나)` 표시 |
| 일반 참여자 | 참여자 목록 조회 및 다른 참여자의 DM 버튼만 표시. 본인 DM, 초대, 내보내기는 숨김 |
| 방장 | 일반 기능에 추가로 초대 버튼과 각 일반 참여자 내보내기 버튼 표시. 자기 자신/현재 방장은 강제 내보내기 불가 |
| 초대 | 같은 학원의 유효한 운영자/강사를 검색·선택. 현재 참여자와 중복 항목은 제외하며 신규 참여자만 추가 |
| 내보내기 | 대상 이름과 효과를 안내하는 확인창 후 실행. 해당 참여만 종료하며 기존 메시지는 보존. 마지막 일반 참여자도 내보낼 수 있음 |
| DM | 운영자와 강사 모두 같은 방의 다른 활성 참여자에게 시작 가능. 동일 두 명의 활성 DM이 있으면 재사용하고 없으면 생성 |
| 보관된 DM | 사용자가 DM 버튼으로 명시적으로 열면 본인 보관만 해제해 활성 목록에서 열기. 상대의 보관 상태는 유지 |
| 일반 DM 방 | 참여자 목록 및 상대 DM 접근만 제공. 그룹용 왕관/초대/내보내기 표시 안 함 |
| UI 범위 | 관리자 /admin/chat에 우측 패널 적용. 강사 /portal/chat에도 공용 참여자 보기와 DM 동작을 제공하여 일반 참여자 경험을 맞춤 |

강사 DM은 공통 방의 참여자를 대상으로 제한한다. 강사에게 전체 운영자·강사 디렉터리나 단체방 개설/관리 권한을 추가하지 않는다. 기존 관리자 글로벌 DM 시작 기능은 유지한다. STAFF, 학생·학부모 채팅 권한 확대는 포함하지 않는다.

## 4. Acceptance (인수 기준)

현재 방장이 모든 참여자에게 동일하게 표시되고 위임 즉시 갱신된다. 일반 참여자의 초대·내보내기 직접 API 호출은 403이다. 타 학원/비참여자 접근과 본인 DM은 차단한다. 초대/강제 내보내기 동시 요청 시 다른 멤버 변경을 유실하지 않는다. 내보낸 사용자의 열린 방과 첨부파일·멘션 접근은 종료되며 다른 참여자의 대화 이력은 유지된다. 운영자→강사, 강사→운영자, 강사→강사 DM을 지원한다.

## Approved Layout Constraint (승인된 화면 조건)

2026-10-06 사용자 구현 승인. 관리자 채팅 참여자 목록은 **현재 우측 이용 팁 자리**를 교체하여 표시한다. 기존 패널 가리기/다시 보기 및 다른 페이지 이용 팁은 유지한다. 좁은 관리자 화면은 기존 패널 반응형 배치를 사용하며, 강사 포털은 참여자 대화상자를 사용한다. 운영 배포는 별도 요청 시 진행한다.
