# REQ-261027 Per-student bill registration from the list (목록에서 학생별 청구 등록)

## 1. Request (요청)
- 화면: `/admin/pay?view=detail` (수납 관리 > 청구 상세 목록)
- 증상: [청구 등록] → [미리보기] 시 `POST /api/acm/pay/bills/batch-preview` **400**, 화면에는 "처리하지 못했습니다" 만 표시.
- 요구: 청구 등록을 **목록에서 학생별로** 할 수 있도록 개선.
- 추가 요구(v1.1): **엑셀 일괄등록** — 입력할 엑셀 양식 다운로드 기능 포함.

## 2. As-Is Analysis (현황 분석)
### 2.1 400 원인 (코드 기준)
미리보기 요청 중 **한 행이라도** 아래에 걸리면 요청 전체가 400 으로 실패한다.

| # | 위치 | 조건 | 코드 |
|---|------|------|------|
| 1 | `CollectionsService.candidate` | 대화상자의 [수업] 에서 고른 수업을 선택 학생이 수강하지 않음 — [수업] 목록은 학생과 무관한 **테넌트 전체 수업** | `PAY_STUDENT_NOT_ENROLLED` |
| 2 | 〃 | 할인 > 청구액 (청구액 0 상태에서 할인 입력 등) | `PAY_INVALID_AMOUNT` |
| 3 | 전역 ValidationPipe | 납기·청구월을 지워 빈 값 | DTO 검증 400 |

- 프론트 `CreateDialog` 는 오류 코드를 무시하고 공통 문구만 표시 → 사용자는 원인을 알 수 없음 (`PAY_STUDENT_NOT_ENROLLED` 안내 문구는 이미 4개 언어로 있음).
- 운영 감사 로그로 어느 원인인지는 확인하지 못함(운영 DB 조회 권한 없음). 아래 개선은 세 원인을 모두 해소한다.

### 2.2 청구 등록 동선
- 상세 목록(청구 단위 행)에는 학생별 등록 수단이 없다. 상단 [청구 등록] → 학생 검색 → 한 명씩 추가 → 수업·항목·금액 입력.
- 월별 보기(학생 단위)에는 청구가 0건인 학생에게만 [생성](금액 미입력 초안) 버튼이 있다.

## 3. Requirements (요구사항)
| ID | 내용 |
|----|------|
| FR-1 | 상세 목록 각 행에 **[+ 청구]** 버튼 — 해당 학생이 선택된 상태로 청구 등록 대화상자를 연다 (청구월 = 행의 청구월, 지점 = 행의 지점). |
| FR-2 | 학생별 등록 시 [수업] 선택지는 **그 학생이 수강 중인 수업만** 표시. |
| FR-3 | 미리보기는 행 단위 판정 — 수강하지 않는 수업·금액 오류 행은 사유를 표시하고 제외, 나머지는 정상 미리보기 (400 으로 전체 실패하지 않음). |
| FR-4 | 오류 시 서버 오류 코드별 안내 문구 표시 (공통 문구 대신). |
| FR-5 | 납기·청구월·제목 미입력, 할인 > 청구액이면 [미리보기] 비활성 + 안내. |
| FR-6 | 월별 보기의 학생 행에도 [+ 청구] (청구가 이미 있어도 추가 청구 — 교재비 등) 제공. |
| FR-7 | [엑셀 일괄등록] — **입력 양식 다운로드**: 청구월·지점 기준 재원생이 한 줄씩 미리 채워진 xlsx (학생ID·학생명·지점 고정, 청구월·납기·항목·수업·제목·청구액·할인·메모 입력). 참고 시트: 항목 코드, 수업 목록(학생별 수강 수업 포함). |
| FR-8 | 작성한 xlsx 업로드 → 행 단위 검증 미리보기(행 번호·학생·금액·사유). 청구액이 빈 행은 자동 건너뜀. |
| FR-9 | 미리보기에서 정상 행만 [등록 확정] — 한 번에 최대 300행, 같은 요청 재전송 시 중복 생성 없음(기존 requestId·source key 규칙). |
| FR-10 | 양식 머리글은 화면 언어(ko/en/vi/zh-CN)로, 업로드 해석은 열 순서 기준이라 언어와 무관. |
| NFR | 4개 언어(ko/en/vi/zh-CN) 동시 반영, 기존 다중 학생 [청구 등록] 동작 유지. |

## 4. Out of Scope (범위 외)
- 기존 청구의 엑셀 일괄 **수정**(이번은 신규 등록만), 수납(입금) 엑셀 등록.
- 청구 금액 자동 산정(수업료 단가 연동), 일괄 금액 규칙.
