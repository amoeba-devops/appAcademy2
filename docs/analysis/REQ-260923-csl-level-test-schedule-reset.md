# Level Test Schedule Reset (레벨테스트 일정 초기화)

## 1. Request (요구사항)
상담 상세 레벨테스트에 지정된 날짜를 리셋(삭제)할 수 있게 한다. 시험 종류별로 해당 시험의 예약만 초기화한다.

## 2. Current Behavior (현재 구현 확인)
- `level-test-schedule-dialog.tsx`: 날짜·시간이 없으면 저장 불가. 빈값을 undefined로 전송하여 기존 날짜 삭제가 되지 않는다.
- `InquiryService.upsertLevelTest`: undefined는 유지, null은 삭제하는 분기가 있으나 타입 계약은 string만 명시한다.
- `InquiryController.upsertLevelTest`: 저장 후 날짜·시간이 모두 있을 때만 CAL 연동을 호출한다. 날짜만 비우면 기존 CAL 이벤트가 남는다.
- `CslCalLinkerService`: 각 시험의 calEventId로 일정 생성·수정을 수행한다. 초기화 처리 없음.
- `CalEventService.remove`: 일정 소프트 삭제·사유·삭제자 기록과 권한 확인을 제공한다. BODA 일정은 방 종료 부작용이 있어 초기화에서 연동 대상 검증이 필요하다.

## 3. Proposed Behavior (구현 제안)
1. 일정 설정 팝업에 `일정 초기화` 버튼 추가. 저장된 날짜 또는 시간이 있을 때 사용 가능.
2. 날짜와 시간을 함께 null 처리. 시험 행 자체, 담당강사, 진행상태, 점수·결과·비고, 상담 단계는 유지.
3. 같은 테넌트·동일 시험에 연결된 CAL 이벤트만 소프트 삭제하고 calEventId 해제. 다른 시험·데모수업·수동 일정은 변경하지 않는다.
4. 실제 초기화 전 팝업으로 연동 일정도 삭제됨을 안내. 취소하면 아무 변경 없음.
5. 초기화 후 응시예정일은 미지정으로 표시하며 새 날짜로 다시 예약 가능. 반복 초기화는 안전하게 처리하고 중복 일정 생성 방지.
6. 강사는 선택사항을 유지하며 날짜 초기화와 강사 해제를 구분한다.

## 4. Risks and Acceptance (영향·검수)
- 날짜 초기화와 CAL 정리가 부분 성공하지 않도록 동일 DB 트랜잭션으로 구현. 권한·대상 불일치 및 외부 미팅 연동 발견 시 변경 없이 오류 반환.
- 예약 변경/초기화 동시 요청은 동일 시험 행 잠금 및 예상 날짜·시간·연동 ID 비교로 충돌 감지. 기존 예약 변경 경로도 동일 잠금 규칙 적용.
- 현재 CAL에는 삭제 목록 열람만 있고 복구 API가 없음을 확인했다. 초기화로 삭제된 일정은 상담에서 재예약한다.
- 등록/수정/초기화/재예약, 여러 시험 중 한 건만 초기화, 권한·테넌트 격리, 이미 삭제된 CAL, 강사 미지정, 완료 시험 결과 보존, 실패 롤백을 검증.
