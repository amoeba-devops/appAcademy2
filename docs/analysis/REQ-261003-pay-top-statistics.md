# Payment Header Statistics (수납관리 상단 통계)

## 1. Request (요청)

`/admin/pay` 상단에 사용자 첨부 `tpi-11.png`처럼 통계 그래프를 표시한다. 이미지의 원생현황 복합 그래프와 두 달 수납현황 원형 그래프를 화면 구조의 기준으로 삼는다. 이미지의 인원·비율·월 값은 예시이며 운영 데이터에 입력하지 않는다.

## 2. Existing Implementation (기존 구현 확인)

- `frontend-acm/src/modules/pay/payment-page.tsx`: 월별 보기/기간 상세조회/통계 대시보드와 월·사이트 상태가 있다.
- `monthly-payment-view.tsx`, `monthly-types.ts`: 월별 재원생, 금액 미입력/미등록, 청구·누적 수납·미납·사이트 비교를 지원한다.
- `backend/src/modules/acm-pay/application/monthly-pay.ts`: 최근 12개월 금액 추이를 제공한다. 기존 `trend`에는 이미지와 같은 월별 원생 4종 추이 및 청구 건수별 완납 비율이 없으므로 API 확장이 필요하다.
- `resolveMonthlyStudents`는 해당 월에 하루 이상 재원한 학생을 재원기간으로 판정한다. 입원일 누락, 미확정/중복 기간 등은 확인 필요로 구분한다.
- 학생 상태에 ACTIVE/INACTIVE/WITHDRAWN이 있고 한국어 INACTIVE 표시는 휴원이다. `StudentService.changeStatus`는 현재 상태와 수정시각만 갱신하므로 과거 휴원 발생월을 복원할 수 없다. 기존 퇴원 원본에도 휴원여부/사유는 있으나 신뢰할 수 있는 월별 휴원 시작일로 간주할 수 없다.

## 3. Proposed Definitions (집계 기준 제안)

| 통계 | 기준 |
|---|---|
| 표시 기간 | 선택 월을 포함한 최근 3개월 원생 추이, 이전 월과 선택 월의 수납현황 |
| 재원생 | 기존 월별 명단과 같은 월중 하루 이상 재원한 학생, 월별 학생 ID 중복 제거 |
| 신규원생 | 첫 입원일이 해당 월인 학생. 복귀를 신규로 중복 집계하지 않음 |
| 휴원생 | 해당 월에 휴원을 시작한 학생. 날짜가 확인되는 상태 이력 기준 |
| 퇴원생 | 해당 월에 퇴원한 학생. 확정 퇴원일/상태 이력 기준; 단순 재원기간 종료나 사이트 이동을 퇴원으로 간주하지 않음 |
| 완납 | 해당 청구월의 확정된 양수 순청구액 중 현재 잔액 0인 청구 건수 |
| 미납 | 동일 범위에서 현재 잔액이 양수인 청구 건수. 부분납부 및 납기 전 잔액도 포함 |
| 원형 그래프 비율 | 완납 또는 미납 건수 ÷ 두 건수 합계 × 100. 인원·금액 비율과 구분 |
| 제외 항목 | 금액 미입력, 취소, 0원/면제 청구는 원형 그래프 분모에서 제외하고 보조 건수 표시 |
| 기준 시각 | 청구월별 현재 납부상태. 과거 월말 당시의 스냅샷이 아님 |

원생 숫자는 명, 수납은 건/%로 표시한다. 복수 청구가 있는 학생은 원생 통계 1명, 수납 통계 각각의 청구 건으로 센다. 사이트는 학생의 해당 기간 소속 근거와 청구의 저장된 사이트를 각각 사용하며 사이트 이동을 신규 입원으로 세지 않는다.

## 4. Data Quality (데이터 보완)

휴원/복귀/퇴원 및 사이트 변경의 유효일과 상태 이력을 남길 수 있도록 기존 학생 수정·상태 변경 경로를 보완하는 방안을 포함한다. 적용 이전 이력은 확정 날짜만 이관하고 현재 상태나 updated_at으로 과거 발생일을 추정하지 않는다. 날짜가 불명확한 월은 휴원/퇴원 시리즈를 0으로 연결하지 않고 ‘이력 확인 필요’ 또는 미집계로 표시한다. 확인된 0과 자료 부족을 구분한다.

기존 운영 재원기간과 신규 상태 이력을 함께 쓰되 각각을 이중 집계하지 않는 공통 판정 기준을 둔다. 사용자가 과거 유효일을 보정할 수 있어야 하며 재원 목록과 그래프의 차이는 확인 필요 건수로 설명한다.

## 5. Acceptance (완료 기준)

- 수납관리 진입 시 이미지와 같은 3개 그래프가 상단에 나타난다.
- 월·사이트 변경 시 그래프 전체가 함께 갱신되고 이전 요청 응답이 새 필터 결과를 덮어쓰지 않는다.
- 검색/목록 페이지/납부상태 필터가 그래프의 전체 집계 분모를 바꾸지 않는다.
- 대상 청구 0건일 때 100% 완납으로 보이지 않는다. 금액 미입력은 별도로 안내한다.
- 월 경계, 연도 변경, 휴원·복귀, 사이트 이동, 부분납부·환불·취소·중복 청구에 대해 기준이 일관된다.
- 모바일에서는 그래프를 세로로 배치하고, 값은 마우스 없이도 읽을 수 있다.
