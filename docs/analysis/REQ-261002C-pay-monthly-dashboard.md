# Monthly Payment View (월별 수납 및 통계 요구사항)

## 1. Request (요청)

`/admin/pay`에 월별 보기, 해당 월 재원학생 기준 노출, 사이트별 보기, 통계 대시보드를 추가한다.

## 2. Current State (현황)

- 기존 payment-page.tsx는 청구월 시작/종료 필터와 청구 원장 목록·금액 요약을 제공한다. 사이트 필터는 상세검색 안에 있다.
- CollectionsService.list는 청구 행 기준으로 조회한다. 학생 현재 상태를 연결하므로 청구 없는 월별 재원생 명단 및 과거 재원 판단을 충족하지 못한다.
- 학생 시작/종료일, 입원/퇴원일 및 amb_acm_dsh_operating_period의 복수 재원 기간·사이트 이력이 존재한다. 현재 ACTIVE 조건만으로 과거 월을 판정하면 안 된다.
- 월 재원 기준 집계, 사이트별 비교, 월 추이, 청구 미등록 인원 집계는 추가 구현이 필요하다.
- 운영 데이터의 기간 이력 누락 규모는 아직 조회하지 않았다. 기존 금액 미입력 DRAFT와 청구 없음은 구분해야 한다.

## 3. Proposed Rules (판정 및 표시 제안)

1. 기본 진입은 이번 달, [이전 달] [YYYY-MM] [다음 달] [이번 달] 제공. 기존 기간 상세조회도 별도 탭으로 유지한다.
2. 월 재원생은 해당 월 중 하루 이상 재원 기간이 겹친 학생으로 제안한다. 월말 재원 인원과 구분한다. 확정·미취소 운영 기간 우선, 이력 없는 경우 기존 학생 시작/종료일 기준을 공통 대시보드 판정과 일치시킨다. 종료일 포함 여부도 기존 공통 서비스의 반개구간 규칙을 따른다.
3. 기간이 누락/충돌한 학생은 확인 필요 목록과 인원에 표시한다. 현재 ACTIVE만으로 과거 재원 상태를 자동 생성하지 않는다. 현재 재원생도 날짜 부족 시 누락 사실을 확인할 수 있어야 한다.
4. 월별 목록은 학생당 1행: 학생/사이트/재원기간/청구상태/합산금액/상세. 복수 청구는 상세에서 조회·편집한다. 청구 없는 학생도 표시하고 실제 청구는 명시적 등록 때만 생성한다.
5. 사이트는 상단 [전체/TPI/Trinity Academy/Santa Croce/미지정]. 학생 재원 소속은 해당 기간 이력, 청구 금액은 청구의 사이트 스냅샷 기준. 사이트 이동 학생은 해당 사이트에서 재원한 경우 표시하고 전체 인원은 학생 ID로 중복 제거한다. 사이트별 인원 합이 전체와 다를 수 있음을 안내한다.
6. 월 재원 대상과 별도로 해당 월 기존 청구 전체를 볼 수 있어야 한다. 퇴원생 미납·대상 외 청구를 숨기거나 원장을 삭제하지 않는다.
7. 청구 없음, 금액 미입력, 미납, 부분납, 완납, 납부불필요를 구분한다. DRAFT/미등록 금액은 0원 확정과 구분하고 금액 합계·수납률 분모에서 제외한다.

## 4. Dashboard (통계 기준)

- 인원: 월 재원생(고유 학생), 청구 미등록 학생, 금액 미입력 학생/건수, 확정 청구 학생, 미납 학생. 기간 확인 필요는 별도 표시.
- 선택 월 청구 기준: 순청구액, 연결된 누적 순수납액(납부-환불), 현재 미납액, 수납률. 수납률은 확정 순청구액이 양수일 때만 계산하며 0 분모는 ‘—’. 기준일을 표시한다.
- 실제 수납일 기준: 선택 월 납부액·환불액·순수납액. 과거 월 청구에 대한 이번 달 납부도 포함한다. 위 청구월 기준 수납과 섞지 않는다.
- 최근 12개월 청구/수납 추이, 사이트별 비교표, 미납 상위 목록. 학생 인원은 청구 조인 중복 없이 집계하고 통화별로 분리한다.
- 월 재원 대상 집계와 월 전체 원장 집계는 범위를 명시한다. 과거 월 청구의 현재 수납 상태는 후속 납부에 따라 바뀔 수 있으며 ‘당시 월말 잔액’으로 표현하지 않는다.

## 5. Constraints (제약)

테넌트 격리 및 기존 관리자/직원 권한 유지. 조회 동작으로 청구·금액·납부 내역 생성 없음. 엑셀·목록·집계는 동일 범위를 적용하며 상세 기간조회도 유지한다. 모든 문구 4개 언어 지원. 기존 재원생 51건 및 미입력 의미 보존.


## Implementation Update (구현 반영)

2026-10-02 사용자 “구현” 승인 후 구현 완료. 첫 재원 경계는 기존 대시보드와 같은 입원일 기준이며, 복귀 이후 확정 기간 및 종료일 제외 규칙을 공통 함수로 사용한다. 입원일 누락·확정되지 않은 기간·종료일 없는 비재원·중복 기간은 확인 필요로 구분한다. 사이트 미지정 조회와 과거 월 재원생 청구 생성도 지원한다. 수납 원장은 현재 KRW 단일 통화 구조로 유지한다.

운영 읽기 전용 점검: 전체 학생 299명, 현재 재원 51명, 현재 재원생 입원일 누락 0명. 전체 입원일 누락 177명, 비재원 중 학생 마스터 종료일 누락 175명, 운영 재원 이력 91건 중 미확정 1건. 이 수치는 원천 필드 점검이며 해당 월 최종 재원/확인 필요 인원과 동일하지 않다. 원천 데이터 자동 보정은 수행하지 않았다.

검증과 제한은 [구현 보고서](../report/RPT-261002C-pay-monthly-dashboard.md)를 참조한다. 2026-10-02 운영 배포 완료.
