# REQ-261103 Class Schedule Editor — Students First & Manual Time (수업일정 등록 — 학생 먼저·시간 직접 입력)

## 1. Request (요청)
`/admin/cal` 수업일정 **등록/수정** 화면에서
1. "참석자" 이름을 **"참석자/학생"** 으로 바꾸고, 위치를 **담당자/강사 선택 위**로 옮긴다.
2. 학생을 선택하면 **제목에 학생 이름이 자동 입력**된다. 사용자가 고칠 수 있다.
3. 시간은 지금의 **30분 단위 선택**을 유지하고, 오른쪽에 **직접 입력칸**을 추가한다.

## 2. As-Is (현재, 9a7e08b)
| 항목 | 현재 |
|------|------|
| 화면 순서 | 제목 → 구분 → 담당자/강사 → 시작·종료 → 장소 → 설명 → 화상 → 첨부 → **참석자(맨 아래)** |
| 참석자 | 별도 묶음 "참석자 (n)", [+ 참석자 추가] → 학생·강사·학부모 검색 창. 레벨테스트 구분이면 숨김 |
| 제목 | 직접 입력만 (필수) |
| 시간 | 06:00~23:30, 30분 간격 선택. 저장된 값이 30분 단위가 아니면 그 값을 목록 맨 위에 추가 |
| 파일 | `frontend-acm/src/modules/cal/components/cal-event-modal.tsx` |

## 3. Requirements (요구사항)
| ID | 내용 |
|----|------|
| FR-1 | 참석자 묶음 제목을 **"참석자/학생 (n)"** 으로 변경(4개 언어). |
| FR-2 | 참석자 묶음을 **구분 아래·담당자/강사 위**로 이동. 레벨테스트에서 숨기는 규칙은 유지. |
| FR-3 | 학생(STUDENT)을 추가·삭제하면 제목을 학생 이름으로 채운다. 강사·학부모 참석자는 제목에 넣지 않는다. |
| FR-4 | 사용자가 제목을 직접 고치면 그 뒤로는 자동으로 덮어쓰지 않는다. 수정 화면의 기존 제목도 덮어쓰지 않는다(제목이 비어 있을 때만 채움). |
| FR-5 | 시작·종료 시간 선택 오른쪽에 **직접 입력칸(시:분, 1분 단위)**. 입력하면 선택 목록에도 그 값이 보이고, 선택을 바꾸면 입력칸도 같이 바뀐다. |
| FR-6 | 직접 입력은 00:00~23:59 모두 허용. 기존 검증(종료 > 시작 등)은 그대로. |
| NFR | 4개 언어, 모바일 규칙(입력 16px·터치 36px+), 서버·DB 변경 없음. |
