# Class Schedule — Link Students by Title (수업 일정 — 제목의 학생 이름으로 참석자 일괄 연결)

## 1. Overview (개요)
REQ-261023 후속. 강사 피드백 "학부모 메일 발송" 받는 사람을 반 수강생까지 넓혔으나(#382) 효과가 없었다. 원인은 **수업 일정에 학생이 연결돼 있지 않은 데이터**다. 사용자 승인: 제목의 학생 이름으로 참석자를 일괄 연결하는 관리자 기능.

## 2. Findings (운영 DB 읽기 전용, 2026-10-23)

| 항목 | 값 |
| --- | --- |
| 10월 정규 수업 | 386건 — 모두 수동 등록(`evt_source=MANUAL`), 반 연결(`evt_cls_id`) **0건**, 학생 참석자 **8건**, 담당 강사 354건 |
| 제목 형태 | 학생 이름이 제목에만: "송시율", "김라엘 (오프라인)", "이윤건, 이윤후 (오프라인)" (ICS 가져오기 일정으로 추정, REQ-260930) |
| 영향 | ① 강사 피드백 학부모 메일 받는 사람 없음 ② **학생·학부모 포털에 그 수업이 안 보임**(포털 범위 = 학생 참석자 또는 반 수강생) |
| 정리 대상 (7일 전 ~ , 학생 참석자 없는 정규 수업) | **186건**, 제목 **43종**, 반복 수업 24건(8개 반복), 마지막 11-30 |
| 제목 ↔ 학생 이름 일치 | 1명 143건 · 2명 이상 20건 · 없음 23건 |
| 2명 이상 일치 예 | "이윤건, 이윤후 (오프라인)" → 형제 2명(정상) / "김민재" → 김민·김민재, "이서준" → 서준·이서준 (**부분 이름 오탐**) |
| 일치 없음 예 | "수업 가능 시간" 15건, "유니스탁" 7건, "수업 어려움" 1건 |
| 포털 계정 | 학생 9 · 학부모 8 · 강사 5 (활성) — **연결해도 계정이 없는 학생·학부모는 포털에 못 들어옴** |

## 3. Functional Requirements (기능 요구사항)

| ID | 요구사항 |
| --- | --- |
| FR-1 | 운영 콘솔 **수업 일정 > "학생 연결 정리"** 화면(관리자 ADMIN·APP_ADMIN) |
| FR-2 | 기간(기본: 7일 전 ~ 90일 후)·분류(기본 정규 수업) 안에서 **학생 참석자가 없는 일정**을 **제목별로 묶어** 보여 줌: 제목 · 일정 수 · 기간 · 담당 강사 · 반복 여부 · 찾은 학생 |
| FR-3 | 학생 찾기 규칙: 제목에 학생 이름(2자 이상, 삭제·퇴원 제외 옵션)이 들어 있으면 후보. **긴 이름 우선** — 다른 후보 이름의 일부인 후보는 제외(김민재 ⊃ 김민). 결과 상태: 확실(1명) · 여러 명 · 없음 |
| FR-4 | 관리자가 묶음마다 학생을 **선택·해제**(여러 명이면 기본 모두 선택 해제 상태로 확인 요구), 없음 묶음은 학생 검색으로 직접 지정 가능 |
| FR-5 | [선택한 묶음 연결] → 그 제목의 대상 일정 전체에 학생을 **참석자(STUDENT)** 로 추가. 이미 있으면 건너뜀. **메일 발송 없음** |
| FR-6 | 반복 수업: 대상 회차 + **반복 원본**에도 학생 추가(이후 자동 연장 회차에도 포함) |
| FR-7 | 결과 요약(연결 일정 수·학생 수·건너뜀) + 감사 활동 로그 + 일정 수정 이력(사유 "제목 기반 학생 연결") |
| FR-8 | 연결 후 해당 학생·학부모 중 **포털 계정이 없는 사람 수**를 함께 안내(계정 발급은 기존 포털 계정 화면에서) |
| FR-9 | 미리보기는 DB 를 바꾸지 않음. 연결은 한 번에 한 트랜잭션, 재실행 안전(멱등) |
| FR-10 | 4개 언어, 운영 콘솔 UI 표준, 모바일 카드 |

## 4. Out of Scope (범위 외)
- 일정 제목 변경·삭제, "수업 가능 시간" 같은 비수업 일정 분류 변경
- 포털 계정 일괄 발급(기존 화면 사용; 필요 시 별도 요청)
- 과거(기간 밖) 일정 자동 정리 — 기간을 넓혀 같은 화면으로 처리 가능
