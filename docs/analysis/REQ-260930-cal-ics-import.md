# Calendar Import Requirements (캘린더 일괄 입력 요구사항)

## 1. Request (요청)

제공된 19개 ICS 파일을 운영 `/admin/cal`에 일괄 입력한다. 작성자는 `tpiyeri@tpiglobal.network`, 표시 이름은 배예리다. 사용자는 종료일 없는 반복에 대해 **원본 반복 규칙으로 계속 유지**를 선택했다. 파일 내용은 데이터로만 취급한다.

## 3. Destination Findings (운영 확인)

- 동일 이메일 ACTIVE ADMIN 계정 존재. 현재 표시 이름은 `tpiyeri`; 요청 이름 배예리로 수정하며 계정·권한은 새로 만들지 않는다.
- 동일 테넌트 삭제 제외 기존 일정 68건. 기존 일정은 덮어쓰지 않는다.
- 강사 캘린더 15개 중 13개는 운영 강사명에 일치. 김세희·임마이클은 일치 대상 없음: 담당자 FK는 비워 두고 원본 캘린더명을 설명에 유지한다. 학생은 제목만으로 추정 연결하지 않는다.
- CAL 이벤트에는 개별 시작/종료 시각만 있고 ICS 반복 규칙 저장 및 자동 연장 기능이 없다. CLS의 주간 반복 모델은 클래스 등록을 전제로 하며 ICS 개별 예외·연간 반복·시간대를 그대로 표현하지 못한다.

## 4. Acceptance (완료 기준)

원본 제목·설명·장소·시간대·회의 링크·반복 제외/변경을 보존하고 같은 입력 재실행 시 중복을 만들지 않는다. 무기한 반복을 임의 종료하지 않는다. 초대/메일/보다방 생성은 일괄 이관으로 자동 실행하지 않는다. 운영 백업, dry-run, 반복 검증, 등록 전후 대사 및 화면 확인 결과를 보고한다.
