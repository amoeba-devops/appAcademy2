# REQ-261102B Notification Settings (알림 설정)

## 1. Request (요청)
서비스 설정(`/admin/config`) 화면에 **알림 설정** 메뉴를 만들어, 모든 알림 상황의 설정을 한 곳에서 관리한다.
모바일·웹·PC 등 모든 접속 기기와 알림 발송에 필요한 설정을 구현한다.

## 2. As-Is (현재, ea67f48)

### 2.1 Channels (알림 경로)
| 경로 | 동작 | 현재 설정 위치 |
|------|------|----------------|
| 앱 내 알림함 (🔔) | outbox → inbox, 5초마다 배달 | 없음 (항상 켜짐) |
| 기기 푸시 (휴대폰·PC 브라우저·PWA) | 알림함에 들어온 안 읽은 알림 → Web Push, 10초마다 | 서버 VAPID 키(env)만, 기기별 [켜기/끄기]는 사용자 |

### 2.3 Problems (문제)
- 상황별로 켜고 끌 수 없다. 받는 사람(역할)도 코드에 고정돼 있다.
- 푸시는 밤에도 그대로 발송된다(방해 금지 시간 없음). 채팅 내용은 잠금 화면에 항상 보인다.
- 기기(휴대폰/PC)별로 몇 대가 구독 중인지, 발송이 성공하는지 운영자가 볼 수 없다.
- 피드백 미완료 알림 시간(5·10시간)이 고정이다.
- 알림 관련 설정이 메일·카카오·AMA 페이지에 흩어져 있다.

## 3. Requirements (요구사항)
| ID | 내용 |
|----|------|
| FR-1 | `/admin/config` 에 **알림 설정** 카드 → `/admin/config/notifications` (서비스 운영자 `CONFIG_ADMIN` 만). |
| FR-2 | **상황별 설정표**: 각 상황(2.2)마다 경로(알림함·기기 푸시·화면 팝업·AMA·메일·알림톡) 켜기/끄기. 그 상황에 없는 경로는 '—'. |
| FR-3 | **받는 사람**: 상황별로 받을 역할(관리자·직원·강사) 선택. 채팅·멘션처럼 대상이 정해진 상황은 고정 표시. |
| FR-4 | **기기 푸시 공통**: 전체 켜기/끄기, **방해 금지 시간**(예: 22:00–08:00, 학원 시간대 기준), 잠금 화면 **채팅 내용 표시** 켜기/끄기. |
| FR-5 | **기기 현황**: 기기 종류별(휴대폰·PC) 구독 수, 최근 7일 발송 성공·실패, 서버 푸시 키 설정 여부. **[내 기기로 테스트 알림]** 버튼. |
| FR-6 | **피드백 미완료 알림 시간**: 1차·2차 시간(기본 5·10시간) 변경. |
| FR-7 | 메일·카카오·AMA 연결 상태를 한 줄로 보이고 각 설정 페이지로 이동 링크. |
| FR-8 | 기본값 = 현재 동작. 배포 직후 알림 동작이 바뀌지 않는다. |
| NFR | 4개 언어, 모바일 규칙(입력 16px·터치 36px+), 변경 이력은 활동 로그에 남김, 테넌트별(`ent_id`) 저장. |

## 4. Open Questions (확인 필요)
| # | 질문 | 권장안 |
|---|------|--------|
| Q1 | 설정 범위 — 학원(테넌트) 전체만 vs 사용자 개인별 설정도 | **학원 전체만**(이번 범위). 개인은 지금처럼 기기별 [켜기/끄기]만. 개인별 상황 선택은 다음 단계 |
| Q2 | 방해 금지 시간에 온 알림 — 끝나면 보내기 vs 버리기 | **끝나면 보내기**(알림함에는 바로 들어가고, 푸시만 미룸. 그사이 읽으면 안 보냄) |
| Q3 | 신규 상담 팝업(지금은 '알림 필수'로 닫을 때까지 유지) — 끌 수 있게 vs 고정 | **끌 수 있게**, 기본은 켜짐·유지 |
| Q4 | 기기 종류 구분 — 기기를 켤 때 휴대폰/PC 정보 저장(새 컬럼) | **저장**(화면 크기·브라우저 정보로 판단, 기존 구독은 '알 수 없음'으로 표시, 다음 접속 때 갱신) |

## 5. Decisions (결정, 2026-11-02)
| # | 결정 |
|---|------|
| Q1 | **학원 전체 + 개인별**. 개인은 학원이 켠 알림 중 상황별 알림함·푸시·팝업만 끌 수 있고(켜기는 학원 설정 범위 안), 개인 방해 금지 시간도 둔다. 🔔 › 알림 설정 창에서 설정. |
| Q2 | 방해 금지 시간 푸시는 **끝나면 보내기**(그사이 읽으면 생략). 학원·개인 시간이 겹치면 늦게 끝나는 쪽. |
| Q3 | 신규 상담 팝업은 **항상 켜짐 고정**(학원·개인 모두 끌 수 없음). |
| Q4 | 기기 종류 **저장**(MOBILE/DESKTOP). |

### 5.1 Scope notes (범위 메모)
- 일정 초대 메일은 일정마다 보낼지 고르는 방식이라 이번 설정표에서 제외했다(2.2의 CAL_INVITE). 비밀번호·사용자 초대 메일, 수업 피드백 발송도 사람이 직접 보내는 것이라 제외.
- 받는 역할은 **좁히기만** 가능(예: 상담 알림에 강사 추가 불가 — 강사는 상담 화면 권한이 없음).
- 알림함을 끄면 같은 상황의 푸시·AMA 전달도 꺼진다(둘 다 알림함 배달을 기준으로 동작).
