# REQ-261119 KST time basis for all statistics (모든 통계·기준 시간 한국시간 집계)

## 1. Overview (개요)
모든 통계와 기준 시간(오늘, 이번 달, 기간 경계)은 한국시간(테넌트 시간대, 기본 `Asia/Seoul`)으로 계산한다.
운영 서버·DB·컨테이너는 UTC 이며, 일부 코드만 한국시간을 쓰고 나머지는 UTC 로 계산되어 한국 00:00~09:00 에 날짜가 하루 어긋나거나 시각이 9시간 밀린다.

## 2. Current State (현황, 2026-11-19 운영 확인)
| 항목 | 상태 |
|---|---|
| DB `timezone` | `Etc/UTC` |
| backend / frontend 컨테이너 `TZ` | 미설정 (UTC) |
| 테넌트 시간대 설정 (3곳) | `Asia/Seoul` |
| 이미 한국시간인 곳 | 대시보드 일별 지표, 접속·활동 로그, 강사 정산, 학부모 포털 주간 수업, 학생 연결, 예약 작업 7개 |
| **데이터 오류** | 반복 수업 회차(`amb_acm_cls_sessions`) 53건 전부 +9시간 저장 (월 15:00 → 화 00:00) |

컨테이너 TZ 변경(C안)은 DATE 컬럼이 서버 로컬 0시 Date 로 읽혀 `toISOString().slice(0,10)` 날짜가 하루씩 당겨지므로 채택하지 않는다.

## 3. Requirements (요구사항)
| ID | Requirement |
|---|---|
| FR-1 | 저장은 UTC(timestamptz) 그대로, '오늘·월·기간 경계·표시 시각'은 테넌트 시간대로 계산한다 |
| FR-2 | 반복 수업 회차 생성 시 시작 시각을 테넌트 시간대 벽시계로 해석한다 |
| FR-3 | 백엔드에서 '오늘'을 UTC 로 구하는 곳(기준표·가이드·레벨테스트 기준일, 알림톡 #{일시}, 수업 완료일, 연도 등)을 공통 헬퍼로 교체 |
| FR-4 | timestamptz 기간 필터(맵테스트 신청일 등)의 날짜 경계를 한국시간 0시로 |
| FR-5 | 환불 정책 적용일 `CURRENT_DATE` 를 한국시간 날짜로 |
| FR-6 | 즉시 강의 기본 제목의 시각을 한국시간으로 |
| FR-7 | 프론트 기본값(수납 월·납부일, 수업 시작일, 기준표 날짜, 대시보드 수동 입력 등)의 '오늘'을 `todayYmd(tz)` 로 |
| FR-8 | 운영 반복 수업 회차 53건 -9시간 보정 (실행 전 대상 확인, 운영 쓰기 승인) |
| FR-9 | 새 코드에 UTC '오늘' 패턴이 들어오지 않도록 검사 추가, CLAUDE.md 에 규칙 명시 |

## 4. Out of Scope (범위 밖)
- 서버·DB·컨테이너 시간대 변경
- 이미 한국시간으로 계산되는 집계의 정의 변경
