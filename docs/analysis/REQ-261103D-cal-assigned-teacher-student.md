# REQ-261103D Calendar-Assigned Teacher & Student (수업일정 배정 강사·학생 노출)

## 1. Request (요청)
1. 학생정보(학생 상세)에 **수업일정에서 배정된 강사**가 노출되어야 한다.
2. 강사 포털 수강생관리에 **수업일정에서 배정된 학생**도 나와야 한다.

## 2. As-Is (현재, f700783)
| 항목 | 현재 |
|------|------|
| 수업일정의 강사 | `amb_acm_cal_event.evt_assignee_tch_id`(강사 선택) + 참석자 `amb_acm_cal_invitee` `inv_kind='TEACHER'` |
| 수업일정의 학생 | 참석자 `amb_acm_cal_invitee` `inv_kind='STUDENT'` (`inv_ref_id` = std_id) |
| 학생 상세 강사 | 학생관리 배정(`amb_acm_std_student_teacher`)만. 수업일정 강사는 안 보임 |
| 강사 포털 수강생 | `std_teacher_id` ∪ 학생관리 배정 ∪ 반 소속. 수업일정 참석 학생은 빠짐 |

## 3. Production Data (운영 확인, 2026-11-03 SELECT 만)
| 항목 | 값 |
|------|----|
| 학생이 참석자로 연결된 일정 | 210건 (전체 6,258건 중) |
| 수업일정 강사·학생 조합 | 53개 (학생 41명 · 강사 12명) |
| 그중 학생관리 배정 없는 조합 | **14개** — 지금 어느 화면에도 연결이 안 보임 |

## 4. Requirements (요구사항)
| ID | 내용 |
|----|------|
| FR-1 | 수업일정 강사·학생 조합 = 삭제 안 된 **최근 90일 ~ 앞으로** 일정에서 [강사 선택 또는 TEACHER 참석자] × [STUDENT 참석자]. 삭제된 학생·강사 제외 |
| FR-2 | 학생 상세에 **수업일정 강사** 묶음: 강사명 · 일정 수 · 최근/다음 수업일. 학생관리 배정 강사와 구분 표시 |
| FR-3 | 강사 포털 수강생 목록에 수업일정 학생 추가(중복 제거). 상세 접근도 허용. 목록에 출처 표시(배정 / 반 / 수업일정) |
| FR-4 | 조회 시 합산만 — 학생관리 배정 데이터는 바꾸지 않음(일정 삭제·변경 시 자동 반영) |
| NFR | 4개 언어, 모바일, 통합 테스트 |

## 5. Decisions (결정, 2026-11-03)
| # | 결정 |
|---|------|
| Q1 | **조회 시 합산** — 학생관리 배정 데이터 변경 없음 |
| Q2 | **최근 90일 + 앞으로** 일정만 |
| Q3 | 수업일정 학생에게도 강사 수업링크 입력 **허용** (학생 포털 수업정보에도 그 강사 표시) |
| Q4 | 화면 계획서대로 |
