# REQ-261030B Read-only list amounts, label changes & instant save (목록 금액 읽기 전용·문구 변경·즉시 저장)

## 1. Request (요청)
1. `/admin/pay?site=UNASSIGNED&view=monthly` — **미지정은 포함 안 함**.
2. 청구 상세 목록의 청구액·할인액 칸: 입력 가능한 것으로 오해 → **읽기 전용 표시**, 마우스 클릭(포커스) 시 바로 수정 창. 표시 폭 9자리까지.
3. 마지막 열 버튼 `수정 (1)`·`+ 청구` → 모두 **청구**.
4. 상태 문구: 청구 없음 → **미청구**, 미납 있음 → **미납**, 금액 미입력 → **금액수정**.
5. 금액수정(금액 미입력 청구)에서 금액을 넣으면 **바로 저장**.
6. 청구 없는 학생의 [청구] → 입력 후 **바로 저장하고 창 닫기**. 청구 추가는 청구가 있는 학생의 수정 창에서.

## 2. Requirements (요구사항)
| ID | 내용 |
|----|------|
| FR-1 | 사이트 선택(월별 목록·청구 상세·대시보드·엑셀 일괄등록)에서 '미지정' 항목 제거. 전체 범위 처리는 Q1. |
| FR-2 | 청구 상세 목록의 청구액·할인액은 숫자 텍스트(최대 9자리, 쉼표 포함 폭 고정·오른쪽 정렬)로 표시, 셀 클릭/Enter 시 해당 학생 청구 창 열림. 목록 직접 입력·[변경 저장]·[취소] 제거(기본 납기는 새 청구 기본값으로 유지). |
| FR-3 | 마지막 열 버튼 문구 `청구` 하나. |
| FR-4 | 상태 문구 변경(4개 언어): NONE=미청구, UNPAID=미납, DRAFT=금액수정. |
| FR-5 | 청구 창에서 금액 미입력(DRAFT) 청구의 청구액을 입력하고 Enter 또는 칸을 벗어나면 즉시 저장. |
| FR-6 | 청구 없는 학생: 간편 입력 창 → [저장] 시 등록 후 창 닫힘. 청구 있는 학생: 기존 수정 창(청구 추가 포함). |
