# REQ-261103C Portal Class Links & Teacher Student List (포털 수업링크 메뉴·강사 수강생 누락)

## 1. Request (요청)
1. 강사 포털 `/portal/students` 수강생관리에 **학생관리에서 강사 배정한 학생이 누락**됨 (강사 정성경 · 학생 김익용).
2. 수업링크 **Google Meet/https 주소 검증 폐기** — 인터넷 링크 모두 허용.
3. 학생 포털 좌측 **수업일정 아래 "수업링크" 메뉴** 추가 — 강사별 링크 목록.

## 2. As-Is (현재, d5ed848)
| 항목 | 현재 |
|------|------|
| 강사 수강생 목록 | `PortalTeacherStudentsService.listMyStudents` = `std_teacher_id` ∪ `amb_acm_std_student_teacher`(학생관리 강사 배정) ∪ 반 소속. 기준은 **포털 계정의 `pac_ref_id`(= tch_id)** |
| 수업링크 검증 | 서버 DTO `@IsUrl({protocols:['https'], require_protocol:true})`, 화면 `isHttpsUrl` — https 아니면 저장 거부 |
| 포털 수업정보 | `/portal/calendar` 달력 아래 카드(과목·교재·[수업 입장]). 별도 메뉴 없음 |

## 3. Analysis — 항목 1 (누락 원인)
- 코드는 학생관리 강사 배정(`amb_acm_std_student_teacher`)을 이미 포함한다. 같은 강사·학생 조합은 통합 테스트로도 노출됨.
- 따라서 **데이터 불일치**가 유력:
  - (a) 강사 "정성경"이 `amb_acm_tch_teacher` 에 **2건**(AMA 동기화분·수기 등록분 등) — 포털 계정은 A, 학생 배정은 B.
  - (b) 학생 "김익용" 이 소프트 삭제/다른 테넌트, 또는 배정 저장이 실제로 안 됨.
- 운영 DB 읽기(SELECT)로 확인 필요 → 원인별 조치(중복 강사 병합 SQL 또는 코드 수정).

### 3.1 운영 확인 결과 (2026-11-03, SELECT 만)
| 항목 | 값 |
|------|----|
| 강사 정성경 | 1건(`16c31d48…`), 포털 계정 `pac_ref_id` 도 같은 행 — 중복 아님 |
| 학생 "김익용학생등록" (`906d7c4f…`) | 2026-09-18 **삭제**됨. 이 행에 정성경 배정이 있었음 |
| 학생 "김익용" (`1cf5baf5…`) | 2026-11-03 06:55 UTC 새로 등록. **강사 배정 0건**(`amb_acm_std_student_teacher`·수업정보 행 없음). 감사 로그: 등록 1회·이메일 수정 1회, 이후 강사 변경 없음 |

→ **코드 결함 아님**. 현재 김익용 학생에는 강사가 배정되어 있지 않다. 학생관리 수정 화면에서 정성경을 선택·저장하면 강사 포털에 바로 나타난다(조회 조건에 이미 포함). 로컬에서 등록·수정 화면으로 강사 배정 → 강사 포털 목록 표시까지 확인.
