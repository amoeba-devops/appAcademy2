> frontend-acm 에는 테스트 러너가 없어(`package.json` 에 test 스크립트 부재) **화면 동작은 자동 검증되지 않는다.** 아래 체크리스트는 사람이 확인해야 한다.

## 2. 수동 검증 체크리스트

브라우저 개발자도구의 디바이스 툴바에서 폭을 바꿔가며 확인한다.

### 2.1 셸 — 375px (모바일)

- [ ] 헤더 좌측에 **☰ 버튼**이 보이고, 누르면 메뉴가 왼쪽에서 슬라이드로 열린다
- [ ] 열린 상태에서 **오버레이 탭 / ESC / 우상단 ✕ / 메뉴 선택** 으로 닫힌다
- [ ] 메뉴가 닫힌 상태에서 본문이 화면 전체 폭을 쓴다 (좌측 여백 없음)
- [ ] **페이지 전체(body)가 가로로 스크롤되지 않는다** ← 가장 중요
- [ ] 채팅 메뉴의 미읽음 배지가 정상 표시된다

### 2.2 셸 — 768px (태블릿)

- [ ] 사이드바가 **아이콘만(64px)** 표시된다
- [ ] 헤더에 접기/펴기 토글이 **보이지 않는다** (이 구간은 고정)
- [ ] 아이콘에 마우스를 올리면 메뉴명 툴팁이 뜬다

### 2.3 셸 — 1280px (데스크톱)

- [ ] 기본 상태가 **펼침(240px)** 이고, 기존 화면과 동일하게 보인다
- [ ] 헤더의 토글(⇤)을 누르면 아이콘 모드(64px)로 접히고 본문이 넓어진다
- [ ] **새로고침 후에도 접힘 상태가 유지**된다 (localStorage `acm-ui`)
- [ ] 아이콘 모드에서 채팅 미읽음이 **점(●)** 으로 표시된다
- [ ] 아이콘 모드에서 하단 이메일이 숨고 로그아웃이 아이콘만 남는다

### 2.4 화면별 — 375px 기준

각 화면에서 **body 가로 스크롤 없음** + 표는 자체 영역에서만 스크롤되는지 확인.

- [ ] `/admin/dashboard` — 기간 입력 2칸이 줄바꿈되어 들어가고, 하단 그리드 표가 자체 스크롤 (첫 열 고정 유지)
- [ ] `/admin/csl` 목록 — 필터 세로 배치, 표 가로 스크롤
- [ ] `/admin/csl` 칸반 — 단계별 1열 배치
- [ ] `/admin/cal` — **첫 진입 시 리스트 뷰**로 열림, 월/주 전환 가능
- [ ] `/admin/std`, `/admin/cls`, `/admin/tch`, `/admin/stf` — 목록 표 스크롤
- [ ] `/admin/sch` — 학교/학년대/일정 3개 표 모두 스크롤
- [ ] `/admin/ref` — 레벨테스트·벤치마크·가이드라인 표 스크롤
- [ ] `/admin/qna` — 목록·분류 표 스크롤
- [ ] `/admin/map` — 문항 목록 + 등록 모달 입력 그리드 2열
- [ ] `/admin/config` — 보다 설정 등 3열 폼이 1열로 접힘
- [ ] 상담 상세 패널 — 점수 입력 표(ISEE/SSAT) 가로 스크롤
- [ ] 각종 다이얼로그 — 좌우 여백 유지, 내용이 길면 내부 스크롤

### 2.5 회귀 — 1280px 이상

- [ ] 모든 화면이 작업 전과 시각적으로 동일하다 (열 수·여백·표 폭)
