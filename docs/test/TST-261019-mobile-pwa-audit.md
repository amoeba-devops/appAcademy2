# Mobile & PWA Audit (모바일·PWA 전체 페이지 점검)

요청 원문: "pwa , 모바일 최적화 전체 페이지 점검"

## 1. Method (방법)

- 환경: 로컬 서버 + 테스트 DB 사본, 운영과 같은 코드(main `a3f371d`).
- 기기: iPhone 크기 390×844, 터치, iOS Safari 사용자 에이전트.
- 계정: 콘솔 관리자, 포털 강사 1명·학생 1명(로컬 테스트 비밀번호).
- 대상 46개 화면:
  - 공개 5: 홈, 콘솔·포털·학부모 로그인, 앱 시작
  - 운영 콘솔 29 + 사이드바 메뉴
  - 포털 강사 6, 포털 학생 6
- 측정 항목:
  - 가로 넘침(페이지 폭 초과), 화면 밖으로 잘린 요소
  - 32px 미만 터치 영역
  - 12px 미만 글자
  - 16px 미만 입력칸(iOS 가 눌렀을 때 화면을 확대함)
  - 화면 캡처 육안 확인

## 2. Summary (요약)

- **가로 넘침 0 / 잘린 요소 0 (46 화면 전부)** — 넓은 표는 상자 안에서 좌우 스크롤된다. 사이드바는 휴대폰에서 서랍 메뉴로 열리고 "앱 설치"·로그아웃이 하단에 있다.
- PWA 설치 조건·서비스 워커·오프라인 화면·iOS 설치 안내는 정상(REQ-261018D 검증 결과 유지).
- 아래 9건의 개선 필요 사항 — 높음 2, 보통 5, 낮음 2.

## 3. Findings (발견 사항)

| # | 중요도 | 내용 | 위치·측정값 | 제안 |
| --- | --- | --- | --- | --- |
| M1 | 높음 | **입력칸이 16px 보다 작아 iPhone 에서 누르면 화면이 확대**된다 | 모든 로그인 화면(콘솔 3·포털 3·학부모 2칸), **모든 화면 상단 언어 선택**, 마이페이지 타임존 | 휴대폰 폭에서 input·select·textarea 글자 16px (전역 CSS 1곳) |
| M2 | 높음 | **콘솔 로그인 화면의 "Debug Context Panel" 이 운영에도 보인다**. 로그인 주소에 AMA 토큰이 붙어 오면 토큰과 내용을 화면에 보여주고 복사할 수 있다. 휴대폰에서는 하단 설치 안내 위를 가린다 | `/admin/login` 우하단 | 개발 환경 또는 `?debug=1` 일 때만 표시 |
| M3 | 보통 | **터치 영역이 32px 미만** | 대시보드 42개(드릴다운 숫자 "0 *", 새로고침·수정 링크), 학생 목록 27·퇴원 30(정렬 머리글·강사 선택), 사용자 초대 14·이슈 14(필터 칩), 이슈 상세 15, 수업일정 11·포털 일정 8(이전/다음·보기 전환), 수업통계 9, 포털 자료실 6~8(칩) | 휴대폰에서 칩·세그먼트·아이콘 버튼 최소 높이 36~40px |
| M4 | 보통 | **글자가 12px 미만** | 대시보드 99(KPI 설명 10~11px), 상담 목록 16(구분 배지 10px), 수납 9(차트 축·범례), 상담 상세 7, 이슈 상세 5 | 본문 최소 12px, 배지 11→12px |
| M5 | 보통 | **공개 홈의 떠 있는 버튼 4개**(맵테스트·상담신청·카카오톡·전화)가 휴대폰에서 본문 글자를 가린다 | `/` 오른쪽 | 휴대폰에서는 하단 고정 바 1줄 또는 버튼 1개로 접기 |
| M6 | 보통 | **수납관리 통계 차트 3개가 가로로 눌려** 범례가 줄바꿈되고 원형 차트가 잘린다. 이력 경고 문구가 매우 길다 | `/admin/pay` | 휴대폰에서 차트 세로 배치, 경고는 접기(펼쳐 보기) |
| M7 | 보통 | **가로 스크롤 탭의 끝이 잘려** 더 있다는 표시가 없다 | 학생 관리 사이트 탭("S…"), 포털 상단 메뉴("마…") | 오른쪽 흐림 표시 + 선택 탭 자동 스크롤 |
| M8 | 낮음 | 콘솔 상단 언어 선택이 약 90px 를 차지해 아이콘이 몰린다 | 콘솔 상단 바 | 휴대폰에서 언어는 아이콘 버튼 + 목록 |
| M9 | 낮음 | 포털 채팅 제목이 아직 "로비채팅"(콘솔은 "채팅"으로 바뀜) | `/portal/chat` | 포털도 "채팅"으로 통일 |
