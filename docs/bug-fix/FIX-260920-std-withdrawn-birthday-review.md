# Same Birthday Review (동일 생일 학생 검토)

## 1. Problem (문제)
생일이 같은 다른 이름의 학생이 있으면 후보가 있다는 이유만으로 신규 등록을 차단했다. 원본 명부에 서로 다른 이름·원본번호로 구분된 학생도 해당되어 1행이 보류됐다.

## 2. Fix (수정)
후보가 있어도 검토자가 신규 등록을 명시적으로 선택할 수 있도록 한다. 기존 이름/별칭 또는 확정 원본번호가 일치하면 계속 중복 등록을 차단한다. 생일만 같은 다른 학생은 신규 선택을 허용하며 자동으로 합치지 않는다.

## 3. Validation (검증)
합성 데이터의 동일 생일·다른 이름 신규 등록, 동일 원본 재신규 등록 차단을 포함한 격리 PostgreSQL 통합 테스트 5개와 FE/BE 빌드 통과.
